# C3 指示書: AI のひとこと

> 状態: 指示 | 更新: 2026-10-20 | C2 の実況アプリに、AI (Claude Haiku) が作る短い自由な文章を足す。大事な場面だけ、決まりの実況の後に、ずんだもんの声で読む。計画は doc/commentary/plan.md

前提: C2 の後の asterism-games main (594701a、0.19.0)。実況アプリ `lib/asterism_games/commentate*` (出来事 `mahjong_events.rb` と prio、言い回し `mahjong_phrases.rb` と口調 `TONES` (ずんだもんの AI への一文つき)、読み `SPEECH_READ`、VOICEVOX の合成とキャッシュ、ブラウザの待ち行列と捨て方)。ゲームホストの AI の仕組み `lib/asterism_games/ai.rb` (Settings、**Budget** (1 日の費用の上限、種類ごと)、Claude (anthropic の gem は依存ではなく、キーがあるときだけ読む)、Fake)。C1・C2 の report は `doc/commentary/report/c1.md`・`c2.md`。

言葉: 文書は常体、「確かめ」ではなく「確認」。コードのコメントと asterism-games の文書は英語。実況の言葉は日本語。

## 1. 決まっていること (2026-10-20 ユーザ、選択形式)

1. AI のひとことを足す (短い自由な文章)。AI のデモにもする。
2. モデルは **Claude Haiku** (既定 `claude-haiku-5-5`、`--ai-model` で変えられる)。キーは `ANTHROPIC_API_KEY`。
3. **1 日の上限は 3 ドル** (`--ai-daily-usd` で変えられる)。超えたら決まりの実況だけで続ける。

## 2. 決めごと (親が決めた形。変えるなら止まって返す)

- **呼ぶ場面**: 大事な出来事 (リーチ、和了 (特に満貫以上)、流局、逆転、オーラス、終局) と、静かな時間が続いたとき (例: 60 秒何も無い)。1 局に数回が目安。呼ぶ間隔の下限 (例: 20 秒) を置く。`--ai off` で切る、キーが無ければ出さない (画面に「AI: off (キーなし)」)。
- **頼み方**: 固定の部分 (実況者の役、麻雀の決まりの要点、口調 (TONES のずんだもんの一文)、長さ「40 字以内、1〜2 文」、手牌を出してよいか) をシステムの部分にまとめ、**プロンプトキャッシュ**に乗せる。変わる部分は、その時点の観戦用の様子の要約 (局・点数・リーチ・河の要点・各席の手牌と待ち (手牌を隠すときは出さない)) と、直前の出来事。答えは文章だけ (前置き・記号・絵文字なし)。
- **読みと字幕**: AI の文は字幕にそのまま出し、声には C2 の読み直し (`SPEECH_READ`、牌の名前) を通してから合成する。字幕の印で AI の文と分かるように。
- **古くなったら捨てる**: 頼んだ時点の様子の番号 (`sv`) を持ち、答えが来たときに局が変わっていたり、決めた秒数より古かったりしたら読まない。読み上げの待ち行列では、決まりの実況より prio を低くする (和了の決まりの文の後に来る)。
- **手牌を隠すとき** (`--public` / H): AI にも手牌を渡さない (公開の情報だけで実況させる)。
- **費用**: ゲームホストの Budget を使い回し、使った tokens から費用を数える (キャッシュの読み・書きも)。画面の上に今日の費用と上限を出す。上限を超えたら呼ばない。記録は手元 (`~/.local/state/asterism-games/` など XDG に従う) に置き、日をまたいだら戻る。
- **失敗**: 時間切れ (例 8 秒)・失敗は 1 行のログで黙って捨てる (再試行しない)。キーや中身をログに出さない。
- **依存**: anthropic の gem は依存に足さない (ゲームホストと同じく、キーがあるときだけ読み、無ければ「anthropic の gem を入れると AI のひとことが出る」と案内)。SDK の使い方・モデル名・キャッシュの書き方は claude-api の skill を読んで合わせる。
- **試験は外の API を呼ばない**: Fake (ai.rb の Fake か、同じ形の偽物) で、場面の選び方・間隔の下限・古い答えを捨てる・手牌を隠すときに手牌を渡さない・上限で止まる・読み直しを試験する。
- 版は 0.19.0 のまま (C1・C2 と同じ版に足す)。

## 3. 作るもの

1. AI のひとことの部品 (場面の選択、頼む文の組み立て、呼び出し (非同期、待ち行列へ)、古い答えを捨てる、費用と上限)、`--ai on|off`、`--ai-model`、`--ai-daily-usd`、画面の表示 (AI の印、今日の費用)。
2. 試験 (上の項目)。記録した東風戦 (C1 の fixture) を流して、AI を呼ぶ回数が目安に収まることも見る。
3. README (AI のひとことの節: キー、モデル、上限、場面、手牌を隠すときの扱い、費用の目安)、CHANGELOG。
4. 確認: Fake で手元の zenohd とゲームホスト (CPU 4 人) に当て、ヘッドレスのブラウザで AI の文が決まりの実況の後に出る・読まれる順番をページのログで見る。**実際の API での確認はユーザが行う** (report に手順と「確認してほしいこと」)。

## 4. 受け入れ条件

1. `MJ_GAMES=4 bundle exec rake test` が通る。
2. 上の確認が Fake で通り、report に写す。
3. 実際の API を一度も呼んでいない (試験・確認とも)。

## 5. 範囲・決まり

- **触ってよいもの**: asterism-games (main)。fmruby-core は report だけ (`doc/commentary/report/c3.md`、ファイルとして書くだけ、git の操作はしない)。
- **触らないもの**: fmruby-core のコード、asterism・asterism-console・riichi_engine、VPS、GitHub の設定、Tab5。ユーザの `~/asterism_keys/` の証明書、ユーザの VOICEVOX (127.0.0.1:50021、要るなら自分のコンテナ)、ユーザの API キーを使わない。
- 外の API を呼ばない。push・タグ・gem push はしない。`git commit -a` は使わない。コミットの末尾は `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。実在の値の検査をしてからコミットする。
- 起こしたもの (zenohd、ホスト、VOICEVOX とブラウザのコンテナ) は名前で止めて消す。docker の prune はしない。pid で止める。
- **止まる条件**: 1・2 章に無い仕様の選択が要る。止まったら report に、ユーザが選べる形の選択肢 (推奨を先頭に) を書いて返す。
- **report** (`doc/commentary/report/c3.md`、常体): 場面と間隔、頼む文の形 (キャッシュの部分)、古い答えの扱い、費用の数え方、試験と確認の結果、ユーザが実際の API で試す手順と確認してほしいこと。
