### 1.1 声の置き場所と探す順番

アプリは宣言ごとに (ファイル単位で) 次の順に探し、最初に見つかったものを鳴らす。

1. `/home/voice/mahjong/<名前>.wav` — ユーザの物。Tab5 には焼かずに送れる。
2. `/usr/share/sounds/voice/mahjong/<名前>.wav` — ユーザが VOICEVOX で `flash_local/usr/share/sounds/voice/mahjong/` に作った物。端末のビルドで入る (flash_local は flash に重ねて焼かれる)。
3. `/usr/share/sounds/voice/mahjong/default/<名前>.wav` — 同梱の既定の声 (Open JTalk、Mei)。全端末とブラウザ版に入る。

名前は `riichi` `pon` `chi` `kan` `tsumo` `ron`。

### 1.2 VOICEVOX の道具 (`tools/mahjong_voice.rb`)

- `VOICEVOX_URL` (既定 `http://127.0.0.1:50021`)、`SPEAKER` (既定 ずんだもん)、`STYLE` (既定 ノーマル)。`--url` `--speaker` `--style` `--dir` でも渡せる。
- 番号は `/speakers` から名前で引く (無ければ、ある名前を並べて止まる)。
- `audio_query` の答えの `outputSamplingRate` を 16000、`outputStereo` を false にして `synthesis`。WAV は 16bit モノラル 16000Hz であることを確認してから書く。
- 読みは道具の中の表 `WORDS`: リーチ！ ポン！ チー！ カン！ ツモ！ ロン！
- 出力は `flash_local/usr/share/sounds/voice/mahjong/` (gitignore)。同じ場所に `CREDITS.txt` (1 行目が `VOICEVOX:<キャラクター>`、規約の要点、各自が作ったもので配らないこと)。アプリはこの 1 行目をクレジットに使う。
- VOICEVOX が答えないときは、アプリか docker のエンジンの起こし方、WSL のときの住所の渡し方、次に打つ `rake voice:mahjong` を出して終了状態 1 で止まる。
- 標準ライブラリだけ。

### 1.3 既定の声の道具 (`tools/mahjong_voice_default.rb`)

- MMDAgent の公式の配布 (SourceForge の MMDAgent_Example-1.8、2018-12-25) から `MMDAgent_Example-1.8.zip` を取り、SHA-256 を確認する (`f702f2109a07dca103c7b9a5123a25c6dda038f0d7fcc899ff0281d07e873a63`)。`--zip` で手元の zip を渡せる。
- `debian:bookworm-slim` のコンテナ (名前 `fmrb-mahjong-voice-<pid>`、`--rm`) で `open-jtalk=1.11-3`、`open-jtalk-mecab-naist-jdic=1.11-3`、`unzip` を入れ、zip から `Voice/mei/mei_normal.htsvoice` を取り出して SHA-256 を確認 (`b19e8e5ddef4d9d9559d654f395818e2bb3c0bbdbbca533f96086de21ac5db2b`)、6 語を `open_jtalk -s 16000 -p 80 -g 12` で合成する (Mei は 48kHz の声なので、16kHz では 5ms のフレームが `-p 80`。+12dB で一番大きい語が約 -4dBFS)。
- 出力を 16bit モノラル 16000Hz と確認して `default/` に置き、`CREDITS.md` を書く。
- 2 回 (ダウンロードからと `--zip` から) 作り、6 つとも SHA-256 が一致した (再現できる)。

### 1.4 既定の声のライセンス (確認した中身)

- **Mei**: zip の `Voice/mei/README.txt` と `COPYRIGHT.txt`。HTS Voice "Mei" version 1.5、MMDAgent Project Team 発行、Copyright (c) 2009-2018 Nagoya Institute of Technology, Department of Computer Science、**Creative Commons Attribution 3.0**。帰属の書き方の指定は無い (CC BY 3.0 の通常の帰属: 作品名・権利者・ライセンスへのリンク)。`CREDITS.md` と `ASSETS.md` にこれを書いた。
- **Open JTalk**: BSD-3-Clause (Nagoya Institute of Technology)。**辞書** open-jtalk-mecab-naist-jdic: BSD-3-Clause (Nara Institute of Science and Technology、Nagoya Institute of Technology。中の unidic-csj.csv は The UniDic Consortium の BSD-3-Clause)。Debian の copyright ファイルで確認。どちらも配らない (作った音だけを配る)。
- 合成した音は Mei の声の派生として CC BY 3.0 の扱いにし、アプリは使っている間「声: Open JTalk (Mei, CC BY 3.0)」を出す。

### 1.5 アプリ (`mahjong_sound.rb`)

- 宣言が来たとき (ジングルを鳴らす契機、`snd_view` の `@shout`) に、ジングルに加えて `snd_voice(名前)` で WAV を鳴らす。ジングルと WAV は重なる。
- ほぼ同時の宣言: 鳴っている声の優先度と終わりの時刻 (`VOICE_HOLD_MS` = 1000ms) を覚え、優先度が同じか高い声だけが割り込む (ロン 6 > ツモ 5 > カン 4 > ポン 3 > チー 2 > リーチ 1)。ポンの直後のロンはロンに替わり、ロンの直後のチーは鳴らない。
- `play_wav` が false (Retro) なら何も覚えない。ファイルが無い語は鳴らさない (エラーを出さない)。
- 設定: 一覧と待ち合わせに「声 入[V]」/「声 切[V]」(BGM・効果音の隣、V キー)。声のファイルが 1 つも無ければボタンを出さない。`/home/mahjong.toml` に `voice = true/false` で覚える (既定は入)。切にすると鳴っている WAV も止める。
- クレジット: 待ち合わせ (640x360 と 1280x720) の音のボタンの右に「声: <使っている声>」。使っている置き場所ごとのクレジットを ` / ` でつなぐ (既定だけなら「声: Open JTalk (Mei, CC BY 3.0)」、VOICEVOX の物なら CREDITS.txt の 1 行目で「声: VOICEVOX:ずんだもん」、`/home` に CREDITS.txt が無ければ「VOICEVOX:ずんだもん」とみなす)。声を切にしている間は出さない。
- 以前からある `mahjong.toml` の `voice_ron = "..."` などは、見つけた声より優先する。ただし「ジングルの代わり」ではなく「ジングルと一緒」に鳴るようにした (1 章 2 節の「重なってよい」に合わせた)。
- Ruby だけの変更。`mahjong.app.rb` は待ち合わせの 1 行 (`snd_credit(snd_buttons(...), ...)`) だけ。

### 1.6 Tab5 へ送る手順

```
rake voice:mahjong_push IP=<Tab5 の住所>
```

`flash_local/usr/share/sounds/voice/mahjong/` を端末の `/home/voice/mahjong/` に `fmrb_rd_fs.rb push ... --force` で送る (ディレクトリは作られる)。MCP なら tab5_fs で同じ場所に put してもよい。アプリを開き直すと効く。

### 4.1 確認できなかったこと

- **ずんだもんの声の sim での再生**: flash_local の声を sim の読む場所 (flash/ の下、または sim の /home である flash/home/voice/mahjong/) に写して鳴らそうとしたが、権限の判定 (Out-of-Place Publication) で写しとアプリの起動が断られたので、そこで止めて写しを消した。sim は flash_local を重ねない (重ねるのは ESP32 の storage の組み立てだけ) ので、flash_local の声を sim で鳴らすには写すしかない。置き場所の順番とクレジットの選び方は host の試験で確認した。ずんだもんの聞こえ方と、Tab5 の `/home/voice/mahjong/` からの再生は、親とユーザが確認する。
- **ESP32 のビルドで flash_local が重なること**: 今回は ESP32 のビルドをしていない (CMakeLists.txt の `copy_directory flash_local` が flash の上に重ねる既存の仕組みで、`usr/share/sounds/voice/mahjong/` は `default/` と同じ親に入る)。
- **ブラウザ版**: 既定の声は git の追跡分なので束に入る (wasm:webflash は ls-files、wasm:scan も追跡分を通す)。ブラウザで鳴るかは今回見ていない。
- 640x360 以外の実画面 (1280x720) は overflow の試験だけ。

## 5. ユーザが自分の VOICEVOX でずんだもんの声を作って入れる手順

1. VOICEVOX を動かす (どちらか)。
   - VOICEVOX のアプリを起動する (エンジンは 127.0.0.1:50021)。
   - または `docker run -d --name voicevox -p 127.0.0.1:50021:50021 voicevox/voicevox_engine:cpu-0.25.0`
2. fmruby-core で声を作る。
   ```
   rake voice:mahjong
   # 別の住所・キャラクター: VOICEVOX_URL=http://<住所>:50021 SPEAKER=ずんだもん STYLE=ノーマル rake voice:mahjong
   ```
   `flash_local/usr/share/sounds/voice/mahjong/` に 6 つの WAV と CREDITS.txt ができる (git には入らない)。
3. 入れる (どちらか)。
   - **焼き直す**: `rake build:esp32` → flash。flash_local が storage に重なり、`/usr/share/sounds/voice/mahjong/` に入る (flash_local を新しく作ったときは、組み立ての設定に反映させるため `rake clean` してからビルド)。
   - **Tab5 に焼かずに送る**: `rake voice:mahjong_push IP=<Tab5 の住所>` (端末の `/home/voice/mahjong/` に入る)。麻雀アプリを開き直す。
   - sim で聞くなら、sim の /home にあたる `flash/home/voice/mahjong/` に写す (gitignore の中)。
4. 麻雀アプリの待ち合わせに「声: VOICEVOX:ずんだもん」が出ていること、宣言で声が出ることを確認する。声を止めるには V キーかボタン。既定の声 (Mei) に戻すには、`/home/voice/mahjong/` のファイル (と flash_local の物) を消す。

## 6. 範囲と後片付け

- 触ったのは fmruby-core だけ (麻雀アプリ、tools/、rakelib/、test/、ASSETS.md、flash/ の既定の声)。asterism-games は読んで実行しただけ (変更なし)。fmruby-graphics-audio は sim が `flash/etc/display_conf_linux.txt` (width=426) と `flash/cache/` (既定の声の同期の写し、gitignore) を書いたが、手では触っていない。

- VOICEVOX のコンテナ `fmrb-c4-voicevox` は名前で stop・rm、Open JTalk のコンテナは `--rm`、ゲームホストは pid で TERM、sim は mute に戻して sim_down (zenohd も一緒に下りた)。docker の prune はしていない。
- sim の `flash/home/mahjong.toml` は確認の前に写しを取り、確認の後に戻した。
- 生成したずんだもんの WAV は `flash_local/usr/share/sounds/voice/` ごと消した (flash_local には元からの `home/music` だけ)。sim の /home への写しも消した。`git status` で追跡・未追跡に生成物が無いこと、`flash_local/` が gitignore されていることを確認した。
- コミットは e7915df9 と 3eec8057 (push していない)。この報告と指示書はコミットしていない。実在の値 (IP、鍵、ドメイン) を差分で検査した (出てくるのは 127.0.0.1 の既定の住所と公開の配布元の URL・ハッシュだけ)。

## 7. 気づき・選べること

- **Retro の image から声を外した** (2026-10-21 ユーザの決定)。Retro は play_wav が false で使わないので、CMakeLists.txt の Retro の取り除き (サービスと同じ所) で `usr/share/sounds/voice/mahjong` を消す (同梱の声も flash_local の声も)。git と sim・ブラウザ版には残る。
- VOICEVOX の声は Mei より小さい (ピーク約 -17dBFS)。Tab5 で小さければ、道具で `volumeScale` を上げる。
- `voice_ron = "..."` などの以前からの設定は、ジングルの代わりから一緒に鳴る形に変わった。
