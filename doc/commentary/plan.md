# 麻雀の実況 (PC の実況アプリ、宣言の声、AI のひとこと)

> 状態: 計画済 | 更新: 2026-10-20 | ゲームホストの観戦用の様子 (GS14、手牌入り) を読んで、麻雀を実況する。まず PC の実況アプリ (ブラウザで卓を見る、決まりの実況、声)、つぎに AI のひとこと、端末の麻雀アプリの宣言の声 (WAV)。観戦者が増えたら、文章づくりをサーバへ移す

## 1. 目的

- 卓の様子を、スポーツ実況のように声と字幕で伝える。観戦の楽しみと、Asterism と AI のデモ (AI が観戦の役割で網に入り、手牌を見て実況する) を兼ねる。
- 打っている人にも、宣言 (リーチ・ポン・ツモ・ロン …) の声が聞こえるようにする (Family mruby の麻雀アプリ)。

## 2. 方針 (2026-10-20 ユーザ決定)

- **文章を作ることと声にすることを分ける**。文章づくりは軽い (決まりで作る)。声にするのは重い。将来、文章はサーバで卓ごとに 1 回作り、声は各観戦者の手元で作る。
- **実況は手元 (PC) で動くもの**から作る。WSL と macOS の両方。
- **PC の実況アプリ**: `asterism-games commentate mahjong` (asterism-games の gem のコマンド)。手元に小さな Web サーバを立て、**ブラウザで卓を見る** (canvas に Family mruby の牌のアセットで描く)。音 (WAV と読み上げ) もブラウザで鳴らす。OBS などの配信ソフトに載せられる。
- **牌のアセット**: fmruby-core の手描きのシート (`tiles_hand.bmp` / `tiles_river.bmp`) の写しを gem に入れる (描き直さない)。gem の中では **MIT** (作者の決定。fmruby-core 側は GPL-3 のまま)。
- **実況の 2 段**: 決まりの実況 (出来事をすぐ言う: リーチ・鳴き・テンパイ・待ち・和了の役と点数・順位・残り枚数) と、AI のひとこと (大事な場面だけ、短い自由な文章。後で足す)。
- **声**: 決まり文句 (リーチ・ポン …) は **WAV** で鳴らす。その場で作る文は音声合成 (VOICEVOX が手元にあればそれ、無ければブラウザの読み上げ)。作者の声は使わない。**既定はずんだもん** (VOICEVOX)。**声は gem に入れず**、各自の PC の VOICEVOX で WAV を作る (再配布しない。規約は doc/reference/voicevox_terms.md)。
- **端末の麻雀アプリにも同じ WAV** (打っている人に宣言の声。`@audio.play_wav`、Retro は鳴らない)。

## 3. 段階

| 段 | 中身 | 状態 |
|---|---|---|
| C1 | PC の実況アプリの土台: ブラウザの卓 (牌のアセット)、観戦用の様子からの出来事、決まりの実況の字幕と読み上げ (ブラウザの読み上げ)、手牌を隠す | 完了 (asterism-games 548b2e7) |
| C2 | 声の束: 一覧表から VOICEVOX で WAV を作る道具、PC で WAV を鳴らす、VOICEVOX でその場の文を読む、キャラクターの選定と CREDITS | 完了 (asterism-games 594701a、2026-10-20 ユーザが試して確認) |
| C3 | AI のひとこと (場面を絞る、短く、古くなったら捨てる、1 日の上限) | 完了 (asterism-games 78160fe、実際の API はユーザが確認) |
| C3b | 実況のページに麻雀アプリの BGM と効果音 (APU で前もって音のファイルに、効果音 MIT・BGM CC BY 3.0、ダッキング) | 完了 (asterism-games 1b13f19、fmruby-core 7f8b198e) |
| C4 | 端末の麻雀アプリで宣言の声 (既定は同梱の Open JTalk Mei (CC BY 3.0)、各自が VOICEVOX でずんだもんに置き換えられる) | 完了 (fmruby-core e7915df9・3eec8057) |
| C5 | 文章づくりをサーバへ (`asterism/<host>/commentary/<卓>`)、PC とブラウザ版は読むだけ | 未 |
| C6 | 声づくりをサーバか家の PC の node へ (観戦者が多いとき。VPS の性能を上げるか、声づくり係を網に置く) | 未 |

**当面の目標は C1〜C3** (2026-10-20 ユーザ)。C4 以降はその後に決める。

**C3 の後にやること (2026-10-20 ユーザ)**: 「観戦対局」。麻雀アプリと `play mahjong` の待ち合わせで、自分は座らずに 4 席を CPU・AI で埋めて「観戦で始める」。ゲームホストの変更 (座らない卓の主、人 0 人で始める、離席の打ち切りを効かせない、終わり方、観戦対局の AI の上限) とアプリの変更。細部は始めるときに選択肢で決める。
