# Stamp-P4 の殻 (3D プリント ケース) 設計指示

記録: 2026-08-31。状態: 設計指示 (モデル未作成)。モデルは別セッションで
書く。本書はそのための決めごと・寸法・測定項目をまとめる。

## 目的

生基板を触らずに Stamp-P4 (+ Stamp-AddOn C6) を持ち歩き・置くための
2 ピースの殻。ヘッドレス機なので**外に出すのは USB-C の口だけ**。
キャリア基板は使わず、モジュール単体を殻で包む。

## 固定の方針

基板にねじ穴が無いので、次を組み合わせる。基板にねじも接着も使わない。

1. **挟み込み (主役)**: 下殻に基板外形 + 片側 0.3mm のポケット、縁に
   幅 1.0mm の棚。上殻の裏に押さえリブ 4 本を立て、閉じたときに基板の
   縁を棚とリブで挟む。リブが当たる場所は**基板の縁で部品の無い帯**
   (スタンプ穴の帯。めっき穴なので押してよい)。C6 と BTB の上は避ける。
2. **USB-C を位置決めに使う**: コネクタの金属殻を側壁の切り欠きにきつめ
   (殻 + 0.3mm) に通す。前後左右が決まり、**ケーブル抜き差しの力を
   半田でなく殻が受ける**。
3. **スタンプ穴の切り欠きをキーにする**: 縁の 2.54mm ピッチの半円の
   切り欠きに、下殻から幅 0.8mm 以上の突起を 2〜3 か所だけ差し込む。
   ずれ止めと、裏返し・前後逆に入らない向きの取り違え防止。全部の穴に
   入れない (細い突起は折れる)。
4. **C6 を押さえる**: C6 は BTB の嵌合だけで留まっており、衝撃で浮くと
   WiFi が消える。上殻の内側に C6 のシールド缶の上を軽く押す座を設け、
   1mm 厚のウレタンかシリコンのパッドを貼る。**基板アンテナの上には
   何も置かない**。
5. 両面テープ / ホットボンドは最初の 1 個の間に合わせにのみ可。本命の
   殻では使わない。

## 具体案 (寸法は測定で確定する。下記は出発値)

- 下殻: 底 1.0mm、ポケット 30.4 x 22.6mm (本体 29.8 x 22.0 + 0.3/辺)、
  縁に幅 1.0mm の棚。USB-C の反対側の短辺に切り欠きキー 2 個。裏面に
  部品があれば棚で浮かせ、平らなら底に直置き。
- 側壁: USB-C の切り欠き 9.4 x 3.7mm (受け口の殻がおよそ 8.9 x 3.3mm)。
  **コネクタ面が壁の外面と同じかわずかに出る**位置 (プラグの樹脂が壁に
  当たらないため)。P4 のシールド缶の側に通気スリット。
- 上殻: 四隅に押さえリブ (先端 0.8 x 2mm、閉じたときに基板を 0.1〜0.2mm
  だけ締める高さ)、中央に C6 押さえのパッド座。
- 結合: **M2 のタッピングねじ 4 本を四隅のボス**に (再開閉が確実)。
  小ささ優先なら長辺に爪 (スナップ) 2 対。外形の見込みはねじで約
  36 x 28 x 13mm、爪で 33 x 25 x 12mm。
- 向き: C6-MINI-1 の基板アンテナの端を**壁厚 1.2mm 以下の外壁に寄せ**、
  金属を置かない。USB-C はその反対側が理想。
- 全高: 本体 4.3 + C6 4.0 + BTB 嵌合分で 9mm 前後を見込む (実測で確定)。
- 材料: **PETG か ASA** (P4 は負荷時に温まる。PLA は 60°C 付近で軟化)。
- 穴: 外に出すのは USB-C と通気だけ。LED もボタンも本体に無い前提
  (実物で無いことを確認したら、将来キャリアを作るまで窓は設けない)。

## モデルを書く前に測るもの (ノギスと写真)

1. 基板の板厚。裏面が平らか (1.27mm パッドだけか、部品が載っているか)。
2. USB-C の位置: どの辺か、辺の端からの距離、コネクタ面が基板端から
   出ているか (何 mm)、高さ方向の中心。
3. C6 を嵌めたときの全高。C6 が上面のどこに来るか (基板外形に対する
   位置)、基板アンテナがどの端に来るか。
4. P4 のシールド缶の位置と高さ (通気スリットとリブの逃げ)。
5. スタンプ穴の縁の出っ張り (半円の切り欠きの直径と、どの辺にあるか。
   2.54mm の穴が 2 辺か 4 辺か)。
6. MIPI CSI の BTB の位置 (リブの逃げ。カメラを使わない殻では蓋で覆う)。

## モデルの作り方 (別セッションへの指示)

- OpenSCAD で、上記の寸法を全て変数にした 2 ピース (下殻・上殻) の
  モデルを書く。`clearance` (0.3)、`wall` (1.2〜1.5)、`floor` (1.0)、
  `rib_squeeze` (0.15) を先頭の変数にし、測定値を入れ替えるだけで再生成
  できる形にする。
- 先に**ポケットと USB-C 切り欠きだけの下殻**を試し刷りして嵌め合いを
  確かめ (30 分で刷れる大きさ)、clearance を決めてから上殻を仕上げる。
- 出力は STL 2 つ。プリンタが無ければ出力サービスに出す (PETG 指定)。
- 置き場所: モデルと STL は fmruby-core の外 (基板データと同じ扱い) に
  置き、本書からは相対位置だけを書く。

## 受け入れ条件

1. 殻を閉じた状態で振っても基板と C6 が動かない (音がしない)。
2. USB-C ケーブルの抜き差しを 50 回して、基板が動かず、プラグが最後まで
   入る。
3. WiFi (C6) の接続が殻の有無で変わらない (遠隔画面の kbps と fps で比較)。
4. 遠隔画面を 30 分流し続けて殻の表面温度を測り、触れる温度 (目安 45°C
   以下) であること。超えるなら通気を増やす。
5. 殻の開閉を 10 回して、リブ・キー・ボスが欠けない。

## 未確定事項

- 基板の裏面の凹凸と板厚 (測定 1)。
- USB-C の正確な位置 (測定 2)。
- C6 のアンテナの向き (測定 3)。ケースの向き決めの根拠。
- 本体にボタン・LED が本当に無いか (資料に記載無し)。
- ねじか爪か (小ささと再開閉のどちらを取るか。既定はねじ)。
