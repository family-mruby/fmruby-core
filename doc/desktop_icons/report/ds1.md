## 2. 作ったもの

- `main/prebuild_scripts/kernel/system_desktop/desktop_icons.rb` (新規、`DesktopIconsMixin`)
  - 読み込み: `/home/desktop.toml` → 無いか読めなければ `/usr/share/desktop/desktop.toml` → それも無ければ空。
  - 書式は `apps = ["default/editor", "/app/tool/nsf_player.app.rb"]` (1 行でも複数行でも、`#` の注釈つきでもよい)。Regexp が無いので行を歩いて引用符の中を集める。キーが無い・`]` が来ない・引用符が閉じないものは「壊れている」として nil。
  - 解決: ランチャーの一覧 (`@launcher_apps`) を道のりで引く。無ければ `/app/...` の道のりから `.toml` を直接読む (`parse_app_toml` を流用)。それも無ければ飛ばす。ランチャーの除外カテゴリにあるアプリや、ランチャーのキャッシュが古くて載っていないアプリも出せる。
  - 描画: 背景の canvas (`@bg_gfx`, z=0) に、ランチャーのアイコン SpriteImage を `draw_tile` で押す。`draw_background` が壁紙の直後に呼ぶ。名前は文字幅の板 (テーマの窓の色) の上に書き、どの壁紙でも読める。
  - 入力: デスクトップの `handle_click` の末尾 (何も開いていない・メニューバーより下) から当たり判定。1 回目で選択 (名前の板がハイライト色)、同じアイコンへの 2 回目で起動。間隔の数え方はランチャー・ファイル管理と同じ (`@counter` 5 未満、on_update が 500ms 毎)。
- `launcher.rb`
  - タイトルバー右端に FmrbUI のボタン `:lnc_desk` (118x12)。選択中のアプリがデスクトップに有れば「デスクトップから外す / Remove from desktop」、無ければ「デスクトップに置く / Add to desktop」。何も選んでいないときは隠す。
  - 名前の 2 行割りを `icon_label_layout(label, max_px)` に切り出し、ランチャーとデスクトップで共用。
  - 再走査の後、解決できなかった項目があったときだけアイコンを組み直す (新しく入れたアプリが出る)。
- `system_desktop.app.rb`: mixin の取り込み、ivar の初期化、`on_create` で構築、`draw_background` で描画、`handle_click` で当たり判定。`paint_bg_rect` にランチャーのタイトルバーの穴 (ボタンを隠した跡) をタイトルバーの色で埋める分岐。
- `i18n.rb`: `desk_add` / `desk_remove`。
- `flash/usr/share/desktop/desktop.toml` (新規、既定の組)。

## 4. 内蔵 RAM とメモリ

- C (main/) とグラフィックス側の変更は無い。増えたのは Ruby の objects だけで、デスクトップ VM のプール (起動時に確保済みの固定の塊) の中に収まる。アイコンの絵はランチャーが起動時に作る SpriteImage をそのまま使い (アイコンファイルで共有)、グラフィックス側の新しい確保も無い (ランチャーが持たないアイコンのアプリを置いたときだけ 1 枚増える)。よって内蔵 RAM の増分は 0 の見込み。**実機の同一コミット比較 (`M1|` / `IRAM free:`) はしていない** (sim は内蔵 RAM を出さない)。親の Tab5 確認で見てほしい。
- デスクトップ VM: アイコン構築時の増分はログ `Desktop icons: 5/5 shown, pool +7KB (46%)` (Modern sim)、`+3KB (61%)` (Retro sim)。起動後の `sim_app ps` で system_desktop は 735-867KB / 1536KB (ごみの溜まり具合で揺れる)。
- 置く・外すのたびに一覧を作り直すので少しごみが出るが、操作頻度からして問題にならない。

## 5. 判断したこと・解釈

- **ランチャーからの操作はボタンにした**。右クリックは今までどおり「一覧の作り直し」(ランチャー内のどこでも)。計画 3 章の「今の右クリックの意味とぶつけない形」をボタンで満たした。右クリック・長押しの意味は変えていない。
- **ダブルクリックの判定は既存と同じ**にした (タップ 1 回起動には変えていない。仕様の選択になるため)。Tab5 で打ちにくいかどうかは実機確認次第。
- 「描画は出す分だけ (背景の再描画のたびに全部を描き直さない)」の解釈: 選択の変化では名前の板 2 つだけを塗り直し、壁紙は触らない。毎秒の時計更新では背景を触らない。壁紙を描き直すとき (起動、全画面アプリから戻ったとき、外したアイコンの跡を消すとき) はアイコンも描き直す — 壁紙がアイコンを上書きするので避けられない。アイコン 1 個は 24x24 の draw_tile と文字 1-2 行。
- 列は画面の左半分まで。Retro (320x240) は 1 列 5 個 (17 + 5x44 = 237)、超えたら右の列へ。左半分を越える分は出さない。
- セル幅は 64 (最初 56 で「NSF Player」が 2 行に割れたので広げた)。

## 6. 見立てと違った点・踏んだ罠

- `create_image` (画像) は PNG しか読まない (グラフィックス側が `drawPng` 固定)。アイコンは BMP なので背景に直接描けない。SpriteImage は canvas に縛られず id で全域から引けるので、`draw_tile` (SpriteImage の一部を任意の canvas に押す、透明色対応) を使った。P4 の display_local と graphics-audio の両方が実装済み。
- FmrbUI の Button は disabled のとき文字色が枠の色になり、既定テーマでは塗りと同じ色 (0x60) で文字が消える。灰色にする代わりに隠すことにし、隠した跡をタイトルバーの色で埋める分岐を `paint_bg_rect` に足した。
- ブラウザ版の束は git の index から作るので、新規の `desktop.toml` は `git add` してからでないと入らない (入れなかったら既定の組が空になる)。
- 手元の sim の `flash/var/cache/launcher_index` は古く (App Store が 2 つ出る)、ランチャーの一覧に無いアプリも `.toml` から引く経路が役に立つ。キャッシュは利用者のローカル物なので触っていない。
