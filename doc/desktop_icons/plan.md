# デスクトップにアプリのアイコンを並べる

> 状態: 進行中 | 更新: 2026-10-18 | 代表的なアプリをデスクトップの背景にアイコンで並べ、ダブルクリック (タップ) で起動する。DS1 で実装 (sim・ブラウザ版で確認済)。残りは Tab5 のタップ確認と実機の内蔵 RAM 比較

## 1. 目的

- アプリが増え、ランチャーから探すのが手間になった。よく使うアプリを、デスクトップの背景から直接起動できるようにする。

## 2. 決まっていること (2026-10-18 ユーザ、選択形式)

1. **既定の組 + 利用者が変えられる**: 代表的なアプリ (例: エディタ・Shell・ヒデ雀・お絵かき・NSF プレイヤ) を既定で出し、利用者が「デスクトップに置く / 外す」を変えられる (/home の設定ファイルと、ランチャーからの操作)。
2. **背景にアイコンを並べる**: パソコンのデスクトップのように、背景の左側にアイコンと名前を縦に並べ、ダブルクリック (かタップ) で起動。窓の下になる (窓が上に重なる)。

## 3. 方針

- アイコンは各アプリの `.icon` / `.bmp` (ランチャーと同じもの) を使う。
- 設定の置き場所: 利用者の選びは `/home` の設定ファイル (例 `/home/desktop.toml`)。既定の組はファームの側 (例 `/usr/share/` か system_conf)。`/home` は空で出荷する決まり (fmruby-core の CLAUDE.md) に従い、設定ファイルが無ければ既定の組。
- ランチャーからの操作: 今、ランチャーの右クリックは「一覧の作り直し」に使っている。アプリの上での右クリック (か長押し) に「デスクトップに置く / 外す」を足すときは、今の右クリックの意味とぶつけない形にする。
- Modern (Tab5・P4・ブラウザ版・sim の 426x240 / 640x360) と Retro (320x240、NTSC) の両方で崩れないこと。内蔵 RAM は増やさない (決まり: 増分 0)。描画は出す分だけ (背景の再描画のたびに全部を描き直さない)。
- Tab5 のタッチは相対移動 (タップ = カーソルの位置)。ダブルクリックが打ちにくければ、タップ 1 回で起動にする選択肢を残す (仕様の選択になるので、そのときは止まって返す)。

## 4. スコープ

- 入れる: 背景のアイコン、既定の組、/home の設定ファイル、ランチャーからの置く・外す。
- 入れない: アイコンのドラッグでの並べ替え (後で)、フォルダ。

## 5. 受け入れ条件

1. sim (426x240・640x360) とブラウザ版で、既定の組のアイコンが背景の左に並び、ダブルクリックで起動する。窓が上に重なる。画面を写す。
2. ランチャーから置く・外すと、デスクトップのアイコンが変わり、/home の設定ファイルに残る (起こし直しても同じ)。
3. 設定ファイルが無い / 壊れているときは既定の組で出る (落ちない)。
4. Retro の sim (320x240) で崩れない。内蔵 RAM の増分 0 (同じコミットで比べる)、デスクトップの VM の使用量 (数字)。
5. Tab5 の実機で、タップで起動できることをユーザに確認してもらう (実タッチは注入では確かめられない)。
6. sim の標準構成で、エディタを 1 回起動して 1 打鍵する。

## 6. 決まったこと (DS1、report/ds1.md)

- 既定の組: エディタ・Shell・ヒデ雀・お絵かき・NSF プレーヤ (上から)。`/usr/share/desktop/desktop.toml` に置く。その端末に無いアプリは飛ばす (Retro の実機ではヒデ雀が出ない)。
- 利用者の選び: `/home/desktop.toml` (`apps = [ "道のり", ... ]`)。無い・壊れているときは既定の組。
- ランチャーからの操作: タイトルバー右端のボタン (「デスクトップに置く / から外す」、選択中のアプリに対して)。右クリックの意味 (一覧の作り直し) は変えない。
- 起動はダブルクリック (間隔の数え方はランチャーと同じ)。
- File Manager のショートカット (2026-10-18 ユーザ): アプリではないので `"desktop/file_manager"` という特別な名前で一覧に書く。フォルダのアイコン (`/usr/share/icon/folder.icon`) で出し、ダブルクリックでメニューの File Manager と同じものを開く。既定の組では Shell の次。ランチャーには出ないので、ランチャーのボタンでは置く・外すができない (`/home/desktop.toml` を手で編集する)。
- アイコンの名前は単語の切れ目で 2 行に折る (「File / Manager」)。ランチャーと共通の処理なので、ランチャーの名前も同じように折れる。
