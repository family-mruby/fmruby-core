## 1. 起きていること (ユーザ: 「今使いにくいので UI の配置や保存ファイルの指定とか使いやすくしたい」)

今のスプライトエディタは: ランチャーに出ない (ファイルマネージャーで絵を選んだときだけ開く)、新しく作れない、
保存はキーの S で上書きだけ (別名で保存できない)、色は決まった 16 色、クリックで 1 点ずつ (なぞれない)、
道具は塗るだけ、16x16 のタイルだけ、Window の大きさを変えても配置が変わらない、メニューもボタンも無く英語の 1 行だけ、
標準の部品とテーマの色を使っていない。

## 2. 決まっている形 (2026-11-21 ユーザ)

1. **配置**: 上にメニューバー (ファイル・編集)。左に道具の列、中央に拡大した絵、右に色とタイルの一覧、下に状態の行。

```
+----------------------------------------+
| ファイル  編集                           |
+----+--------------------+--------------+
|ペン|                    | 色 (256)     |
|消す|                    | ############ |
|塗る|    拡大した絵      | ############ |
|拾う|                    | 今の色 [##]  |
|戻す|                    +--------------+
|    |                    | タイルの一覧 |
+----+--------------------+--------------+
| stamp1.png  16x16  (3,5)  色 E0  *     |
+----------------------------------------+
```

2. **色**: 256 色 (RGB332 の全部) の升目を並べ、クリックで選ぶ。その近くに最近使った色を数個。
   **`0x01` は透明色**で、升目でも絵の上でも市松模様などで見分けられるようにする。今の色の表示。
3. **ファイル (テキストのエディタと同じ流儀)**: ランチャーから起動できる。メニューに「新規」(大きさを選ぶ)・「開く」・
   「保存」・「名前を付けて保存」。ファイルを選ぶ画面はテキストのエディタが使っているものに合わせる。保存していない変更が
   あるまま閉じる・開く・新規のときは聞く。ファイルマネージャーから開く道も残す。既定の置き場は `/home` の下
   (スタンプ用の見立ては `/home/stamps/`。無ければ保存のときに作る)。
4. **道具**: ペン (押したまま動かして塗れる)、消しゴム (透明色で塗る)、塗りつぶし (つながった同じ色)、色を拾う、
   取り消し (数回分)。
5. **絵の大きさ**: 新規のときに 16x16・24x24・32x32・48x48 から選べる。拡大率は Window の大きさに合わせて変わる。
   Window の大きさを変えたら配置し直す。今ある 16x16 のタイルのシート (複数タイル) も今までどおり開けて、
   タイルを選んで編集できる。
6. 入れないもの: 左右・上下の反転、ずらす (ユーザが選ばなかった)。アニメーション、レイヤー。

細部 (升目の大きさ、最近使った色の数、取り消しの回数、426x240 と 640x360 での割り振り、キーの割り当て、
メニューの文、新規のときの下地の色) は決めてよい。**決めたものは report に並べる**。画面の文は日本語と英語
(端末の言語の設定に従う。ほかのアプリの流儀)。

## 3. 気をつけること

- 保存の形式: 今は開いた形式で書き戻す (BMP332.save は拡張子で決める)。新規の既定の形式は、スタンプ (PNG、48x48 以下、
  8 KB 以下、c0.md) と合うものにする。PNG に書いたとき `0x01` の画素がどうなるか (PNG の透明にするのか、色のままか) を
  実物で確かめ、チャットの側 (C3) が透明として出せる形を report に書く。**形式をまたぐ扱いで選ぶ必要が出たら、止まって
  選択肢にして返す**。
- VM プール: 48x48 の絵、256 色の升目、取り消しの分を持ったときの使用量を測る。取り消しは絵の全体の写しを数個持つ形で
  足りるか、KB 単位で見積もる。
- 描画は画面に出る量に比例させる (1 点塗るたびに全部を描き直さない)。なぞっている間の重さを sim で見る。
- PicoRuby の罠: Regexp 無し、`Array#pack` 無し、ブロックは重い、`String#length` は文字数。
- アプリは mruby のアプリのまま (Spinel にしない)。

## 4. 受け入れ条件

1. sim の Modern: ランチャー (か `sim_app`) から開く → 新規 32x32 → ペンでなぞる・塗りつぶし・消しゴム・色を拾う・
   取り消し → 256 色のうち升目の端の色と `0x01` で塗る → 名前を付けて保存 → 閉じて開き直すと同じ絵。画面の写しで確認。
2. 保存していない変更があるまま閉じると聞かれる。キャンセルで戻れる。
3. 今ある絵 (リポジトリの中のタイルのシート。例: ゲームの絵) をファイルマネージャーから開けて、タイルを選んで直して
   保存でき、ほかのタイルが変わっていない (保存の前後でファイルを比べる)。
4. Window の大きさを変えると配置し直され、どの部品も押せる。426x240 と 640x360 の両方で使える。
5. ブラウザ版でも開いて 1 点塗って保存できる (`/home` に残る)。
6. `rake regress` が通る。最後に 1 回 `rake regress:screens`。VM プールを report に。
7. `git status` に取りこぼしなし (前からある 3 つを除く)。起こしたものは止めてある。
