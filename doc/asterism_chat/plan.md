# Asterism のチャットルーム (チャットホストと端末のアプリ)

> 状態: 進行中 | 更新: 2026-11-21 | Asterism の上に、部屋で文字とスタンプをやり取りするアプリを作る。履歴と部屋を持つチャットホスト (新しい gem asterism-chat、VPS のコンテナ) と、端末のアプリ (Modern・ブラウザ版・ネイティブ版)。ゲームホスト・AI ホストと同じ流儀。C0・C1 (ホストの gem の最小)・C2 (端末のアプリ、文字だけ。sim とブラウザ版で互いに話せた) ・C3a (スプライトエディタの作り直し) 済。・C3b (絵のビューワー・ファイルの画面の最初のフォルダ・PNG の透明)・ホストのスタンプと配置の一式 (asterism-chat 0.2.0) 済。次は C3 (端末のスタンプ)

## 1. 目的

家族や仲間の決まったメンバーが、Family mruby の端末 (P4-Nano・Tab5・ブラウザ版・GPD) から部屋に入って話せるようにする。
後から開いても続きが読めること (履歴) を中心に置く。Asterism の「呼び出し」と「流す値」の両方を使う、ゲーム以外の
最初の常設のアプリにする。

## 2. 決めたこと (2026-11-21 ユーザ)

1. **作り**: 端末同士で流すのではなく、**チャットホストを 1 つ立てる**。履歴・部屋・発言の順番はホストが持つ。
2. **対象の端末**: Modern (P4-Nano・Tab5)・ブラウザ版・ネイティブ版 (GPD)。**Retro は対象外**。
3. **発言の中身**: 文字とスタンプ。画像一般・アプリやコードの受け渡しは最初の版に入れない。
4. **部屋**: 複数。名前と数は**ホストの設定で決める**。役割を持つ端末は全部の部屋に入れる。端末から部屋を作る機能・
   部屋ごとのメンバーの管理は作らない。
5. **履歴**: 部屋ごとに直近の件数まで (設定の値)、**ホストを再起動しても残る**。古いものは捨てる。
6. **ホストの置き場**: 新しい gem **asterism-chat** (ruby-asterism の下の独立したリポジトリ。asterism-tutor と同じ作り)。
7. **発言者の名前**: **端末で決めた表示名**。ホストは、ルータが確認した端末のノード名と組にして覚える
   (名前は自由に付けられるが、端末は偽れない)。
8. **スタンプ**: **ユーザが描いた絵をスタンプにできる** (絵そのものを運ぶ)。
8b. **スタンプの絵は ESP32 の配布イメージ (storage) に入れない。App Store の機能でインストールできるようにする**
    (2026-11-21 ユーザ)。見本・既製の絵は「スタンプのパック」として App Store (family-mruby-apps) から入れる。
9. **新着の知らせ**: アプリを閉じている間の知らせは入れない。アプリの中で、部屋の一覧に未読の数を出す。

C0 の後に決めたこと (2026-11-21 ユーザ。値と線の形の正は report/c0.md):

10. **画面**: 大きさを変えられる Window 1 つ。狭いときは部屋の一覧と会話を切り替え、広いときは左に一覧・右に会話を並べる。
11. **自分の絵**: スプライトエディタの絵と、`/home/stamps/` の PNG (48x48 まで) の両方を一覧に出す。
12. **チャットのアプリの置き場**: 配布イメージに入れる (`flash/app/modern`)。App Store で入れるのはスタンプの絵だけ。
13. **スタンプのパックの形**: family-mruby-apps の一覧を作る道具を直して、スクリプトの無い「絵だけのパック」を認める。
    公開のリポジトリへの反映は、C3 のときに改めてユーザの許可を得る。
14. **同じ表示名**: 画面に出ている発言の中で、同じ名前が別の端末から出ているときだけ、ノード名の末尾 3 文字を添える。
15. **スタンプの透明**: **スプライトエディタを直す。色を 256 色 (RGB332 の全部) から選べるようにし、ほかと同じく
    `0x01` を透明色にする**。スタンプも `0x01` を透明として出す。
16. **ホストの記録**: 発言の本文を残さない (どの端末が・どの部屋に・何文字、まで。本文は履歴にだけある)。
17. **上限の既定**: 発言 200 文字、履歴 500 件/部屋、1 日 300 回/端末、表示名 8 文字 (ホストの設定で変えられる)。
18. **スプライトエディタを使いやすくする** (2026-11-21 ユーザ「UI の配置や保存ファイルの指定とか使いやすくしたい」):
    配置は上にメニューバー・左に道具・中央に絵・右に色とタイルの一覧。色は 256 色の升目と最近使った色。
    ファイルはテキストのエディタと同じ流儀 (ランチャーから起動、新規・開く・保存・名前を付けて保存、変更ありで閉じるとき聞く)。
    道具はペン (なぞれる)・消しゴム・塗りつぶし・色を拾う・取り消し。絵の大きさは 16・24・32・48 から選べる。
    反転・ずらすは入れない。正は instruction_c3a.md。
19. C2 の細部 (親の仮決め、report/c2.md): 並べる幅は区画 380 px から。端末の設定は `/home/chat/settings.toml`。
    開いたことの無い部屋の未読は全部を数える。時刻は `HH:MM` だけ。打ちかけの文は部屋を変えると消える。
    Retro の storage にはチャットのアプリを入れない (AI ヘルパーと同じ除外)。
20. C3a の後 (2026-11-21 ユーザ): PNG・BMP の**標準は新しく作るビューワー**、ファイルマネージャーの右クリックで
    スプライトエディタ。名前の無い絵の保存は、**ファイルの画面を `/home/stamps/` から開く** (ファイルの画面に最初の
    フォルダを渡せるようにする)。PC で描いた **PNG の透明は、読み込みで `0x01` にする**。
21. 発言の時刻は「月/日 時:分」(年は出さない。2026-11-21 ユーザ)。決定 19 の「`HH:MM` だけ」を置き換える。

前提 (前からの方針): Asterism は信頼できるメンバーだけの網。知らない人を招く形は作らない。使える端末は console の役割で絞る。

## 3. 方針

### 3.1 全体の形

```
端末のアプリ (chat) ──呼び出し──> <node>/chat/room  (post・history・rooms・hello・stamp_*)
                    <──流す値──  <node>/chat/@pubs の部屋ごとのトピック (新しい発言の番号)
チャットホスト (asterism-chat、VPS のコンテナ): 部屋・履歴・表示名・スタンプをディスクに持つ
```

- **発言はホストが番号を振る** (部屋ごとの通し番号)。端末は「この番号より後をください」で続きを取る。
  トピックには発言そのものではなく**新しい番号の知らせ**を流し、端末はそれを見て続きを取りに行く
  (取りこぼしても次の知らせか次の問い合わせで追いつく。順番は全員同じ)。
  発言が短いうちは知らせに本文を載せてしまう形も C0 で比べる。
- **端末は直近の分だけを持つ**。開いたときに直近 N 件、さかのぼるときに続き。VM プールを KB 単位で食わない件数にする。
- **表示名**: `hello(名前)` でホストに伝える。ホストは `from` (ルータが確認したノード名) ごとに 1 つ覚える。
  発言には、発言した時点の表示名とノード名の両方を残す。
- **既読**: 作らない。未読の数は、端末が覚えている「最後に見た番号」と部屋の最新の番号の差。

### 3.2 スタンプ (ユーザの絵)

- スタンプは**小さい絵のファイル** (大きさと形式の上限は C0 で決める。見立ては 32x32〜48x48 の PNG、数 KB まで)。
- 端末の決まった置き場 (見立て `/home/stamps/`) にある絵を、アプリのスタンプの一覧に出す。
- 送るとき: 絵の中身の sha256 を発言に書く。ホストがその絵を持っていなければ、端末が小分けにして送る
  (asterism-tutor の `doc_begin`・`doc_piece` と同じ形)。受ける側の端末は、持っていない sha256 の絵をホストから
  小分けで取り、端末の置き場に貯める (同じ絵は 1 回しか運ばない)。
- ホストは絵を検査する (大きさ・形式・画素数の上限)。合わないものは断る。持つ枚数にも上限。
- **絵の出どころは 2 つ**:
  - **スタンプのパック**: App Store (`main/ruby/default_app/appstore.app.rb`、置き場は `/app/usr/<id>/`、一覧は
    family-mruby-apps) から入れる。配布イメージには 1 枚も入れない (決定 8b)。パックの形 (絵のファイルと、
    パックであることの印) と、チャットのアプリがパックを見つける方法は C0 で決める。App Store の今の作りが
    「アプリでないもの (絵だけ)」を入れられるかも C0 で読む。試作の間は、App Store の別の置き場
    (`/home/appstore_base.txt`) か、手で置いたパックで試す。
  - **自分で描いた絵**: 端末の置き場 (見立て `/home/stamps/`)。描く道具は、今あるスプライトエディタ
    (`flash/app/tool/sprite_editor.app.rb`、16x16 の RGB332) が候補。
- どちらの絵も、送るときは絵そのものがホスト経由で相手に届く (相手が同じパックを入れていなくても出る)。

### 3.3 権限 (console の役割)

- **chat-host** (ホストの側): 自分のノードの下の公開 (`asterism/${node}/chat/**`) と要る読み。
- **chat** (使う端末の側): ホストの `room` を呼べる、部屋のトピックを購読できる。使わせる端末にだけ付ける。
  ブラウザは利用者ごとに付ける (console 0.4.2 以降の仕組み。共有の ws のページには付けない)。
- 行の形は AI ホスト (tutor-host・tutor) を写す。

### 3.4 置き場と配置

- gem: `asterism-chat` (試作の間は非公開。公開は後で決める)。`deploy/vps/` に Dockerfile・compose・env.example・update.sh
  (asterism-tutor 0.2.2 の形。状態の問い合わせは `</dev/null` つき)。状態の volume に履歴とスタンプ。
- 端末のアプリ: `flash/app/modern/chat.app.rb` と `chat/` (AI ヘルパーの画面の部品・Link の使い方を土台にする)。

## 4. スコープ

- 入れる: 2 章の 1〜9。日本語の入力 (自前のかな入力・PC とブラウザの IME)。つながらないときの表示。
  ホストの記録 (JSONL)・`status`・SIGTERM の扱い・1 日の上限 (発言の数・スタンプの大きさ) は AI ホストに倣う。
- 入れない: Retro、端末からの部屋作り、部屋ごとのメンバー、既読、閉じている間の知らせ、画像一般・ファイル・
  アプリの受け渡し、発言の編集と取り消し、暗号化 (ルータの TLS と ACL まで)、ルータなしの P2P。
