## 1. 作るもの

`flash/app/modern/chat.app.rb`・`chat.app.toml` と `flash/app/modern/chat/` (分けるなら)。Modern・ブラウザ版・
ネイティブ版で動く。Retro は対象外 (ランチャーに出ない置き場のまま)。

1. **つなぐ**: `FmrbAsterism::Link` で網につなぎ、`*/chat/room` を探す。つながらない・ホストがいない・役割が無いときは、
   理由を分かる言葉で状態の行に出す (AI ヘルパーの文の流儀。呼び名は「チャットホスト」)。
2. **表示名**: 初めて開いたときに名前を打つ (8 文字まで。ホストの上限に従う)。端末に覚える (置き場は `/home` の下の
   設定のファイル。形は任せるが report に書く)。後から変えられる。`hello` で伝える。
3. **部屋の一覧**: 名前と未読の数 (端末が覚えている「最後に見た番号」とホストの `last` の差)。
   最後に見た番号は端末に覚える (開き直しても未読が合う)。
4. **会話**: 発言の欄 (名前・本文・時刻。自分の発言は見分けがつく形)、入力の行、送信。日本語が入る
   (自前のかな入力、PC・ブラウザの IME。AI ヘルパーと同じカーソルの申告)。長い発言の折り返し、スクロール、
   上へさかのぼると古い分を取る (`history(before:)`)。端末が持つのは部屋ごとに直近 50 件まで。
5. **新着**: トピック `news` を購読し、開いている部屋なら `history(after:)` で続きを取って出す。ほかの部屋なら未読の数を増やす。
   知らせを取りこぼしても、次の知らせか部屋を開いたときに追いつく。自分の発言も、ホストが振った番号で出す
   (`post` の答えと知らせの両方が来ても二重に出さない)。`cid` で送り直しても二重に載らない。
6. **画面 (決定 10)**: 大きさを変えられる Window 1 つ。狭いときは部屋の一覧と会話を切り替え、広いときは左に一覧・
   右に会話。切り替える幅は c0.md の案を元に決めて report に書く。
7. **同じ表示名 (決定 14)**: 画面に出ている発言の中で、同じ名前が別のノードから出ているときだけ、ノード名の末尾 3 文字を添える。
8. **断り**: ホストの誤り (too_long・limit・no_name・stopping など) を、子どもに分かる文で出す。
9. 端末の案内 `flash/usr/share/doc/chat_ja.md`・`chat.md` (短く)。アイコンは今ある流儀で (`.icon` と `rake icons`)。

**入れない**: スタンプ (C3)。スプライトエディタ (C3a)。閉じている間の知らせ。ただしスタンプの発言
(c0.md の発言の形に足す見込みの欄) が来ても落ちず、「(スタンプ)」のように出すこと。

## 2. 気をつけること

- VM プール: AI ヘルパーの実測 (a3d・a3e) を目安に。50 件/部屋を持ったときの使用量を測る。件数が多いと厳しければ、
  減らす案を数字つきで report に書く (勝手に仕様を変えない。50 件は c0 の見積もり)。
- PicoRuby の罠: Regexp 無し、`Array#pack` 無し、ブロックは重い (描画の輪で `each` を使わない)、`String#length` は文字数、
  バイトは `bytesize`/`getbyte`。**切り出した文字列の長さは信用しない作りにしなくてよい** (mruby の直しが develop に入っている。
  a3e の追記)。
- 描画は画面に出る量に比例させる (全部の発言を毎回描き直さない)。優先度の高い所に長い仕事を置かない。
- 時刻は端末の時計が合っていないことがある。発言の時刻はホストの `t` を使い、`hello` の `tz` で表示する。
- 呼び出しは待たずに回す形 (AI ヘルパーと同じ。ブラウザ版は協調のタスクなので、待つと画面が止まる)。

## 3. 受け入れ条件

1. ローカルのルータ (`../asterism-chat` の試験と同じ起こし方) とチャットホストで、**sim の Modern とブラウザ版の 2 つ**が
   同じ部屋で互いの発言を見られる (片方が送ると、もう片方に知らせで出る)。順番が両方で同じ。日本語の発言が入る。
   画面の写しを report に (場所はスクラッチでよい。report にはパスでなく、何が見えたかを書く)。
2. 後から開いた側が履歴を取れる。さかのぼりで古い分が出る。未読の数が、開き直した後も合う。
3. Window の幅を変えると、一覧と会話の並べ方が切り替わる。入力の行のカーソルの申告が、大きさを変えた後も合う
   (`tools/fmrb_web.rb ime` で `focused: ime`)。
4. ホストを止めた・役割が無い (受け付けない端末)・長すぎる発言・1 日の上限のそれぞれで、分かる文が出る。
   ホストを起こし直すと、続きから話せる。
5. `rake regress` が通る。最後に 1 回 `rake regress:screens`。VM プール (開いて、50 件の部屋を出した後) を report に。
6. `git status` に取りこぼしなし (前からある 3 つを除く)。起こしたもの (sim・web・ルータ・gem) は止めてある。
