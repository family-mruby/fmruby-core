# W4 指示書: 見本のアバターのアプリ

> 状態: 実装中 | 更新: 2026-11-11 | 正は plan.md の「決定」(見本は flash/app/demo/、movable、絵は Ruby の文字列でアプリの中に持つ)

## 目的

枠なしの Window (W1〜W3) と checkpoint の `amove` を、1 つのアプリで見せる。デスクトップの上にいる小さな
キャラクターで、どこを掴んでも動かせ、`amove` でほかの端末やブラウザへ移ると、同じ姿・同じ状態で現れる。

## 作るもの

- `flash/app/demo/avatar.app.rb` と `.app.toml` (名前は既存に合わせて決めてよい。表示名は英日)。
  `window_frame = "none"`、`movable = true`、ランチャーに出す。
- 絵: 小さなドット絵 (32x32 か 48x48 前後、2〜4 コマ) を Ruby の文字列 (行ごとの文字で色を表すなど) としてアプリに
  持つ。外部のファイルを読まない (doc/app_assets が無くても移った先で同じ姿)。オリジナルの絵にする (既存の
  キャラクターを真似ない)。
- ふるまい (控えめに):
  - 待機のアニメーション (まばたき・揺れ)。描くのは変わったときだけ (描画の費用は画面に出る量に比例させる)。
  - クリック (W2 の預かりで、押して離した) で小さな反応 (表情が変わる、短い吹き出し)。吹き出しは Window の中に収める。
  - 状態を持つ: 名前、なでられた回数、訪れた端末の一覧 (`on_restore` で今の端末のノード ID か platform を足す)。
    移った先でそれが続いていることが画面で分かる (例: 吹き出しで「3 か所目だよ」)。
  - 右クリックで閉じる (W2 の既定のまま)。
- Retro (320x240) と Modern (426x240) の両方で動く。Spinel ではなく mruby の VM のアプリ (movable の前提)。

## 確認

- `rake regress` (画面の基準は変えない)。
- ネイティブ版 2 つの間で `amove` (native_app の move か CLI) して、移った先で同じ状態・透けたまま・ドラッグとクリックが
  効く。ブラウザ版と sim の Retro で起動して透け・クリック・ドラッグ。画面を scratchpad の w4/ に。
- 可能ならネイティブ版からブラウザ版へ Asterism で `amove` (手元の zenohd、regress:checkpoint の web の場面の作り)。
- 回帰の場面に足すかは見立てを report に書く (足すなら別のコミット、基準の更新は親)。
