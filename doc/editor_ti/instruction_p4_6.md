# 実装指示書 P4.6: ヘルプ/要約の二国語化 (ja/en、1 マーカー方式)

対象: 実装担当セッション。前提: P4.5 完了 (F1 ヘルプ + 補完/ホバーの要約が
動作)。plan.md と report/p4_5.md を先に読むこと。

report は doc/editor_ti/report/p4_6.md へ。タスクごとにコミット。

## ゴール

補完/ホバーの一行要約と F1 ヘルプページを、システム言語 (ja/en) に追従して
切り替える。**ファイル数を増やさず、fork エンジン / tidbgen / gen_help を
一切変更しない**。二言語は sig の doc コメント内に 1 マーカーで同居させ、
**表示側 (ti_ui.rb) だけ**が言語を選ぶ。

## 方針 (決定済み)

- **マーカー = `<<en>>`** (複数文字、本文に出ない)。要約はインライン、
  ヘルプ長文は行として言語の境に置く。
- 二言語は**同じ 1 マーカー**で扱う。sig/ もヘルプも 1 ファイルのまま。
- **fork / tidbgen / gen_help は無改修**: これらは doc 文字列を中身を見ずに
  素通しする。区切りはただの文字列として db / .md を通過する。
- **言語源は FmrbI18n.lang** (= FmrbApp.language、"ja"/"en")。エディタは
  既に FmrbI18n を使っている。
- **日本語トーンは大人も使う想定の普通の説明** (子供向けに寄せすぎない。
  P4 の「子供向け一文」は撤回。ユーザ指示 2026-08-12)。
- **フォールバック**: マーカーが無い doc は、その 1 言語を両方の言語で出す。
  = 既存の日本語のみ doc は無改修で従来どおり動く (移行が安全)。

## sig の書き方 (規約)

doc コメントの構造:

```
# 黒 (RGB332) <<en>> black (RGB332)     ← 1 行目 = 要約。<<en>> で ja | en
#
# 背景を塗りつぶすときに使う。            ← 2 行目以降 = 長文 (日本語側)
# ```ruby
# gfx.clear(FmrbGfx::BLACK)
# ```
# <<en>>                                 ← 長文の言語境 (行として置く)
# Used to fill the background.
# ```ruby
# gfx.clear(FmrbGfx::BLACK)
# ```
```

- 1 行目 (要約) は db に入る。`ja <<en>> en` の形。日本語側が先。
- 2 行目以降 (長文) は flash/help に出る。`<<en>>` だけの行が日本語長文と
  英語長文の境。署名行 (gen_help が先頭に書くシグネチャ) は言語非依存。

## T1: 規約と見本

1. `sig/README.md` に上記規約を追記: 1 行目 `ja <<en>> en` / 長文は
   `<<en>>` 行で区切り / **トーンは大人も想定 (子供向けに寄せすぎない)** /
   マーカー無しは片言語フォールバック。P4 で書いた「子供向け一文」の記述を
   この方針に更新する。
2. 見本を数件だけ二言語化 (全 API はやらない。書き方の基準を作るのが目的):
   FmrbGfx の色定数 (BLACK 等) 数個、draw_text、FmrbApp のフック 1-2 個。
   既存の日本語一文を「大人も使う普通の説明」に直しつつ `<<en>>` で英語を
   足す。長文を持つものは長文側も二言語に。

## T2: 要約の言語選択 (ti_ui.rb)

エンジンが返す doc 文字列 (要約) を表示する箇所で、`<<en>>` で割って現在
言語の側を出すヘルパを 1 つ作り、全表示点で通す。

- ヘルパ (例):
  ```
  def ti_pick_lang(text)
    return text.to_s if text.nil?
    i = text.index("<<en>>")
    return text if i.nil?           # マーカー無し = そのまま両言語で
    FmrbI18n.lang == "en" ? text[(i + 6)..-1].to_s.strip : text[0, i].strip
  end
  ```
  (`"<<en>>".length` = 6。lang は "ja"/"en"。)
- 通す表示点は **2 箇所**:
  - `comp_explain_selected` (補完ドロップダウンの doc 行、`@comp_docs[...]`)。
  - ホバー (Ctrl+T) が doc を出す箇所 (show_hover の method_document 表示)。
- 幅の切り詰めは**split の後**に行う (現状の fit ロジックの手前で
  ti_pick_lang を通す)。画面に出る幅は片言語だけなので従来と同じ。

## T3: ヘルプページの言語選択 (ti_ui.rb, open_help)

F1 は `load_file(HELP_DIR + path)` で .md を丸ごとバッファに読む。読んだ後、
`<<en>>` だけの行を境に、現在言語でない側を EditorCore のライン操作で消す。

- .md の構造 (gen_help の出力): `シグネチャ行` → 空行 → `日本語長文` →
  `<<en>>` 行 → `英語長文`。
- フィルタ手順 (load_file の直後):
  - `<<en>>` 単独行 (trim 一致) の行 index M を EditorCore.line_count /
    line_length / char_at で探す。無ければ何もしない (フォールバック)。
  - **ja のとき**: M 行目から末尾までを削除 (シグネチャ + 日本語長文が残る)。
  - **en のとき**: シグネチャ末尾 (先頭からの最初の空行 B) の次から M 行目
    までを削除 (シグネチャ + 空行 + 英語長文が残る)。
  - 削除は EditorCore の行/範囲削除 API (ec_delete_range 等、既存の editor-core
    API を使う。無ければ複数行削除を組む)。
- 読み取り専用/ハイライトオフ等、既存 open_help の後処理は不変。
- 実行時に言語を変えたら (system_conf 再読込は不要、FmrbI18n.lang が返す値で)
  次に F1 を開いた時点で切り替わる。ビルドは 1 回で両言語が .md に入っている。

## T4: 検証 (sim, 両構成)

   - `FmrbGfx::B` + Tab → 候補選択の doc 行が**日本語**要約。
   - Ctrl+T → 日本語要約/シグネチャ。
   - 二言語化した見本メソッドで F1 → **日本語長文のみ**が開く (`<<en>>` 行と
     英語側が見えない)。
2. language=en に変えて再ビルド/再起動 (config は起動時読み):
   - 同じ操作で doc 行・F1 が**英語**になる。
3. マーカー未対応 (既存日本語のみ) の doc/ヘルプ: ja/en どちらでも日本語が
   出る (フォールバック、壊れない)。
4. 両エンジン (標準=Spinel / 全 mruby) でビルド通過。
