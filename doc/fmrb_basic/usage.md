# FMRuby BASIC の使い方

Family mruby 上で動く Family BASIC 互換 BASIC の利用者向け文書。
互換の範囲と既知の差は `known_differences.md`、動作した作品の一覧は
`compat_list.md` を参照。

## 1. プログラムを置く・動かす

### エディタで書いて F5

一番早い。デスクトップのランチャーから **Editor** を開き、プログラムを
書いて **F5** (メニューの `Run` / `Alt-R` でも同じ)。

- 無題なら保存ダイアログが出る。**`/home` または `/app` の下**に保存する
  (他の場所は実行できない)。
- 前回 F5 で動かしたものが走っていれば、それを止めてから起動し直す。
- 実行中のアプリからエディタへ戻るには **Ctrl-Q**。全画面のゲームでも
  これで抜けられる。戻ればそのまま F5 で再実行できる。

### ランチャーに並べる

`.bas` と同じ名前の `.toml` を並べて置くと、ランチャーのアイコンになる。

```
flash/app/basic/mygame.app.bas
flash/app/basic/mygame.app.toml
```

```toml
app_handle_name = "mygame"
app_screen_name = "My Game"
app_screen_name_ja = "マイゲーム"
# 省略すると .bas は全画面で起動する。ウィンドウにしたいときだけ書く:
#default_window_mode = "window"
```

- ランチャーの一覧は**デスクトップ起動時に一度だけ**作られる。後から
  置いたものを出すには、ランチャーの中で**右クリック**して再スキャンする。
- `.toml` が無いファイルも F5 やシェルからは実行できる (アプリ名には
  ファイル名が使われる)。

### 画面の大きさ

Family BASIC の画面は **28 文字 x 24 行 (224x192 ドット)** で固定。
全画面で起動したときは画面中央に置かれ、周囲は黒で塗られる。

## 2. キーボードとパッド

USB ゲームパッドがあればそれを使う。無くてもキーボードで代用できる。

| BASIC から見た入力 | パッド | キーボード |
|---|---|---|
| `STICK(0)` の 1 (右) | 十字右 / 左スティック右 | → |
| `STICK(0)` の 2 (左) | 十字左 / 左スティック左 | ← |
| `STICK(0)` の 4 (下) | 十字下 | ↓ |
| `STICK(0)` の 8 (上) | 十字上 | ↑ |
| `STRIG(0)` の 1 (START) | START (ボタン 7) | Enter |
| `STRIG(0)` の 2 (SELECT) | SELECT (ボタン 6) | Space |
| `STRIG(0)` の 4 (B) | B (ボタン 1) | X |
| `STRIG(0)` の 8 (A) | A (ボタン 0) | Z |

- パッドは挿さっていなくてよい。未接続でもエラーにはならず、
  キーボードだけで動く。
- **Ctrl-Q** はシステムが横取りする予約キー。プログラムには渡らない。
- **矢印キーは `INKEY$` では読めない**。文字を持たないキーなので
  `INKEY$` には流れてこない。方向入力は `STICK(0)` で読む。
- **Enter は `INKEY$` に `CHR$(10)` で届く** (`CHR$(13)` ではない)。
  入力終了の判定は `IF A$=CHR$(10) OR A$=CHR$(13)` と両方見ておく。
- **`INKEY$(0)` (キー待ち) の直前に PRINT した文字は、キーが来るまで
  画面に出ない**。待っている間フレームが進まないため。プロンプトを
  見せてから待つときは `PAUSE 1` と引数なしの `INKEY$` を回す。

### 付属のデモ

ランチャーの BASIC には、機能を一通り見せる 3 本と、言語そのものの見本を
置いている。**3 本ともキーボードだけで遊べる**。

| デモ | 見せるもの | キー |
|---|---|---|
| シュート (`sample_11_shoot`) | スプライト一式 (DEF MOVE 8 方向、CRASH、CUT/ERA/CAN、PALET) と PLAY / BEEP | ヤジルシ=移動、Z=ショット |
| メイロ (`sample_12_maze`) | テキスト画面 (LOCATE / COLOR / SCR$)、穴掘り法の迷路生成、カナ入力 | ヤジルシ=移動、TAB=カナ、Enter=決定 |
| オンガク (`sample_13_music`) | PLAY 3 声の非同期再生、CLICK / BEEP、拡張の CIRCLE / PRESENT | 1-4=曲、Z=全部、0=終了 |
| BASICデモ (`basic.app.bas`) | PRINT / FOR / IF / GOSUB。入力なしで流れる見本兼テンプレート | なし |

### カナ入力

実行中のプログラムが `INPUT` や `INKEY$` でカナを受け取るときは、**TAB** で
カナモードに入り **ローマ字 2 打**で 1 文字 (`KA` -> カ)。もう一度 TAB で
英数に戻る。実機は JIS カナ配列の直接入力だが、こちらはローマ字方式を
正式仕様としている (`known_differences.md` #18/#31)。

**エディタではカナを打てない**。カナ入りのプログラムを書くときは PC 側で
編集し、`flash/` に置いて焼くか、ファイル転送で持ち込む。エディタは
カナの表示もできない (文字化けする) ので、カナを含む行を開いたまま
編集するのも避けたほうがよい。エディタ側の対応は本プロジェクトの
範囲外 (`known_differences.md` 区分 4)。

## 3. fmruby 独自の拡張

Family BASIC には無い命令。互換性が要るプログラムでは使わないこと。

| 命令 | 意味 |
|---|---|
| `CIRCLE x,y,r,色` | 円を描く。テキスト面と同じキャンバスに直接描画する |
| `PRESENT` | 画面を今すぐ反映する。通常は自動なので、CIRCLE と組み合わせるときだけ必要 |
| `_SCRDUMP [tag]` | 画面の内容をログへ出す (ゴールデンテスト用) |
| `_SPEED n` | 1 フレームあたりの実行文数。`0` で制限なし (ベンチ用) |

`_` で始まる名前は Family BASIC の変数・命令になり得ないので、
既存のプログラムと衝突しない。

## 4. ファイルの読み書き

- `SAVE "名前"` … `/home/名前.bas` に保存する。名前は 16 文字以内、
  パス区切りは使えない。`.bas` は自動で付く。
- `LOAD` / `LOAD?` … **何もしない**。実機ではインタプリタのプロンプトで
  打つコマンドであり、このシステムには直接モードが無いため
  (`known_differences.md` #29)。プログラムを読み込むにはエディタを使う。

## 5. 音

`PLAY "MML文字列"` と `BEEP` が使える。PLAY は**非同期**で、鳴らしながら
プログラムは進む。再生中に次の `PLAY` を出すと**前の曲を置き換える**。

MML は音階 `C`-`B` と `#`、音長 `0`-`9`、休符 `R`、オクターブ `O0`-`O5`、
テンポ `T1`-`T8`、音量 `V0`-`V15`、エンベロープ `M0`/`M1`、デューティ
`Y0`-`Y3`。`:` で区切ると 3 声まで同時に鳴らせる (1 つの文字列の中で
区切る。文字列は 31 文字以内)。

```basic
100 PLAY "T4M1Y2V12O3C5E5G5:C5E5G5:O1C9"
```

## 6. 絵柄を差し替える

文字とスプライトの絵は画像ファイルとして持っている。差し替えても
ファームウェアを作り直す必要はない。

```
flash/usr/share/basic/font_b.bmp   文字 (表B)
flash/usr/share/basic/tile_a.bmp   スプライト・アニメキャラ (表A)
```

- 128x128 の**インデックス BMP**。8x8 のセルが 16x16 個並び、
  文字コード = 行 x 16 + 列。
- パレット番号 **0 = 透明 / 背景、1-3 = 配色グループの 3 色**。
  慣例として 1 = 輪郭、2 = 本体、3 = ハイライト。
- **BASIC アプリを起動し直せば反映される**。ファイルが無い・壊れている
  場合は内蔵の絵に戻るだけで、動かなくなることはない。

PNG で描きたい場合は変換できる:

```
rake basic:sheet_convert IN=font_b.png OUT=flash/usr/share/basic/font_b.bmp
rake basic:sheet_convert IN=flash/usr/share/basic/font_b.bmp OUT=font_b.png
```

## 7. うまく動かないとき

| 症状 | 見るところ |
|---|---|
| `?SN ERROR IN 30` | 30 行の書き方。省略形の解釈が違う場合もある (`known_differences.md` #8) |
| `?IL ERROR` が出る命令 | 直接モード専用の命令かもしれない (LIST / AUTO / DELETE / RENUM / FIND / GAME) |
| POKE しても何も起きない | 対応していないアドレス。ログに `POKEW|unmapped $XXXX` が 1 度だけ出る。対応表は `virtual_memory_map.md` |
| 画面が動かない | ログの `GFX STATS` の presents/s を見る |
| キーが効かない | ランチャーや F5 から起動していれば自動でフォーカスが入る。それ以外の経路ならウィンドウを 1 度クリックする |
