# Family BASIC V3 追加仕様

V3 で追加された全 26 命令と、V3 のメモリマップ・エラーメッセージを
まとめる。基本命令・関数・PLAY (MML)・DEF SPRITE / DEF MOVE の
正式書式は family_basic_core_spec.md を参照。
表記: [ ]=省略可、{ }=いずれかを選択。未確定項目は「要確認」と明記。

## 確定した仕様

### メモリマップ (V3)

| アドレス | 内容 |
|---|---|
| &H6000 - &H6FFF | ユーザー RAM (4KB) |
| &H7000 - &H7FFF | 未使用領域 |
| &H8000 - &HCFFF | BASIC インタプリタ |
| &HD000 - &HD3FF | BG 画面 (マリオワールド用) |
| &HD400 - &HDBFD | GAME 0 |
| &HDBFE - &HE681 | GAME 1 |
| &HE682 - &HF307 | GAME 2 |
| &HF308 - &HFFF9 | GAME 3 |
| &HFFFA - &HFFFF | システム用 |

- ユーザ RAM は 4KB (V3)。BACKUP 命令の使用禁止領域は &H7000-&H703F。
- 仮想 POKE/PEEK の設計では &H6000-&H6FFF (ユーザ RAM) と
  BG 画面領域の再現が中心になる。

### エラーメッセージ一覧

エラー表示は 2 文字コード。コード 15, 18-21 は V3 で追加。

| No | 表示 | メッセージ | 意味 |
|---|---|---|---|
| 0 | NF | NEXT without FOR | FOR がないのに NEXT |
| 1 | SN | Syntax error | 文法誤り |
| 2 | RG | RETURN without GOSUB | GOSUB がないのに RETURN |
| 3 | OD | Out of DATA | READ すべき DATA がない |
| 4 | IL | Illegal function call | 呼び方の誤り |
| 5 | OV | Overflow | 演算結果が許容範囲を越えた |
| 6 | OM | Out of memory | メモリ不足 |
| 7 | UL | Undefined line Number | 分岐先行番号がない |
| 8 | SO | Subscript out of range | 配列添字が規定外 |
| 9 | DD | Duplicate Definition | 配列の二重定義 |
| 10 | DZ | Division by zero | 0 除算 |
| 11 | TM | Type mismatch | 変数の型不一致 |
| 12 | ST | String too long | **文字列が 31 文字を越えた** |
| 13 | FT | Formula Too complex | 式が複雑すぎる (括弧過多等) |
| 14 | CC | Can't continue | CONT で再開できない |
| 15 | UF | Undefind function | 未定義関数 (V3) |
| 16 | MO | Missing operand | 必要なパラメータがない |
| 17 | TP | Tape read ERROR | テープ読み取りエラー |
| 18 | NR | No RESUME | ハンドラに RESUME がない (V3) |
| 19 | RE | RESUME without error | ハンドラ外の RESUME (V3) |
| 20 | NB | No BG data | BG データが RAM 領域にない (V3) |
| 21 | UP | Unprintable error | 0-20 以外のエラー (V3) |

- 実装上の確定事項: **文字列変数の最大長は 31 文字** (ST エラーの定義より)。

### DEF SPRITE 系と DEF MOVE 系の命令対照表

| # | 機能 | DEF SPRITE 系 (ユーザ定義キャラ) | DEF MOVE 系 (特定動作のアニメキャラ) |
|---|---|---|---|
| 1 | 表示を可能にする | SPRITE ON | (同左) |
| 2 | 表示を不可能にする | SPRITE OFF | (同左) |
| 3 | 定義する | DEF SPRITE ~ | DEF MOVE ~ |
| 4 | 未定義の状態にする | RUN 命令での初期化 | CAN n0, n1, ~ (V3) |
| 5 | 動かす / 表示する | SPRITE n, X, Y | MOVE n0, n1, ~ |
| 6 | 動きを止める | SPRITE n, X, Y | CUT n0, n1, ~ |
| 7 | 消す | SPRITE n | ERA n0, n1, ~ |
| 8 | 初めの位置を決める | SPRITE n, X, Y | POSITION n, X, Y |
| 9 | 現在の位置を知る | (ユーザプログラムで実現) | XPOS(n), YPOS(n) |
| 10 | 動いているか止まっているか | (ユーザプログラムで実現) | MOVE(n) ※関数形 |
| 11 | 動いているときの方向 | (ユーザプログラムで実現) | VCT(n) (V3) |
| 12 | 重なりの判定 | (ユーザプログラムで実現) | CRASH(n) (V3) |

### V3 追加命令の書式

凡例: [ ]=省略可、{ }=いずれかを選択 (必須)。「省略形」は短縮入力形。

- AUTO [m][,n] : 行番号自動付与。m=開始行番号 (0-65534)、
  n=増分 (0-65534)、省略時 m=10, n=10。入力済み行に到達すると
  RETURN でスキップ、STOP キーで終了。
- BACKUP : プログラム/BG のメモリバックアップ (電池保持)。BG 面 1 を
  一緒に残すには BGGET であらかじめユーザ RAM へ転送が必要。
  その場合プログラムは 3KB 以下であること。
- BGGET (省略形 BGG.) : 書式 `BGGET`。VRAM にある BG 面 1 のデータを
  ユーザー RAM に転送する (BACKUP 用)。ユーザー RAM に余裕がないと
  OM エラー (ユーザー RAM 容量は 4KB)。
- BGPUT (省略形 BGP.) : 書式 `BGPUT`。BGGET でユーザー RAM に
  転送したデータを VRAM へ転送する。すでに転送済みの場合は NB エラー。
  HOT START 時は自動的に転送され BGPUT 実行後と同じ状態になる。
- BGTOOL : 書式 `BGTOOL`。BASIC モードから BG グラフィックモードへ
  移行し、BG 面 1 に背景画を描く。プログラム作成途中でも実行でき、
  プログラムに組み込むことも可能。BASIC モードへ戻るには ESC キーを
  押した後 STOP キー。
- CAN : 書式 `CAN n0[,n1,...,n7]` (n=スプライト番号)。
  DEF MOVE で定義したアニメキャラの表示と座標位置の両方を同時に
  未定義にする (従来必要だった ERA + POSITION の 2 命令を 1 命令で)。
- CLICK (省略形 CLI.O. / CLI.OF.) : 書式 `CLICK {ON|OFF}`。
  キー入力音 (クリック音) の ON/OFF。ON=クリック音発生、OFF=無音。
- CLS の V3 拡張 (省略形 CL.) : 書式 `CLS [BG面]`。0=BG 面 0 を
  クリア、1=BG 面 1 をクリア。省略時は現在アクセス中の BG 面が
  クリアされる。
- CRASH (省略形 CR.) : 書式 `CRASH(n)` (n=スプライト番号 0-7)。
  DEF MOVE によるアニメキャラ同士の重なり判定関数。n と重なっている
  スプライトのうち最小のスプライト番号を返す。重なりなし = -1、
  スプライト未定義 = -2。
- DELETE (省略形 DEL.) : 書式 `DELETE [m][-][n]`。プログラム行の
  一括削除。受理形は 4 通り: `DELETE m-n` (m~n 行)、`DELETE m`
  (m 行のみ)、`DELETE -n` (先頭~n 行)、`DELETE m-` (m 行~最終行)。
- ERL : 書式 `ERL` (システム変数)。エラーが発生した行番号を返す。
  ON ERROR GOTO のエラー処理ルーチン内で、発生行による処理分岐に
  使う。
- ERR : 書式 `ERR` (システム変数)。発生したエラーのエラーコード
  (エラー表の No) を返す。エラー処理ルーチン内で
  エラー種別による処理分岐に使う。
- ERROR (省略形 ERR.) : 書式 `ERROR エラーコード`。指定コードの
  仮のエラーをその行で発生させる (エラー処理ルーチンの動作確認用)。
- FIND (省略形 FI.) : 書式 `FIND "X"` (X=探したい単語、31 字以内)。
  入力済みのプログラム行から文字列 X を含む行をすべて表示する。
- FILTER (省略形 FIL.) : 書式 `FILTER カラー番号` (0-7、デフォルト 0)。
  BG 面の全面をフィルターをかけたように淡く着色する。
  0=無色, 1=赤, 2=緑, 3=黄, 4=青, 5=マゼンタ, 6=空色, 7=白。
  CTR+D キー同時押しでもデフォルト状態 (0) に戻る。
- GAME (省略形 GA.) : 書式 `GAME p[,Sw]` (p=ゲーム番号 0-3、
  Sw=背景画転送 1=行う / 0 または省略=行わない)。ROM 内蔵ゲームを
  実行する。プログラム中に組み込み不可。実行するとメモリ内の
  プログラムは自動的に消える。背景画転送が必要なのは
  『マリオワールド』のみ。
- INSTR (省略形 INS.) : 書式 `INSTR([P,]文字列1,文字列2)`
  (P=文字列 1 を探し始める位置、デフォルト 1)。文字列 1 の中の
  文字列 2 の位置を先頭から 1 起算 (左から右) で返す。値域 1-31、
  見つからない場合は 0。
- LOADS : 書式 `LOADS ["ファイル名"]` (ファイル名 31 文字以内)。
  テープから BG グラフィックデータを読み込む (LOAD の BG 版)。
  名前指定時は一致する BG まで SKIP 表示で読み飛ばし、省略時は
  テープの最初の BG を読む。プログラムと一括で読むには
  `LOAD"プログラム名":LOADS"ファイル名"`。読み込み中は
  LOADING ファイル名、終了で OK 表示。
- ON ERROR GOTO (省略形 O. ERR. G.) : 書式 `ON ERROR GOTO 行番号`。
  プログラム先頭部で実行しておくと、以降の行でエラーが発生したとき
  指定行 (エラー処理ルーチン) へ分岐する。ルーチンの終了行は
  RESUME または END にする (END の場合はプログラム終了して
  コマンド入力待ち)。
- RENUM (省略形 REN.) : 書式 `RENUM [l][,m][,n]` (l=新しく付ける
  開始行番号、m=変更を始める行の元の行番号、n=増分。デフォルトは
  いずれも 10)。行番号を整理し、GOTO/GOSUB 文などの分岐先行番号も
  自動的に追随変更する。ただし `ERL=1000` のように比較式で書かれた
  行番号は変更されない。
- RESUME (省略形 RESU.) : 書式 `RESUME [{行番号|NEXT}]`。
  エラー処理ルーチンからメインルーチンへ復帰する。単独=エラー発生行
  から再実行、行番号=指定行から実行、NEXT=エラー発生行の次の行から
  実行。ハンドラ外で実行すると RE エラー。
- SAVES : 書式 `SAVES "ファイル名"` (ファイル名 31 文字以内)。
  BG グラフィックデータをテープへ保存する (SAVE の BG 版)。
  プログラムと一括で保存するには `SAVE"プログラム名":SAVES"ファイル名"`。
  セーブ中は WRITING ファイル名、終了で OK 表示。
- SCREEN (省略形 SC.) : 書式 `SCREEN 表示面[,アクティブ面]`
  (各 0/1)。2 面ある BG 面を表示面とアクティブ (書き込み・カーソル)
  面に割り当てる。表示面とアクティブ面が同一なら第 2 引数省略可
  (`SCREEN 0,0` = `SCREEN 0`)。CTR+D キーで両方 BG 面 0 に戻る。
- TRON / TROFF : 書式 `TRON` / `TROFF`。トレースモードの開始/終了。
  TRON 中は実行中の行番号が `*行番号` の形で表示される。
  ダイレクトモード・プログラムモードのどちらでも実行可。TROFF で
  ノーマルモードに戻る。
- VCT (省略形 VC.) : 書式 `VCT(n)` (n=スプライト番号 0-7)。
  DEF MOVE によるアニメキャラの移動方向を返す関数。値域 0-8。
  0=停止中または未定義。1-8 は方向で、配置は
  1=上, 2=右上, 3=右, 4=右下, 5=下, 6=左下, 7=左, 8=左上。
  DEF MOVE の定義式 `DEF MOVE(n)=SPRITE(AC,D,...)` の方向パラメータ
  D と同じ値。

### DEF MOVE / DEF SPRITE の使用例 (内蔵キャラクタ)

定義書式の正式なパラメータは family_basic_core_spec.md を参照。
以下はサンプルプログラムから確認できた使い方の実例。

- DEF MOVE 使用例:
  `DEF MOVE(n)=SPRITE(AC,D,1,255,0,0)`
  - AC: アニメキャラクタ番号 0-15 (内蔵キャラ。デフォルト 4 はペンペン)。
  - D: 移動方向 1-8 (VCT の方向値と同一)。STICK(0) の値を D=1..8 に
    変換すれば操作キャラを 8 方向に動かせる。
  - 残る 4 引数は 速さ=1 (最高速)、全移動量=255 (2x255=510 ドット)、
    優先度=0、配色=0 (core spec の C,D,E,F に対応)。
  - POSITION n,X,Y で初期位置設定 -> MOVE n で移動開始。
    XPOS(n)/YPOS(n) で現在位置、MOVE(n)<>0 で動作中判定。
- DEF SPRITE 使用例 (16x16 キャラの左右向き切替):
  - 右向き: `DEF SPRITE 0,(0,1,0,1,0)=CHR$(P+1)+CHR$(P)+CHR$(P+3)+CHR$(P+2)`
  - 左向き: `DEF SPRITE 0,(0,1,0,0,0)=CHR$(P)+CHR$(P+1)+CHR$(P+2)+CHR$(P+3)`
  - 第 4 引数 (X 反転) と CHR$ の並び替えを併用して反転表示する。
  - 16x16 スプライト 1 枚はキャラコード 4 つ (CHR$ 連結 4 個) で構成。
  - アニメーションは P を +4 ずつ P1~P2 で巡回させてコマ送りし、
    `SPRITE 0,X,Y` で表示 (PAUSE 3 程度のウェイトを挟む)。
- 内蔵アニメキャラクタの P (開始コード) / P2 (終了コード) 対応
  (P=P1 を開始、P2 を終端としてコマ送りする):

  | P (=P1) | P2 | キャラクタ |
  |---|---|---|
  | 0 | 8 | マリオ |
  | 28 | 36 | レディ |
  | 56 | 60 | ファイターフライ |
  | 64 | 68 | アキレス |
  | 88 | 92 | ニタニタ |
  | 112 | 116 | ファイアーボール |
  | 144 | 148 | スピナー |
  | 184 | 188 | カメさん |
  | 192 | 196 | カニさん |
  | 200 | 204 | トリさん |

### コントローラ

- STICK(n) n=0,1: 0=中立, 1=右, 2=左, 4=下, 8=上 (同時押しは加算)
- STRIG(n) n=0,1: 0=中立, 1=START, 2=SELECT, 4=B, 8=A (同時押しは加算)
