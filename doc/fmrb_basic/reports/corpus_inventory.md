# ターゲット作品 棚卸し表 (テンプレート)

作品リストはユーザが選定する。**作品コードはリポジトリに収録しない**
(この表に書くのは、実装に必要な「使用機能の情報」だけ)。

記入手順:
1. ユーザから作品リストを受け取る (作品名と入手元はユーザ手元で管理)。
2. 1 本ずつリスティングを読み、下の 2 表に転記する。
3. 「未対応機能」列に、現在の spec / 実装計画でカバーされない要素を書く。
4. POKE/PEEK アドレスは頻度表 (sec 3) に集計し、Phase B4 の仮想メモリマップ
   の入力にする。
5. 集計 (sec 4) を更新し、実装優先度の判断材料にする。
