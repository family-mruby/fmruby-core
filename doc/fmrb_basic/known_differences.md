# FMRuby BASIC 既知差異一覧

Family BASIC (V3) と本実装の差を全件棚卸しした確定文書。**この文書の完成を
もって機能実装完了とする** (B4.5 T4.5-4)。以後は区分 3 の値更新と B5 の
計測・調整だけが残る。

疑義番号は各フェーズ report の疑義リストの通し番号 (B0 sec 8.1 の 3 件 +
#6-34)。区分は 4 つ:

1. **解決済み** — 実装またはユーザ裁可で決着した
2. **実装差として確定** — 実機と違うが、これを本実装の仕様とする
3. **データ差し替え待ち** — コードは完成、値だけ実機資料待ち
4. **対象外** — 実装しないと決めたもの

---

## 2. 実装差として確定

実機と挙動が違うことを承知のうえで、本実装の仕様とするもの。

| # | 内容 | 本実装 | 影響する作品 |
|---|---|---|---|
| B0-1 | エラーの画面表示書式が spec に無い | `?<2文字> ERROR[ IN <行>]` | 全作品 (見た目のみ)。`interpreter::raise` 1 箇所で追従可 |
| B0-2 | ロード時エラーに行情報を付けるか | 付けない (`?SN ERROR`) | 同上 |
| 6 | 負数の整数除算・剰余の丸め方向 | 0 方向へ切り捨て (`-7/2 = -3`、C と同じ) | 座標計算で符号付きの値を割る作品 |
| 7 | オーバーフロー時の挙動 | 16bit 折り返し (`32767+1 = -32768`) | 実機が OV を出す場合に差 |
| 8 | 省略形の重複 (`D.` = DIM/DATA、`SC.` = SCREEN/SCR$) | 表順で先勝ち (`D.`=DATA、`SC.`=SCREEN) | 省略形入りのリスト |
| 9 | FOR 終了後のループ変数の値 | 終値 + STEP (MS 系) | ループ後に変数を使う作品 |
| 10 | 未宣言配列の暗黙 DIM | 各次元 0-10 で自動生成 | DIM を書かない作品 |
| 11 | 文字列 31 字制限をテンポラリにも適用するか | 適用する (超過は ST)。ただし PRINT の裸のリテラルだけ制限外 | 32 字以上を PRINT する作品 |
| 12 | 文字コード表に無い文字 | ロード時に `?` (0x3F) へ置換 | カナ文字列を多用する作品 |
| 14 | `SCR$(X,Y,1)` の戻り値の包み方 | 値 0-3 を持つ 1 文字の文字列 | 配色を読む作品 |
| 15 | スクロール時の配色属性 (2x2 エリア単位なので半エリアずれる) | 文字と一緒に 1 行ずらす | 色付き画面をスクロールする作品 |
| 17 | LOCATE 範囲外のエラー種別 | IL | エラー分岐する作品 |
| 18 | カナ入力方式 (実機は JIS カナ配列) | TAB トグル + ローマ字 2 打 (#31 で確定) | カナ入力を伴う操作 |
| 20 | パッド代替キーの SELECT (spec 案の Shift は sdl2 で取れない) | Space | headless 検証の手順のみ |
| 22 | ひらがな・長音符が文字コード表に無い | ひらがな -> カタカナへ畳み、長音符 -> `-` | 互換より可読性を採った |
| 25b | MOVE が画面端に達したときの挙動 (spec に記述なし) | 座標をそのまま更新し描画側でクリップ | 端で跳ね返る/消える作品 |
| 32 | ERR は「エラー未発生」も 0 を返す (エラー表の No 0 は NF) | 区別しない | ERR はハンドラ内で使う前提なので実害は小さい |
| - | LIST の省略形 | 正式名で出力する (実機の LIST と同じ) | 省略形で書いたリストの見た目 |
| - | 実行速度 | 60 statement / frame の校正ノブ (B5 で実機比較) | タイミング依存の作品 |
| - | 表 A (アニメキャラクタ) の絵柄 | 本プロジェクトの自作キャラクタ。コード位置と役割 (歩き 3 コマ・ジャンプ・敵・爆発など) は spec sec 12 どおりなので DEF SPRITE / DEF MOVE は同じに動くが、絵は本家と別物 | キャラクタの見た目を前提にした作品 (動作には影響しない) |

## 4. 対象外

実装しないと決めたもの。作品がこれらに依存している場合は動かない。

| 項目 | 理由 |
|---|---|
| CALL / マシン語 | 互換レベル L5。6502 コードを走らせる基盤が無い (compat_plan sec 5.6) |
| 直接モードコンソール | エディタ + F5 の RUN で足りるとユーザが判断 (B4 T4-1) |
| LOAD / LOAD? | 直接モードのコマンドであり、プログラム中では意味を持たない (#29) |
| 行エディット系 (LIST / AUTO / DELETE / RENUM / FIND) と GAME | 同上。プログラム中に現れたら IL + ログ 1 行 |
| BACKUP | 電池バックアップ相当。`/home` が永続なので不要 |
| VIEW | BG GRAPHIC 面は BGTOOL 前提で対象外なので、その面に絵が入らない。CLS の代わりに VIEW を使う作品が走ることを優先して no-op |
| BGTOOL | BG グラフィックエディタ。作画は PC 側の画像編集で代替 |
| LOADS / SAVES | テープの BG データ入出力。テープが無い |
| 実機タイミング互換 (L5) | フレーム単位までは合わせるが、命令単位のサイクル一致は追わない |
