# C6b 指示書: 組のボタン「標準」「強め」(ネイティブ版とブラウザ版)

> 状態: 実装中 | 更新: 2026-11-08 | C6 の続き。3 回目の見比べの後にユーザが決めた、デモ用の切り替え口

正は plan.md の「決定事項 (2026-11-08 ユーザ、C6)」。ここには範囲と進め方だけを書く。

## 範囲

1. **値の表を 1 か所に**: 組「標準」と「強め」の 8 つの強さ
   (走査線・格子・にじみ・曲がり・四隅の暗さ・NTSC の色のにじみ・ちらつき・ノイズ)。
   - 標準 = 55・30・30・15・40・0・0・0 (今の既定と同じ。既定の表があるならそれを使う)
   - 強め = 75・50・45・25・55・50・50・50
   ネイティブ版とブラウザ版の両方が同じ表を読む形にする (`hosted/crt/` のように共通の
   置き場があればそこ。生成や写しが要るなら `rake webcrt:test` の古さの検査に足す)。
2. **ネイティブ版**: PC の設定の Window の「画面」のページに「標準」「強め」の
   ボタンを置く。押すと 8 つの強さをまとめて入れ、stepper の表示も合わせ、利用者の
   `[crt]` に覚える (C5 で stepper を変えたときと同じ経路)。**入り切りは変えない**。
   **今の「既定に戻す」は「標準」に名前を変え、隣に「強め」を置く** (ボタンは 2 つ。
   ユーザ決定)。「標準」の働きは今の「既定に戻す」と同じ (8 つの強さを既定へ)。
3. **ブラウザ版**: ページの Display の欄に同じ 2 つのボタン (今「既定に戻す」に当たるものがあれば、
   ネイティブ版と同じく「標準」に置き換える)。押すと 8 つのスライダーと
   保存 (`writeSetting`) を合わせる。入り切りは変えない。
4. 画面の文字は日本語・英語の両方 (既存の言語の切り替えに従う)。「窓」と書かない (Window)。

## 確認

- `rake webcrt:test`、`rake regress`、`rake regress:wl`、`rake regress:screens`
  (画面のページが変わるので基準が変わる場面があれば、変化を report に書き、基準の更新は
  別コミットにする。sim・size の基準は親が更新する)。
- ネイティブ版: headless で「画面」のページを開いてボタンを押し、`comp crt` の状態
  (`state`) が表の値になること、`[crt]` に書かれることを見る。GPD に `.deb` を入れる
  (`~/fm-deb/fm.deb`、`sudo -n apt install -y /home/kishima/fm-deb/fm.deb`)。
  ログインし直しはユーザ。
- ブラウザ版: headless の Chromium でボタンを押し、スライダーと保存の値を見る。
