# ブラウザ版の CRT 風の表示

> 状態: 進行中 | 更新: 2026-10-29 | C1 検収済 (b37e8e2b)、C3 (額縁) 検収済 (a3360e27・bd2baae7)。ブラウザ版の画面を WebGL のシェーダーでブラウン管風に描く選び口を足す。元の絵と画面写しはそのまま

## 目的

- ブラウザ版の画面を、ブラウン管 (CRT) 風の見た目でも描けるようにする。
- Retro の実機は NTSC のテレビに出している。ブラウザ版でその雰囲気を見せられる
  ようにし、ゲームや BASIC のデモの見栄えを上げる。

## 今の作り (出発点)

- `wasm/web/main.js` の `paint()` が、requestAnimationFrame ごとに、絵の通し番号
  (`_fmrb_wasm_frame_seq`) が変わったときだけ wasm の RGBA の絵を 2D の canvas
  (`#screen`) に `putImageData` で写す。
- canvas は絵の大きさ (426x240、高解像度の全画面の間は 640x360) のままで、拡大は
  CSS の `image-rendering: pixelated` が受け持つ (`applyZoom()`)。
- 画面写し (`web_screenshot`、`regress:screens`) は `#screen` を `toDataURL` で読む。
- クリック・タッチの座標は `canvasPos()` が canvas の外枠から割り戻す。

## 方針

- **元の 2D の canvas は残す**。絵の正はそこで、画面写しと回帰の比較は今までどおり
  そこを読む。CRT の表示は、その上に重ねる WebGL2 の別の canvas が受け持つ。
  CRT を選んでいる間は元の canvas を見えなくする (入力は今の canvas の外枠で
  受けるか、重ねた canvas で受けて同じ式で割り戻す)。
- **描くのは絵が変わったときと大きさが変わったときだけ**。テクスチャは絵の
  大きさ (426x240 なら約 400 KB) を送り直す。SharedArrayBuffer の view は
  WebGL に渡せない場合があるので、今の `imageData.data` への写しを使い回す。
- 重ねた canvas は表示の大きさ × `devicePixelRatio` の画素で作る。
- WebGL2 が無い・失敗したときは、今の pixelated の表示に黙って戻す。
- **シェーダーは自前で書く** (数十行)。よく知られた CRT シェーダーは GPL のものが
  多く、ブラウザ版の束に入れると扱いが面倒になる。
- 計算は元の画素を単位にする。拡大の倍率が小さい (2 倍以下・Fit の半端な倍率)
  ときは走査線を自動で弱めて、縞の揺れ (モアレ) を抑える。
- 実機・sim・ネイティブ版は変えない (ブラウザのページだけの話)。

## スコープ

### 効果 (候補)

| 効果 | 中身 |
|---|---|
| 走査線 | 元の 1 行ごとに明暗。明るい画素ほど線が太る |
| 蛍光体の格子 | RGB の縦縞 (アパーチャーグリル) か点の格子 (シャドウマスク) |
| にじみ・光り | 横に少しぼかし、明るい所をにじませる |
| 画面の曲がり・四隅の暗さ | ブラウン管の丸み。入れるならクリックの座標を同じ式の逆で戻す |
| NTSC の色のにじみ | 色の解像度を落とす。Retro の実機の出力に寄せる |
| 時間で動く効果 | ちらつき・ノイズ。入れると毎コマ描くことになる |

### 選び口

- Display の欄に CRT の入り切りと、効果ごとの強さ (走査線・格子・にじみ・曲がり・
  四隅の暗さ・NTSC の色のにじみ・時間で動く効果) の調整を足す。0 にした効果は
  計算しない。選んだものは今の設定と同じ仕組み (`writeSetting`) で覚え、
  「既定に戻す」で戻せる。
- `?look=crt` の URL の指定で、CRT を既定の強さで入れる (デモの配布用)。
- 時間で動く効果の既定は 0 (入れると毎コマ描くので)。

## 受け入れ条件 (案)

- 既定の見た目のとき、ページの表示も画面写しも今と 1 画素も変わらない。
- CRT を選ぶと、3 倍の拡大で走査線と格子が見え、426x240 の英字 (6px) が読める。
- 高解像度の全画面 (エディタ) との行き来で、表示が崩れない・大きさが跳ねない。
- クリック・タッチ・ホイールの位置がずれない (画面を曲げたときも、曲がった絵の上で
  押した所の画素に届く)。曲がりで絵の外になった所の押下は捨てる。
- 絵が変わらない間は WebGL の描画が走らない (時間で動く効果を選んだ場合を除く)。
- WebGL2 を切ったブラウザで、今の表示に戻る。
- `rake regress:screens` が通る。

## 決定事項 (2026-10-29 ユーザ)

- **既定は今の見た目のまま**。CRT は Display の欄か `?look=crt` で選ぶ。
- **画面の曲がりと四隅の暗さは最初 (C1) から入れる**。クリック・タッチの座標は
  シェーダーと同じ式の逆で戻す。
- **高解像度の全画面 (エディタ、640x360) の間も同じにかける**。強さは利用者が
  調整で決める。倍率が小さいときに走査線を弱める自動の調整は、どの解像度でも
  同じ式で効かせる。
- **効果ごとに強さを調整できる**ようにする。

## 額縁 (C3、2026-10-29 ユーザ決定)

- 全画面でないとき、画面の周りに額縁を付ける。Sharp は液晶モニタ風 (細い枠、
  小さなスタンドと電源のランプ)、CRT はブラウン管テレビ風 (木目か黒い樹脂、
  つまみ、スピーカーの網) と CRT モニタ風 (ベージュか灰色の分厚い枠、電源の
  ボタン) を選べる。
- **既定で出す** (ユーザ決定)。開いたときから Sharp は液晶モニタ風になる。
  上の決定事項の「既定は今の見た目のまま」はこの点だけ改める。Display の欄で
  額縁を切れる。
- **見た目だけ**。つまみ・ボタンは押しても何も起きない。
- **canvas の外に置く**: `#screen-box` の周りに HTML・CSS (要れば SVG) で組む。
  canvas には描かない。画面写し・回帰の比較 (`#screen`)・クリックの位置の計算・
  シェーダーの重さは変わらない。枠の内側の縁への画面の光の映り込みは、まず CSS の
  影で作る。
- 画像は使わず自前で描く。実在の製品・会社のロゴは入れず、名札は「Family mruby」。
- 全画面と、狭い画面 (スマホ) では出さない。Zoom の計算 (Fit など) は額縁の分を
  差し引く。

## 結果 (C3、2026-10-29 検収済)

- `#frame` が `#screen-box` を包み、CSS だけで描く (画像なし、canvas に描かない)。
  Frame の選び口は「On (CRT: a TV set)」(既定)・「On (CRT: a monitor)」・「Off」。
  `?frame=tv|monitor|off` は保存しない。つまみ・ボタンは `pointer-events: none`。
- 全画面と、1 倍に額縁が入らない狭い画面では出さない (Fit で幅 液晶 470・テレビ
  588・モニタ 522 px 未満)。額縁の足し分はページで測る (`frameExtra`)。
- 既定の倍率と Fit は額縁を差し引いて決めるが、**スタンドは数えない** (ユーザ決定)。
  3 倍になる表示領域の高さは 液晶 810・テレビ 846・モニタ 860 px 以上 (額縁なしは 782)。
- Zoom を選んだことがない人が Look・Frame を変えると、**倍率を選び直す**
  (ユーザ決定、`rechooseZoom()`)。選んだ倍率はそのままで、入らなければ額縁が消える。
- 残件: 実際の Chrome (dpr が 1 でない)・スマホ・本当の全画面での見え方と、木目・
  つまみの出来の目視。

## 結果 (C1、2026-10-29 検収済)

- 表示は `wasm/web/crt.js` (WebGL2) が `#screen` の上に `pointer-events: none` の
  canvas を重ねて描く。`#screen` は隠さず、入力とフォーカスの扱いは変えていない。
- 格子はアパーチャーグリル (3 倍で縞がちょうど 1 表示画素ずつに乗り、文字を
  崩さない)。曲がりの式は「表示→絵」の向きで JS とシェーダーが同じ式を持ち、
  クリックはそのまま使う。逆はニュートン法 (試験 `rake webcrt:test`、`rake test`
  に入っている)。
- 仮の既定の強さ (0〜100): 走査線 55、格子 30、にじみ 30、曲がり 15 (C1 の 40 はユーザの目視で過剰、2026-10-29 に下げた)、四隅の暗さ 40。
- C1 の後の修正: `canvas { display: block }` が `hidden` を打ち消し、Sharp 表示でも空の
  重ねる canvas (黒) が `#screen` の左上に残っていた (ユーザの目視で発見。`#screen` を
  撮る確認では見えない)。`#crt-view[hidden] { display: none; }` で直した。
- 描くのは絵が変わったときだけ (1278x720 で 1 回約 2.7 ms)。WebGL2 が無いときは
  今の表示に戻る。`?look=crt` は設定を保存しない。
- 駆動の道具 (ルートの tools/fmrb_web.rb) に view・crt・zoom・dom の命令を足した。
- 残件: ブラウザの全画面とスマホの実タッチの目視、Safari、既定値の詰め・NTSC の
  色のにじみ・時間で動く効果 (C2)。
