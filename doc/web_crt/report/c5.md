# 報告 C5: ネイティブ版の CRT の選び口 (設定の画面)

> 状態: 完了 (GPD でユーザ確認済) | 更新: 2026-11-07 | PC の設定の Window に「画面」のページを足した。CRT の入り切りと 5 つの強さをすぐ効かせ、利用者の /etc/system_conf.toml の [crt] に覚える。次のセッションではそれが --set に勝つ。CRT を出せない所ではメニューの項目もページも出さない

指示書は [../instruction_c5.md](../instruction_c5.md)、計画は [../plan.md](../plan.md)。

### 保存の形

```toml
[crt]
# the CRT look chosen in the settings window (doc/web_crt); beats the session file's --set
look = "crt"
scanline = 55
mask = 30
glow = 30
curve = 25
vignette = 40
```

ファイルの最後に置く。前の `[crt]` (見出しから次の見出しまで) は取り除き、ほかの行はそのまま残す。
書き方はデスクトップの Config と同じで、横に書いてから rename する。Config の保存 (`cfg_write`) と
カーネルの 1 行の書き換え (`fmrb_kernel_save_conf_value`) は表の区切りを見ているので、末尾の
`[crt]` に上の階層の鍵が紛れ込むことはない。

## 確認

### GPD の GPU で headless (ユーザの画面には出していない)

C4 と同じく、.deb を `/tmp/fmx` に展開し、HOME を `/tmp/fmx-home` にして動かした
(1080x1920、rotate 270、scale 3)。

- メニューに「Display...」が Bluetooth の下に出て、押すと設定の Window が Display のページで開いた
  (`the settings window: pid 4, 280x200 at (180,86), the Display page`)。
- 「CRT」を押すとすぐ CRT になった。続けて曲がりの「>」を 2 回押すと、その曲がった絵の上で
  押した所の釦に届き、`comp crt` が curve=25 を返した。1 秒後に `[crt]` が書かれた
  (上の形)。表示は「次のセッションでも使います」。
- 「既定に戻す」で強さが 55・30・30・15・40 に戻り、CRT は入のまま (`look=crt`)。
- **次のセッション**: HOME を残したまま `--set display.look=sharp --set display.crt_glow=90` で
  起動し直すと、`native: the CRT look as chosen in the settings (... [crt])` の 1 行が出て、起動の
  1 行は `look=crt(55,30,30,15,40)` になった (利用者の選択が `--set` に勝つ)。
- **pixman**: 同じ HOME (`[crt]` は crt) で `WLR_RENDERER=pixman` にすると、CRT は理由の 1 行で
  sharp のまま。メニューに「Display...」は出なかった。

- **Config との同時の書き込み**: Config を開いたまま、外から `[crt]` の curve を 77 に書き換えて
  Config で保存した。`[crt]` は 77 のまま残った (Config は保存のときに読み直す)。

### 回帰

- `rake regress`: host 21/21、描画の記録 213/213 (Config の変更の後にも流した)。
  `native:test` は機種の定義 555 項目 (`[crt]` の読みを含む)、comp 154 項目 (受け渡しを含む)。
- `rake regress:wl`: standard・mruby とも全部通過 (wl_check 27/27 ずつ、settings 20/20 ほか)。
  pixman なので「画面...」は出ず、今の画面と変わらない。
- `rake regress:screens`: 33/33 (modern 11、retro 9、web 6、native 3、native-keys 4)。sim と
  ブラウザ版のビルドに app.c と Config の変更が入った形で、絵は変わらない (基準の更新なし)。
  graphics-audio が esp32 向けの build のままだったので、`rake clean_all` して `build:linux` した。

## 見立てと違った点

- C4 では、描画器が GLES でないことを、CRT を頼まれたときにしか確かめていなかった。それだと
  pixman で sharp の人にも「画面」が出てしまうので、起動のときに必ず確かめるように変えた
  (ログの 1 行は今までどおり、CRT を頼まれたときだけ)。

## ユーザに確かめてほしいこと (GPD の画面)

.deb (3.0.0+git14.5caabc9d) はパスワード無しの apt で入れてある。ログインし直してから:

1. デスクトップのメニューに「画面...」(英語なら "Display...") があり、押すと設定の Window が
   「画面」のページで開くか。文言・並びが読みやすいか。
2. 「くっきり」と「ブラウン管」の切り替え、5 つの強さの「<」「>」が、押すたびにすぐ画面に効くか
   (曲がった絵の上の釦も押せるか)。
3. 「既定に戻す」で強さが戻り、ブラウン管のままか。
4. 好みの強さにしてからログインし直すと、その強さで始まるか (`/etc/default` は CRT を指定した
   ままでも、画面で「くっきり」を選んだら、次も「くっきり」で始まるか)。

いまの利用者の `/etc/system_conf.toml` にはまだ `[crt]` が無いので、最初のセッションは
`/etc/default` の `--set display.look=crt` で始まる。

## ユーザの確認 (2026-11-07、GPD MicroPC2)

ログインし直して、次の 4 つが期待どおりだった (ユーザ)。

1. メニューの「画面...」で設定の Window が「画面」のページで開き、文言と並びが読める。
2. くっきり / ブラウン管の切り替えと強さの「<」「>」が、押すたびにすぐ効く。曲がった絵の上の釦も押せる。
3. 「既定に戻す」で強さだけが戻り、ブラウン管のまま。
4. 画面で選んだ値で次のセッションが始まる (`/etc/default` が CRT のままでも、画面で選んだ方が勝つ)。
