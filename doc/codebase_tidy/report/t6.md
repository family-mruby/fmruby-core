## 2. 試験用アプリを配布物から外す

置き場 (`flash/app/test/`) は変えない。開発のビルド・sim・ネイティブ版の開発ビルド・`rake wasm:dist`・回帰の道具は今どおり持つ。

| 配布物 | 外し方 |
|---|---|
| 端末のリリースのイメージ (Web Installer が配る) | `FMRB_RELEASE=1 rake build:esp32` で `-DFMRB_RELEASE=ON`、top-level CMakeLists.txt が staging から `app/test` を消す。rake は ON/OFF を毎回渡す (CMake のキャッシュに残らないように)。ルートの release-installer.yml の `env:` に `FMRB_RELEASE: "1"` |
| ブラウザ版の公開 (`rake wasm:site`・`wasm:deploy`) | 先に `wasm:release_bundle` が `FMRB_RELEASE=1` にし、`wasm:webflash` が `flash/app/test/` を束ねない。この後の wasm/build/dist は公開用なので、回帰の道具には `rake wasm:dist` を流し直す |
| ネイティブ版の .deb (`native:root`) | いつも外す (回帰は開発ビルドで動く) |

ついでに、`config/storage_exclude_<target>.txt` が空の target (既定の S3) に当たっていなかった (t0 6.2 の注) のを、空を `naryav3` と読むようにした。既定のビルドでも NARYA v3 の除外 (Modern だけの麻雀・walk_scroller) が効く。
