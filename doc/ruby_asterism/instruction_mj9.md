# MJ9 指示書: 局の始まりの表示、結果は全員の OK、役を 1 つずつ

> 状態: 指示 | 更新: 2026-10-18 | 外の友だちと遊んで出た 3 点: 局の始まりに「東N局 M本場」を 2 秒見せる、結果は人間全員の OK を待つ、役を 1 秒ずつ出して最後に点数

前提: asterism-games の麻雀の卓 (`app/asterism_games/mahjong/table.rb`: status "play" / "result" / "over"、`result_ms` (8 秒) で次の局、`next_now` (人間の誰か 1 人の「次へ」で進む)、配牌から親の最初の自摸まで、away の判定、view の鍵)、0.15.0 (GS8 で種類ごとの AI の上限を足した、未タグ)、README の麻雀の節。fmruby-core の麻雀アプリ (`flash/app/game/mahjong/`: 640x360 は mahjong.app.rb・mahjong_panels.rb・mahjong_640.rb、1280x720 は mahjong_xl.rb、結果の箱 draw_result / xl_draw_result、A_NEXT のボタン、時計 draw_clock、`tools/mahjong_overflow/` のはみ出し検査 `rake mahjong:overflow`)、`rake mahjong:up` (zenohd・ゲームホスト・ページの手元の一式)。

言葉: 文書は常体、「確かめ」ではなく「確認」。コードのコメントと asterism-games の文書は英語。画面の言葉は日本語 (麻雀アプリの決まり)。

## 1. 決まっていること (2026-10-18 ユーザ、選択形式)

1. **局の始まり**: 配牌のあと、**ゲームホストが 2 秒待つ**。そのあいだ全員の画面に「東1局 0本場」(局と本場) を大きく出す。この 2 秒は誰の持ち時間も減らさない (親の最初の番の時計はこのあとから)。CPU・AI もこの 2 秒は動かない。
2. **結果は人間全員の OK**: 局の結果 (和了・流局) のあと、**つながっている人間全員が OK (今の「次へ」) を押したら**次の局へ。途切れた (away) 人は数えない。押さない人がいても、**役のカウントが終わってから 10 秒で自動で進む**。人間がいない卓 (CPU・AI だけ) は今どおり。終局 ("over") の扱いは今のまま。
3. **役を 1 つずつ**: 結果の箱で、役を **1 秒に 1 つ**ずつ出し、全部出たら**最後に点数**を出す。出している途中にクリックかキーを押すと、**残りを一度に出す** (その次の押下で OK)。

## 2. 決めごと (親が決めた形。変えるなら止まって返す)

- **カウントの長さは両側の共通の決まり**: 和了 1 人ぶんの長さ = 役の行の数 × 1 秒 + 点数の 1 秒。ダブロン・トリロンは和了者ごとに続けて (合計)。流局 (テンパイの表示など役の無い結果) は 1 秒。ゲームホストはこの決まりで「カウントが終わる時刻」を計算し、そこから 10 秒を自動で進む時刻にする。画面は同じ決まりで 1 つずつ出す (飛ばしても、ゲームホストの時刻は変わらない)。決まりはゲームホストの README に書く。
- **OK した人**: view に、OK を待っている人間の席 (か、OK した席) と、自動で進む時刻 (残り秒) を入れる。画面は「OK を待っています (2/3)」と残り秒を出す。自分が押したら自分の OK ボタンは「待っています」に変わる。
- **互換**: 新しいゲームホストと古い画面 (今の Tab5 の flash、公開中のブラウザ版) でも遊べること。古い画面の「次へ」はその席の OK として数える。古い画面は 1 つずつの表示もしない。新しい画面と古いゲームホスト (0.14.0) の組み合わせでも落ちないこと (view に新しい鍵が無ければ今どおり)。

## 3. 作るもの

2. 結果のあとの全員の OK と、カウントの長さ + 10 秒の自動進行。`result_ms` の意味の変更 (今の 8 秒の固定はやめる) は README と CHANGELOG に書く。
3. 試験: 2 秒のあいだ時計が減らない・CPU が打たない、全員の OK で進む・away は数えない・誰も押さないと (カウント + 10 秒) で進む・役の数でカウントが変わる・ダブロン・流局・人間のいない卓は今どおり・古い「次へ」が OK として数えられる。
