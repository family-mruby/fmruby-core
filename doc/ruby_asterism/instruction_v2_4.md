# Asterism V2.4 指示書: 開いた機械を囲む枠と、出入口の IP の扱い

> 状態: 指示 | 更新: 2026-10-11 | asterism-console の網の図で、開いた ROS 2 の機械 (V2.3 の塊) のメンバーを囲む四角を描く。枠は飾りの絵で、メンバーが動くたびに描き直す。あわせて、docker の公開ポートの出入口の IP から来た ROS 2 のノードを畳まないようにする

前提: plan.md の V の表 (V2.4 の行)、report/v2_1.md (入れ子の箱を採らなかった理由)、report/v2_3.md (塊の組み立てと、出入口の IP の穴)、asterism-console の docs/v2_3.md、`lib/bridge/groups.rb`、`app/javascript/controllers/console_controller.js`。

## 1. 決まっていること (2026-10-11 ユーザ)

1. **開いた機械の枠**:
   - 開いた機械のメンバーを囲む四角を描く。見出しに機械の名前 (V2.3 の名前、無ければ IP)。
   - 枠は **cytoscape の入れ子 (親子の箱) にしない**。配置の計算に関わらない飾りとして描く (例: ノードの後ろの層に描く四角、または位置を計算で決める飾りのノード。方法は選んで docs に書く)。
   - **メンバーは自由に動かせる**。メンバーが動く・配置が変わる・メンバーが増減するたびに、枠をメンバーを囲む形に描き直す (少しの余白をつける)。
   - 開いた直後と「Lay out again」のときは、メンバーがまとまって置かれるように配置に条件を付ける (例: fcose の相対配置の条件、またはメンバーを先に近くに置いてから全体を回す)。ほかのノードが枠の中に入り込みにくくする。入り込みを完全に防ぐ必要はない。
   - 枠の見出しまたは枠をクリックすると、機械の詳細 (V2.3 のもの、「Fold」つき) が出る。
   - 巻き戻しの図も同じ。
2. **出入口の IP**:
   - docker の公開ポートを通って来た接続は、どれも docker のネットワークの出入口の IP (例: 172.20.0.1) に見える。この IP から来た ROS 2 のノードは、機械が分からないものとして**畳まない** (1 つずつ今のまま出す)。
   - 出入口の IP の見分け方を決める (例: bridge が zenohd のコンテナのネットワークの出入口を知る方法、設定で与える方法、zenohd の管理用の空間から分かるか)。決め方と、決められない環境での扱いを docs と report に書く。
   - ノードの詳細には、そのアドレスが出入口のもので機械が分からないことを書く。

## 2. 受け入れ条件

1. MuJoCo の塊を開くと、10 個のメンバーを囲む四角が名前つきで出る。メンバーを 1 つ動かすと、枠がそれを囲むように描き直される。畳むと枠は消える。
2. 開いた直後と「Lay out again」で、メンバーがまとまって置かれる。
3. 出入口の IP から来た ROS 2 のノードが 2 つ以上あっても畳まれない。実際に確かめる (例: P4-Nano の ROS 2 のアプリと、sim の ROS 2 のアプリか CRuby の ROS 2 の例を、LAN 側の 7447 から入れる。LAN 側から入る経路が作れなければ、テストと理由で示す)。
4. 巻き戻しの図も同じ。
5. 既存のテストが通り、出入口の扱いにテストを足す。
6. 変更前と変更後の写しを scratchpad に置き、report で比べる。

## 3. 範囲・決まり

- **触ってよいもの**: asterism-console (main にコミット・push してよい)、fmruby-core の `doc/ruby_asterism/report/v2_4.md` (develop にコミットのみ、push しない。**コミットは必ずファイルを指定する。`git commit -a` は使わない**)。親リポジトリの compose は変えない (変える必要が出たら案を書いて返す)。
- **触らないもの**: gem、ファーム、`.env`、台帳の試しの登録、機械の名前 `mujoco`。
- **機体**: P4-Nano を使ってよい (親が IP を渡す。ミュート中、`serial_start` は呼ばない)。
- **終わったら**: 親のデモ (zenohd の LAN 向け、MuJoCo、sim の asterism_demo、rails を 127.0.0.1:3000 で、bridge、P4 のアプリ) を新しいコードで動いている状態に戻して返す。
- **止まる条件**: ここに書いていない見え方の選択が要るとき。案を写しつきで返す。
- **report**: Japanese plain style (常体)。書くこと: 枠の描き方、まとめて置く条件、出入口の IP の見分け方、受け入れ条件の結果、残った課題。
