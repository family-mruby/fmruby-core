# MJ11 指示書: 麻雀の効果音・ジングル、BGM の口、音の切替

> 状態: 指示 | 更新: 2026-10-18 | 麻雀アプリは今、音を一切鳴らさない。内蔵の音源 (APU) で効果音と声の代わりのジングルを鳴らし、BGM を流す口と、BGM・効果音の入り切りを作る。BGM の曲そのものは別に探している (決まったら差し込む)

前提: fmruby-core の麻雀アプリ (`flash/app/game/mahjong/`、640x360・1280x720・426x240)、`FmrbAudio` (`lib/add/picoruby-fmrb-app/mrblib/fmrb-audio.rb`、`sig/fmrb_audio.rbs`、`flash/help/FmrbAudio.*.md`: `note_on(ch, freq, volume, duty, sweep)` / `note_off` は APU の SUB、`play(path)` (NSF) と `play_slot(slot, instance: 0)` (FMSQ) は MAIN、`play_wav` は WAV 1 つ)、`tool/mml2fmsq.rb`、`FmrbMidi::MmlPlayer` は SUB を使う (BGM には使わない)、`/home/mahjong.toml` (アシストと名前を保存している)、ブラウザ版の音 (最初の操作まで無音)、`doc/reference/audio_output.md`。MJ9 (局の始まりの表示、結果の役を 1 秒ずつ、OK) が入った後の develop。

言葉: 文書は常体、「確かめ」ではなく「確認」。コードのコメントは英語。画面の言葉は日本語。

## 1. 決まっていること (2026-10-18 ユーザ、選択形式)

1. **BGM**: 配布してよい曲を別に探している。この段では**曲を流す口**だけ作る (NSF か FMSQ を APU の MAIN で流す。場面: 待ち合わせ・対局中、任意で緊張の場面)。曲が無いときは鳴らさない。曲の置き場所と場面との対応は設定 (アプリの定数か小さな設定ファイル) で差し替えられること。
2. **声の代わりに短いジングル**: リーチ・ポン・チー・カン・ロン・ツモ (と九種九牌・流局) ごとに、内蔵の音源で短い合図を鳴らす。後から声 (WAV) に差し替えられる作り (合図ごとに「音源の合図か WAV か」を選べる口)。
3. **効果音**: 打牌・ツモ・自分の番、局の始まり (局の名前の表示)・結果の役のカウント (役が 1 つ出るごと、最後の点数)、終局のファンファーレ (順位ごとの短い曲)。持ち時間の警告は入れない。
4. **入り切り**: アプリに「BGM 入/切」と「効果音 入/切」(ジングルは効果音に含める)。待ち合わせの画面 (と卓の一覧) に置き、自分の端末に記憶 (`/home/mahjong.toml`)。既定は両方入。端末全体の音量・ミュートは今のまま (アプリは触らない)。

## 2. 作るもの

1. 音の小さな部品 (例 `mahjong_sound.rb`): 効果音・ジングル・ファンファーレの定義 (音符の並び: 周波数・長さ・音色)、鳴らす (APU の SUB の 2 つの矩形波と三角波・ノイズの使い分け、重なったときの扱い)、BGM の開始・停止・場面の切替、入り切りの状態と保存。`on_update` を重くしない (毎回の描画に音の処理を足さない。鳴らす合図は出来事のときだけ)。
2. 出来事との結び付け: 自分の打牌・ほかの人の打牌 (音を変えるか同じでよいかは任せる)・ツモ・自分の番になった・鳴きの宣言 (view の声の表示 `shout` が出たとき)・局の始まり (MJ9 の `in`)・結果の役が 1 つ出るとき・点数・終局 (順位)。観戦と振り返りでは鳴らすか: 観戦は効果音を鳴らしてよい、振り返りは操作で進めるので打牌の音だけでよい (任せる。おかしければ止まって返す)。
3. 待ち合わせの画面に入り切りの 2 つのボタン (キーの表記は `[ ]`、MJ8 以降の決まり)。はみ出し検査 (`rake mahjong:overflow`) に場面を足し、失敗 0。
4. ブラウザ版では最初の操作まで音が出ない (ページの決まり)。アプリ側で特別なことはしなくてよいが、最初の操作の前に鳴らそうとしても落ちないこと。
5. アプリを閉じたとき (`stop`・Ctrl+Q・閉じるボタン) に BGM と鳴っている音を止める。
6. 曲が無いときの BGM の口の試し: 手元の短い MML (`tool/mml2fmsq.rb` で FMSQ にした仮の曲。配布物には入れない、または入れるなら自作でライセンスの問題が無いこと) で、場面の切替と停止が動くことを確認する。

## 3. 受け入れ条件

1. はみ出し検査が失敗 0。
2. 手元の一式 (`rake mahjong:up`、ブラウザ版、人間 1〜2 + CPU) で、効果音・ジングル・局の始まり・役のカウント・終局のファンファーレが鳴ることを、音の数値 (ルートの CLAUDE.md「音の確認」: `ruby tools/fmrb_audio_probe.rb` は sim の共有メモリを読む。ブラウザ版なら worklet の出力を確かめる手段を工夫するか、sim で同じ出来事を起こす) で確認する。音の善し悪し (官能評価) はユーザが確認する。
3. 入り切りが効き、アプリを開き直しても記憶されている。アプリを閉じると音が止まる。
4. Tab5 には触らない (親が実機で確認する)。

## 4. 範囲・決まり

- **触ってよいもの**: fmruby-core の `flash/app/game/mahjong/`、`tools/mahjong_overflow/`、report。develop に直接コミットしてよい (親は待つ)。仮の曲を足すなら、自作でライセンスの問題が無いものだけ (ASSETS.md の流儀に合わせて記す)。
- **触らないもの**: FmrbAudio などの C・mrbgem (足りない口があれば止まって返す)、asterism-games・asterism-console、VPS、GitHub の設定、Tab5 (シリアル・WiFi)。
- 牌のシート (`tiles_hand.bmp` / `tiles_river.bmp`) はユーザの手書きを含む: 触らない。
- 外の AI の API を呼ばない。push・タグはしない。`git commit -a` は使わない。コミットの末尾は `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。件名は `game: ...`。
- 起こしたもの (mahjong:up の一式、ブラウザ、sim) は名前で止めて片付ける (sim は sim_down)。docker の prune はしない。
- **止まる条件**: 1 章に無い仕様の選択が要る、FmrbAudio に足りない口がある (例: SUB の音色の制御が足りない)。止まったら report に、ユーザが選べる形の選択肢 (推奨を先頭に) を書いて返す。
- **report** (`doc/ruby_asterism/report/mj11.md`、常体): 音の定義の一覧 (出来事・音色・長さ)、BGM の口の形と曲の差し込み方、入り切り、受け入れ条件の結果 (音の数値)、残ったこと。
