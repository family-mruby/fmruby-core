# OP1 指示書: オセロの卓のアプリで、右の欄の文字が窓からはみ出ないようにする

> 状態: 指示 | 更新: 2026-10-24 | Tab5 (Modern、426x240 の画面に 372x222 の窓) でオセロの卓のアプリを動かしたところ、右の欄の長い文字が窓の右端で切れた (2026-10-24 親が確認、ユーザが直すと決定)。名前は欄の幅に収めて後ろを「…」に、案内の文は 2 行に折り返す

言葉: 文書は常体、「確かめ」ではなく「確認」。コードのコメントは英語。

## 1. 見えたこと (Tab5、2026-10-24)

- 席の行: 「fmruby-a1b2c3* (自分)」が「fmruby-a1b2c3*(自分」までで切れた (閉じかっこが窓の外)。
- 待ち合わせの案内: 「席に着いた (色は始めるときに決まる)」が「席に着いた (色は始めるとき」までで切れた。
- `draw_panel` (flash/app/game/othello/othello.app.rb) は `fit(s, n)` (n = `@pw / 6`、全角 = 2 桁) で詰めているのに切れている。**まず原因を突き止める** (`@pw` の計算 (`@x0 + uw - @px - 2`) が窓の内側の幅より大きい、全角の字の幅が 12 px でない、`text` の座標系の取り違え、など)。推測で数値をずらして合わせない。

## 2. 作るもの

1. 右の欄のすべての文字 (卓の名前と状態、席の 2 行、手番・終局・案内・最後の手・@note) が、欄の右端 (窓の内側) を越えないようにする。原因を直したうえで、Modern の窓と Retro の全画面 (320x240、小さい盤) の両方で収まること。
2. **席の行**: 名前が長いときは名前の側を詰めて末尾に「…」を付け、印 (`*`、` [AI]`、` (自分)`、` 途切れ`) と石の数は必ず全部出す。
3. **待ち合わせの案内** (「席に着いた (色は始めるときに決まる)」「観戦中: 空いた席に座れる」) は、収まらなければ 2 行に折り返す。続く「卓の主 (*) が始める」などの行は、その分下げる (ボタンと重ならないこと)。他の行も、収まらないものは同じ扱い (折り返すか「…」か) にしてよいが、文言は変えない。
4. 文言・ボタン・キー・色は変えない。

## 3. 確認

- Linux sim で、Modern (426x240 の窓) と Retro (320x240 の全画面) の両方の画面を撮り、席に着いた・Jev を入れた・対局中・終局の 4 つの場面で、欄の文字が窓の内側に収まっていることを report に (画像のパスも)。sim でホストに繋ぐ方法は doc/ruby_asterism の既存の report (GS2・GS13 など) を読む。手元でゲームホストを立てる (`rake mahjong:up` など) のはよい。**VPS には繋がない**。
- 名前が長い場合 (例: 20 字の名前) も、印と数が全部見えることを確認する (試験用の名前の与え方は report に)。
- `rake mahjong:overflow` (アプリの検査) と `rake test` が通る。標準構成の sim 検証には、エディタを 1 回起動して 1 打鍵するところまで含める (fmruby-core/CLAUDE.md)。

## 4. 範囲・決まり

- **触ってよいもの**: fmruby-core (develop) の `flash/app/game/othello/othello.app.rb` と report。sim を使うための一時的な設定は終わったら元に戻す。
- **触らないもの**: asterism-games (ホスト)、ほかのアプリ (麻雀の卓も直さない。同じ切れがあれば report に書くだけ)、Tab5・シリアル・VPS・ブラウザ版、sdkconfig。
- push・タグはしない。`git commit -a` は使わない。件名 `game:`、本文英語、末尾 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。fmruby-core の doc (この指示書・report) はコミットしない (親がする)。
- 終わったら sim を片付ける (sim_down)。build/ は Linux のまま残ってよい。
- **止まる条件**: 原因が窓の大きさや描画の基盤 (FmrbApp・gfx の側) にあって、アプリの外を直す必要がある。文言を変えないと収まらない。ボタンと重ならずに折り返す余地が無い (Retro の全画面など)。
- **report** (`doc/ruby_asterism/report/op1.md`、常体): 切れていた原因、直し方、各画面の確認結果と画像、長い名前の試験、麻雀の卓で同じ切れがあるか、コミット。
