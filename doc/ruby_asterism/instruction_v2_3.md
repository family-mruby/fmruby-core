# Asterism V2.3 指示書: ROS 2 のノードを機械ごとに畳む

> 状態: 指示 | 更新: 2026-10-11 | asterism-console の網の図で、同じ機械 (接続元の IP が同じ) から来た ROS 2 のノードを 1 つの点に畳む。既定で畳み、クリックで開く。名前は既定で IP、ユーザが名前を付けられる (名前はメンバーのノード名の組で覚える)

前提: plan.md の V の表 (V2.3 の行)、report/v2_1.md (箱で囲む案を採らなかった理由)、report/v2_2.md、asterism-console の docs/v2.md・v2_1.md・v2_2.md、`lib/bridge/connections.rb`・`lib/bridge/marks.rb`・`lib/bridge/graph.rb`、`app/javascript/controllers/console_controller.js`。

## 1. 決まっていること (2026-10-11 ユーザ)

- ROS 2 は「どの機械・どのプロセスか」という親の情報を運ばない。手掛かりは接続 (Session) のアドレスの IP。
- **同じ IP から来た ROS 2 のノードが 2 つ以上あれば、1 つの塊にする**。1 つだけなら塊にしない (今のまま)。Asterism のノードは対象外 (自分の入れ子がある)。
- **既定で畳む**: 塊は 1 つの点 (例: 「192.0.2.5 (ROS 2 ノード 10)」) として描く。トピックの矢印は塊の点から出入りする (塊の中どうしの矢印は畳んでいる間は描かないか、塊の点の自己ループにしない。読みやすい方を選び docs に書く)。サービスの数の印などは合算して出す。
- **クリックで開く** (詳細の欄の「開く / 畳む」など)。開いた状態では今の描き方に戻る。V2.1 で箱で囲む案は図を壊したので、開いたときも箱で囲まない。開閉の状態はブラウザに覚えさせてよい。
- **名前**:
  - 既定は IP。
  - ユーザが塊に名前を付けられる (詳細の欄から)。名前は console の DB に置き、利用者全員で共有する。付けられるのは管理者だけでよいか、全員か、は既存の権限の作り (W2) に合わせて決め、docs に書く。
  - 名前は **IP ではなくメンバーのノード名の組** に結び付けて覚える (IP は変わりうるため)。新しく現れた塊のメンバーが、名前を付けたときの組と十分に重なれば (例: 半分以上が一致)、その名前で出す。重なりの決め方は report に書く。
  - 名前を消す・付け直すこともできる。
- **記録の巻き戻し**の図も同じ畳み方にする (名前は今の DB のものを使う)。
- 凡例を合わせて直す。

## 2. 受け入れ条件

1. ROS 2 の台車 (S1 の compose) を上げた状態で、MuJoCo のコンテナのノードが 1 つの点に畳まれ、名前は IP で出る。P4-Nano の ROS 2 のアプリ (1 ノード) は今のまま 1 つで出る。
2. 塊を開くと今の描き方になり、畳むと戻る。トピックの矢印が塊の点から出入りする。
3. 塊に `mujoco` と名前を付けると、その名前で出る。MuJoCo のコンテナを作り直して (IP が変わって) も、同じ名前で出る。IP が変わったことは、実際にコンテナの IP を比べて確かめる (変わらなければ、変わる作り方を試すか、テストで確かめる)。
4. 巻き戻しの図も同じ。
5. 既存のテストが通り、塊の組み立てと名前の照合にテストを足す。
6. 変更前と変更後の写しを scratchpad に置き、report で比べる。

## 3. 範囲・決まり

- **触ってよいもの**: asterism-console (main にコミット・push してよい。DB の移行を足してよい)、fmruby-core の `doc/ruby_asterism/report/v2_3.md` (develop にコミットのみ、push しない。**コミットは必ずファイルを指定する。`git commit -a` は使わない** (`.env` にユーザの手元の変更がある))。
- **触らないもの**: gem、ファーム、`.env`、台帳の試しの登録。
- **機体**: P4-Nano を使ってよい (親が IP を渡す。ミュート中、`serial_start` は呼ばない)。
- **終わったら**: 親のデモ (zenohd の LAN 向け、MuJoCo、sim の asterism_demo、rails と bridge、P4 のアプリ) を、新しいコードで動いている状態に戻して返す。
- **止まる条件**: ここに書いていない見え方の選択が要るとき。案を写しつきで返す。
- **report**: Japanese plain style (常体)。書くこと: 塊の組み立て (どこで何を作るか)、名前の照合の決め方、受け入れ条件の結果、残った課題。
