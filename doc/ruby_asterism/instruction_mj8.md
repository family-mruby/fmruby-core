# MJ8 指示書: 麻雀の画面の直し (鳴きの牌を画像で、中央の文字、待機のガイド、同じ牌の印、タイトル「ヒデ雀」)

> 状態: 指示 | 更新: 2026-10-18 | 卓の麻雀のアプリの見た目を直す。鳴きのボタンの牌を画像に、中央の状態の灰色の文字を白に、待機中のガイドを今の状況の説明に、捨てる牌を選んでいるときに同じ牌へ印を、起動時にタイトル画面「ヒデ雀」を出す。追加 (6-8): 640x360 のボタンを右へ、自分の風と点数を左下へ、鳴いた牌の横向き

前提: report/mj5.md・mj6.md・mj7.md・gs5c.md (1280x720 と 640x360 の卓、はみ出しの検査 `rake mahjong:overflow`、発声と持ち時間、待ち合わせ)、卓の麻雀のアプリ (fmruby-core flash/app/game/mahjong/ の mahjong.app.rb・mahjong_xl.rb・mahjong_panels.rb・mahjong_watch.rb、牌の画像 tiles_*.bmp と large/、mahjong.app.toml)。

言葉: 文書は常体、「確かめ」ではなく「確認」。fmruby-core のコードのコメントは英語。

## 1. 決まっていること (2026-10-18 ユーザ、選択形式)

1. **鳴きのボタン (ポン・チー・カン、チーの選び方が複数ならそれぞれ) の牌を、文字ではなく牌の画像で出す**。1280x720 と 640x360 の両方。
2. **中央の状態表示の灰色の文字を、普通の白など見やすい色にする** (重要な情報なので)。
3. **待機中のガイドは、今の状況を書く**: 「いまはできない」のような分かりにくい文ではなく、「南家 (Claude) の番です」「ほかの人の答えを待っています」のように、今何を待っているかを書く。自分の番のときだけ操作の案内を出す。鳴きの最中に誰が鳴けるかをほかの人に見せない今の決まりは守る (「ほかの人の答えを待っています」は誰かを出さない)。
4. **捨てる牌を選んでいるとき、同じ牌に印を付ける**: 全員の河、全員の鳴いた牌 (ポン・チー・カン)、ドラ表示牌のうち、選んでいる牌と同じ牌に印。赤五も同じ牌として扱う。選んでいる間だけ (選びを外すと消える)。
5. **起動時にタイトル画面「ヒデ雀」**: アプリを開いたときに、タイトル「ヒデ雀」の画面を約 2 秒出してから卓の一覧へ。キーかクリックで飛ばせる。その間に網への接続を進めるので、卓の一覧が出るまでの待ち時間を増やさない (起動の速さは譲れない)。ランチャーと窓の名前も「ヒデ雀」に (英語の名前は `Hide Jong` など、任せる)。
6. **640x360 の対局中のボタン (ポン・チー・カン・パスなど) を画面の右側に寄せる** (2026-10-18 追加。P4-Nano の 640x360 で遊んだユーザの求め)。持ち時間の大きな数字 (MJ6) と並ぶ形で、自然な並びに。
7. **640x360 の左上に黄色で出ている自分の風と点数を、左下 (自分の手牌の近く) に移す**。色も見やすく。
8. **鳴いた牌 (ポン・チー・明槓・加槓) は、鳴いた相手の方向の牌を横に倒して置く** (上家から鳴けば左端、対面なら真ん中、下家なら右端を横向き。加槓は横の牌の上に重ねる)。640x360 で未対応なら対応し、1280x720 も同じになっているか確認して、違えば直す。自分の鳴きだけでなく、ほかの 3 人の鳴きも、それぞれの向きで。6-8 もはみ出しの検査に足して 0 を保ち、画面を写して report に残す。

## 2. 作るもの

1. 1 章の 1-5 を、1280x720 と 640x360 の卓に (426x240 は sim の開発用の簡易表示で、落ちない・続けられる程度)。
2. 牌の画像は、今ある手牌・河の画像 (と 1280x720 の large/) を使い回す。ボタンの中に収まる大きさで。
3. タイトル画面は、文字だけでも、牌の画像を添えてもよい (派手にしなくてよい)。ブラウザ版の 1280x720 では全画面の高解像度、640x360 と端末でも崩れないこと。
4. `rake mahjong:overflow` のはみ出しの検査に、新しい表示 (画像のボタン、印、タイトル、ガイドの文) を足し、はみ出し 0 を保つ。
5. 卓のアプリの VM の使用量を対局中に増やさない (タイトル画面の描画は、開いたときだけで、対局中に残さない)。

## 3. 受け入れ条件

1. fmruby-core の `rake mahjong:overflow` ではみ出し 0。`rake test` が通る。
2. 家の LAN の卓 (CPU と偽物の AI でよい) で、1280x720 (ブラウザ版) と 640x360 (sim かブラウザ版) で写す: 鳴きのボタンの牌の画像 (ポン・チー・カン、チーの選択が複数のとき)、中央の状態表示の文字の色、待機中のガイドの文 (ほかの人の番、鳴きの答え待ち)、捨てる牌を選んだときの同じ牌の印 (河・鳴き・ドラ表示、赤五)、タイトル画面と卓の一覧へ移るところ。
3. タイトル画面があっても、アプリを開いてから卓の一覧が出るまでの時間が、直す前と同じくらい (数字を前後で出す)。
4. 卓のアプリの VM の使用量 (対局中) が MJ7 から増えない (数字)。
5. sim の標準構成で、エディタを 1 回起動して 1 打鍵する。
