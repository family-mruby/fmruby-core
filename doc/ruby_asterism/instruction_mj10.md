# MJ10 指示書: 1280x720 の観戦・振り返りで 4 人の手牌を見やすく (案づくり)

> 状態: 指示 | 更新: 2026-10-18 | ブラウザ版の 1280x720 の牌譜の振り返り (と観戦) で、4 人の手牌が河の牌の半分 (24x32) で小さすぎて見にくい。大きくする配置の案を画面で作り、ユーザに選んでもらう

前提: fmruby-core の麻雀アプリ `flash/app/game/mahjong/mahjong_xl.rb` (1280x720 の卓: `xl_opp_items` が観戦者には 4 人の手牌を `XL_ROW_START` から 24x32 の牌で並べる、河は `tiles_river2_*` の 48x64、盤 `XL_BX` ほか、`xl_place`、鳴き)、`mahjong_replay.rb` (振り返りは 1280x720 では `xl_draw` = 観戦の画面)、牌のシート (`large/`: `tiles_river2_r0/r90/r180/r270.bmp` が 48x64 の 4 向き、`tiles_river_r*.bmp` が 24x32、`tiles_hand2_*` が 84x112)、はみ出し検査 `tools/mahjong_overflow/` (`rake mahjong:overflow`)、手元の一式 `rake mahjong:up` とブラウザ版 (`?res=1280x720`)。

言葉: 文書は常体、「確かめ」ではなく「確認」。コードのコメントは英語。

## 1. 決まっていること (2026-10-18 ユーザ)

- 対象は **1280x720 の観戦と牌譜の振り返り** (どちらも同じ観戦の画面)。自分が座っている卓 (自分の手牌が大きい画面) と 640x360 は変えない。
- 4 人の手牌を今 (24x32) より大きく、見やすくする。

## 2. この段でやること (案づくり、止まって返す)

配置は仕様の選択なので、**実装を仕上げる前に止まって返す**。

1. 2〜3 の配置の案を作る。考える材料:
   - 手牌を 48x64 (河と同じ、`tiles_river2_*` の 4 向き) にする。上と下の席は横 14 枚 = 672 ドットで入る。左右の席は縦に 14 枚 = 896 ドットで画面 (720) に入らない。
   - 左右の席の手牌を 2 段に折る、左右だけ 36 ドット相当を作る (今の作りは整数倍のシートだけ: 新しいシートを足すなら牌の生成スクリプトの `--layout-sheets` に足す形)、鳴きを手牌から離して別の場所に置く、河と盤の位置を詰める、など。
   - 手牌が大きくなった分、河・盤・名札・点数・ボタン (「閉じる」・振り返りの操作) と重ならないこと。
2. 案ごとに、最悪の形 (4 人とも鳴き 4 組・カン、長い河、自摸の牌あり) と普通の形の画面を作る (手元の一式かはみ出し検査の場面で描いたものを写す)。はみ出し検査で重なりが無いことを確認する。
3. 案と画面を report に並べ、ユーザが選べる形の選択肢 (推奨を先頭に、それぞれの利点と欠点) を書いて**止まって返す**。コードは案ごとのブランチか作業中のまま (develop にはコミットしない)。

## 3. 範囲・決まり

- **触ってよいもの**: fmruby-core の `flash/app/game/mahjong/`、`tools/mahjong_overflow/`、`tools/mahjong_tilegen.rb` (新しい大きさのシートを足すなら)、report。案は fmruby-core のブランチ (例 `feature/mj10-<案>`) にコミットしてよい。develop にはコミットしない。
- **牌のシートの手書きを壊さない**: `tiles_hand.bmp` / `tiles_river.bmp` はユーザの手書きを含む元のシート。描き直す処理 (`--patch`) を流さない。`--layout-sheets` は元のシートから作るだけなので流してよい (流したら元の 2 枚が変わっていないことを確認する)。
- **触らないもの**: asterism-games・asterism-console、fmruby-core のほかのコード、VPS、GitHub の設定、Tab5 (シリアル・WiFi)。
- 外の AI の API を呼ばない。push・タグはしない。`git commit -a` は使わない。コミットの末尾は `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`。
- 起こしたもの (mahjong:up の一式、ブラウザ、試しのコンテナ) は名前で止めて消す。docker の prune はしない。
- **report** (`doc/ruby_asterism/report/mj10.md` と `report/mj10/` に画面、常体): 案ごとの配置の数字、画面、はみ出し検査の結果、選択肢。
