# GS12 報告: `asterism-games play` を 1 キーで操作する

> 状態: 完了 (検収待ち) | 更新: 2026-10-19 | 標準入力が端末のとき、麻雀・オセロとも 1 キーずつ読む形にした。麻雀は麻雀アプリと同じキー (←→ で牌を選び Enter/Space で打つ、R T P C V B K L J N、Esc パス、Enter で結果の OK)、オセロは十字キーでカーソルを動かし Enter で置く。パイプ・ファイル・試験・`--commands` は今の 1 行ずつの形のまま。`:` (か `/`) で 1 行打ち込む欄を開ける。asterism-games 0.17.0 のまま (98fc8b4、main、push・タグなし)

## 2. キーの一覧

### 麻雀 (麻雀アプリ `flash/app/game/mahjong/mahjong.app.rb` の table_key / shortcut / lobby_key に合わせた)

| キー | 場面 | すること |
|---|---|---|
| ← → | 自分の番 (打牌かリーチが出ているとき) | 手牌の牌を選ぶ (端で反対側へ回る。アプリと同じ)。選んだ牌の下に `^^` |
| Enter / Space | 自分の番 | 選んだ牌を打つ。何も選んでいなければツモ牌 (最後の牌) |
| Enter / Space | 結果 | OK (次へ)。終局では卓の主が待ち合わせに戻す |
| `R` | 自分の番 | リーチの牌選びに入る (もう一度で抜ける)。←→ で選び Enter で切ってリーチ。選んだ牌でリーチできないときは、リーチできる最初の牌 (アプリと同じ) |
| `T` | 自分の番 / 鳴き | ツモ / ロン |
| `P` | 鳴き | ポン (最初の候補) |
| `C` `V` `B` | 鳴き | 1 番目・2 番目・3 番目のチー (アプリの CHI_KEYS と同じ順。画面に各候補の牌を出す) |
| `K` `L` `J` | 自分の番 / 鳴き | 1 番目・2 番目・3 番目のカン (アプリの KAN_KEYS) |
| `N` | 自分の番 | 九種九牌 (アプリにある) |
| Esc | 鳴き / リーチの牌選び | パス / 牌選びをやめる |
| `1`〜`4` | 待ち合わせ | その席に座る (空き席か CPU の席。アプリの「座る[1]」) |
| `S` | 待ち合わせ | 立つ (アプリの「立つ[S]」) |
| `C` | 待ち合わせ (卓の主) | 空き席を CPU で埋める (アプリの「CPU で埋める[C]」) |
| Enter | 待ち合わせ (卓の主) | 始める (アプリの「始める[Enter]」) |

牌の文字 (a〜n) はキーにしていない (`a` はアプリでアシストの切り替えだが、端末版はアシストを 1 に固定しているので割り当てない)。東風/半荘・ルール・`auto`・`nocpu`・`ai` はキーが無いので `:` から打つ。

### オセロ (オセロアプリ `flash/app/game/othello/othello.app.rb` の run_key に合わせた)

| キー | 場面 | すること |
|---|---|---|
| ← ↑ ↓ → | 対局中 (席に着いているとき) | カーソルを動かす。盤の端で止まる (指示書どおり。アプリは反対側へ回る) |
| Enter / Space | 自分の番 | カーソルの所に置く。置けない所は送らずに短い知らせ (`a1: not a legal square`)。相手の番なら `not your move` |
| `S` | 待ち合わせ / 終局後 | 座る、座っていれば立つ (アプリの「座る[S]」「立つ[S]」) |
| `C` | 卓の主 | CPU を空き席へ (アプリの「CPU[C]」) |
| Enter | 待ち合わせ / 終局後 (卓の主) | 始める |

カーソルは `[ ]` で囲む (`  3 . .[*]X * . . .`)。置ける所の印 `*` と別の記号なので区別がつく。初期位置は自分の番になった最初の時点で置ける所の 1 つ目 (`lg` の先頭)、以後は動かした所に残る。対局の外では消える。

### 共通

| キー | すること |
|---|---|
| `Q` / Ctrl+Q / Ctrl+C | 抜ける (アプリの「閉じる[Ctrl+Q]」に合わせて Ctrl+Q も効く) |
| `:` / `/` | 1 行打ち込む欄を開く。端末を cooked に戻し、画面は従来の形 (文字 a〜n と命令の一覧、`> `) に戻る。`d3`、`6s`、`chi 2`、`tonpuu`、`resign`、`auto` など今の命令がそのまま使える。空行は何もしない |

最下行に今効くキーを `[キー]すること` の形で出す。どの画面でも末尾に `[:]打ち込む [Q]閉じる` (オセロは `[:] type a command  [Q] quit`) が付く。

## 4. 端末を戻す扱い

- raw にするのは `key_loop` の間だけ (`IO#raw(intr: false)` のブロック)。Ctrl+C は SIGINT にならずバイト 0x03 として届き、`:ctrl_c` で抜ける。
- ブロックの `ensure` で raw が解ける。キーを読むスレッドが `:` の 1 行読み (cooked) の途中で終わると、そのスレッドの cooked の後始末が raw を戻してしまうので、raw のブロックを出る前にスレッドを kill して join する。外側の `ensure` でカーソルを表示 (`ESC [?25h`) に戻し、`$stderr` の差し替えも戻す。
- raw では端末が出力の `\n` を行頭へ戻さない (cfmakeraw が OPOST も切る) ので、キーで読むときは出力を `Keys::CrlfOut` で包み `\r\n` で書く (`$stderr` も、警告が崩れないよう同じく包む)。画面は従来どおり「消して描く」(`ESC [H ESC [2J`)、残り時間の書き換えも従来どおり ESC 7 / ESC 8。キーで読んでいる間はカーソルを隠し、`> ` は出さない。
- 擬似端末の上で、`stty -a` を起動の前と抜けた後に採って比べた。どれも同じ:

| 抜け方 | 終了コード | `stty -a` | カーソル表示 |
|---|---|---|---|
| オセロ終局後に `Q` | 0 | 同じ | 戻った |
| 麻雀 (kanji) 終局後に `Q` | 0 | 同じ | 戻った |
| 麻雀 (mpsz) 終局後に `Q` | 0 | 同じ | 戻った |
| オセロで Ctrl+C | 0 | 同じ | 戻った |
| オセロで `:` → `quit` Enter | 0 | 同じ | 戻った |
| オセロのプロセスへ SIGTERM | 143 | 同じ | 戻った |

## 6. 決めたこと (1・2 章の範囲の細部)

- 麻雀で選んでいる牌は、手牌が変わる (牌を引く・鳴く) たびにツモ牌に戻す。アプリは選んだ位置を持ち越すが、並べ替えで別の牌を指すことになり Enter 連打で思わぬ牌を切りやすいので、端末版はツモ切りが既定になる形にした。
- 宣言のキーが今できないとき (`P` で鳴けない等) は `今はできない`、打てない牌で Enter は `その牌は打てない` を一言出す (アプリは黙って無視)。
- Esc で卓を出ることはしない (アプリの待ち合わせ・観戦では Esc が「卓を出る」だが、端末版では抜けると同じ。抜けるのは `Q` / Ctrl+C に限り、Esc の押し間違いで落ちないようにした)。
- オセロの投了はキーにしていない (アプリは対局中の Esc → 確認)。`:resign` で打てる。
- オセロの画面は GS11 から英語なので、キーの行も英語にそろえた (`your move: [arrows] move [Enter] play`)。日本語にするかはユーザが選ぶ (§7)。

## 7. 確認してほしいこと (実際の端末で)

1. 麻雀の打ち心地: ←→ で `^^` が牌の真下に来るか (kanji / emoji / mpsz それぞれ。emoji は字形の幅しだい)、Enter・Space で打てるか、`R` → Enter のリーチ、`C`/`V`/`B` の候補の並びが画面の表示と合っているか、Esc のパスに 50 ms の待ちが気にならないか。
2. ツモ・ロン (`T`) とカン (`K`/`L`/`J`) は擬似端末で踏めていない。実際に手が来たら確認してほしい。
3. `:` で 1 行打ち込む欄: 打っている途中に画面が描き直されて行が消えることがある (GS11 の 1 行ずつの形と同じ)。気になるなら直す。
4. 抜けた後に端末が戻っているか (エコー、改行、カーソル)。WSL の端末・VS Code の端末・macOS の Terminal など、使う端末で一度。
5. 選択を求めること:
   - オセロのキーの行を日本語にするか (推奨: 日本語にそろえる。盤の行・状態の行も含めて日本語化する。今は GS11 からの英語のまま)
   - オセロの投了をキーに割り当てるか (推奨: アプリと同じ Esc → 確認 (`Y`/Enter で投了))。今は `:resign`
   - 選んでいる牌をツモ牌に戻す今の形でよいか (推奨: このまま。アプリと同じ持ち越しにもできる)
