# MJ-E3: 持ち時間 5+20 と、フリテン・形式聴牌の細部（報告）

> 状態: 完了 (検収待ち) | 更新: 2026-10-16 | riichi_engine の Fork の `fmrb` は 0.1.1.fmrb5 (3a7aaff、push していない)。ゲームホスト (asterism-games の a3c94f1) に「1 手の時間＋持ち越しの時間」を入れ、卓のアプリ (fmruby-core の feature/mj-e3) に表示と選び方を足した。ゲームホストの Gemfile.lock は 0.1.1.fmrb4 のまま (Fork の push の後に親が更新する)

2026-10-16 のユーザの決定 3 つを入れた。

1. 長考時間を設定で選べるようにし、既定を雀魂の「5+20」にする。今までの「1 手ごとに決まった時間」も選べるように残す。
2. 役の無い聴牌でアガリ牌を見逃したときも同巡フリテンにする（雀魂の文面に例外が無い）。
3. ポンした牌の 4 枚目の単騎はテンパイと数える（除くのは「手持ち 4 枚」の単騎だけ）。

## 1. 持ち時間の仕組み

### 決めたこと

| 項目 | 決めたこと | 理由 |
|---|---|---|
| 1 手の時間 | `turn_seconds`（既定 5）。打牌・リーチ・暗槓・加槓・ツモ和了・九種九牌はどれも 1 手 | 雀魂の「5+20」の 5 |
| 持ち越しの時間 | 席ごとに `bank_seconds`（既定 20）。1 手が 5 秒を超えた分をここから引く。5 秒と持ち越しを使い切ると、ゲームホストが代わりに打つ（自摸った牌を切る） | 同じく 20 |
| 持ち越しを戻す時機 | **半荘（東風戦）を通して戻さない**。対局の始めに満たし、局が変わっても戻さない | 雀魂の既定の文面は「長考時間：5+20」だけで、戻す時機が書いていない。指示どおり「対局を通して持つ」にした（ユーザに選んでもらう点として 5 章に残す） |
| 鳴き（ポン・チー・ロンの窓） | 今までどおり `call_seconds`（既定 8）。持ち越しは使わない | 文面に鳴きの時間の定めが無い。指示どおり |
| 途切れた席 | 今までどおり `away_wait_seconds`（2 秒）で代わりに打つ（案 A）。5 秒より短いので持ち越しは減らない | 指示どおり |
| 決まった時間の型 | 持ち越しが 0 なら今までと同じ「1 手ごとに決まった時間」 | 型を 2 つ持たず、持ち越し 0 で表す |

ゲームホストの設定に `bank_seconds`（環境変数 `MAHJONG_BANK_SECONDS`）を足し、`turn_seconds` の既定を 20 から 5 にした。`deploy/vps/env.example` には触っていない（中の `# MAHJONG_TURN_SECONDS=20` は注釈のままなので、既定の 5+20 で動く）。

### ローカルルールの項目 10「持ち時間」

| 値（見え方の符号） | 画面 | 意味 |
|---|---|---|
| 20005 | 5+20秒 | 雀魂の既定（ゲームホストの既定） |
| 5003 | 3+5秒 | 早い卓 |
| 30010 | 10+30秒 | ゆっくりの卓 |
| 20 | 20秒 | 1 手 20 秒で持ち越しなし（MJ-E2 までの既定） |
| 60 | 60秒 | 1 手 60 秒で持ち越しなし |

- 符号は「1 手の秒 + 1000 × 持ち越しの秒」。持ち越しの無い時間は秒数そのものなので、前の卓のアプリが送る 10・20・30・60 も同じ意味でそのまま通る（ゲームホストは受ける。選択肢の一覧 `tc` には 10・30 を入れていない）。
- ゲームホストの設定の値は必ず選択肢に入る（一覧に無ければ末尾に足す。試験で 7+15 が `15007` として入ることを確かめた）。
- 卓の主が選んだ値は保存され、次の対局にも残る。ゲームホストの値を選び直すと選択を消す（他の項目と同じ）。
- 1280x720 と 640x360 の欄は 15 行のまま。値の幅は最大で「10+30秒」で、欄に収まった。

### 見え方の鍵（古いアプリと新しいゲームホスト、その逆）

| 鍵 | 中身 | 古い卓のアプリ（MJ-E2 まで） |
|---|---|---|
| `ru[10]` | 1 手の秒（5+20 なら 5） | 「5秒」と出る（持ち越しは見えない）。左右キー・クリックで 10・20・30・60 の決まった時間に切り替わる |
| `tb`（新規） | 持ち越しの秒 | 読まない |
| `tc`（新規、待ち合わせのときだけ） | 項目 10 の選択肢（符号の並び） | 読まない |
| `dl` | 自分の手番で持ち越しがあるときは `[席, 残り ms, 持ち越しの ms]`（3 つ目は残りの中の持ち越しの分） | 先頭 2 つだけ読み、合計の残り（25 秒など）を出す。締め切りは正しい |

新しい卓のアプリと古いゲームホストの組では、`tb`・`tc`・`dl` の 3 つ目が無いので、項目 10 は今までどおり 10・20・30・60 で選び、残りは「20秒」のように出る（sim で古いゲームホストに入って確かめた。下の画面の写し）。

### 卓のアプリの表示

- 自分の手番の残りを「5+20秒」の形で出す（1 手の残り + 持ち越しの残り、どちらも秒の切り上げ）。1 手の時間を使い切ると「0+19秒」と持ち越しが減っていく。持ち越しの無い時間・鳴き・途切れた席は今までどおり「12秒」。
- 1280x720 は状況の欄の「残り 2+20秒」、640x360 と sim の小さい卓（426x240）は手牌の上の状況の行。
- 秒が変わるたびに描き直す判定を、壁時計の秒の境目から締め切りまでの秒の境目に変えた（表示が最大 1 秒遅れていたのを直した）。

### 保存と読み戻し

- 席ごとの持ち越し（`banks`）と卓の主の選択（`rules` の `turn_ms`・`bank_ms`）を保存する。保存の形式番号（2）は変えていない。
- 持ち越しより前に保存した卓は読める。`rules` に `turn_ms` だけがある（卓の主が決まった時間を選んでいた）卓は、その決まった時間のまま（持ち越し 0）。選んでいなかった卓は、ゲームホストの 5+20 で、対局中なら持ち越しを満たして続ける。

## 2. フリテンと形式聴牌（Fork）
