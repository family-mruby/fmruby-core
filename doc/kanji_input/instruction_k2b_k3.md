# K2b・K3 指示書: ファームへの組み込みと、変換の操作

> 状態: 実装中 | 更新: 2026-11-11 | 正は plan.md (方針・仮決め・ユーザが選んだ表示とキー・K0 の後の親の判断)、report/k0.md・k1.md・k2.md

## K2b: 組み込み

- `components/fmrb_kanji/` を ESP32 (IDF の component)・ネイティブ版・sim・wasm の組み立てに入れる (wasm は自前の変換を
  使わないので、入れないでよい。入れないなら理由を report に)。
- 引くのは優先度の低い C のタスク (host task では引かない)。辞書と 4 KB の塊のバッファはそのタスクが持つ (PSRAM)。
  結果は候補を UTF-8 に書き出してから K3 の側へ渡す。
- 辞書の置き場所: system_conf の設定 (既定 `/sd/dict/fmrb_kanji.dic`)。sim・ネイティブ版で試す場所は設定で指す。
  辞書が無い・開けないときは変換を無効にし、今のかな入力のまま。設定で変換を無効にもできる。
- 内蔵 RAM の増分 0 (`rake regress:size`)。

## K3: 変換の操作と、画面の下の 1 行

- preedit (未確定の読み) は、辞書が開けて変換が有効なときだけ持つ。かなの合成 (host_task の `fmrb_kana_feed` の隣) で、
  かなモードの打鍵をアプリへ送らずに preedit にためる。辞書が無ければ今どおりすぐ送る。
- キー (ユーザが選んだ): スペースか変換キー (JIS) で変換、もう一度で次の候補、Enter で確定 (候補を選んでいなければかなのまま
  確定)、Esc で読みに戻る、もう一度 Esc で読みを捨てる、BS で preedit の 1 字を消す、数字キーで候補を直接選ぶ。
  確定した文字は今の送り方 (`host_send_kana_byte` など) でアプリへ送る (受け側のアプリは変えない)。
- 読みの先頭からの最長一致: 読みの一部だけが辞書にあれば、その部分を変換し、残りは次の preedit として続ける。
- 表示 (ユーザが選んだ: 画面の下の 1 行): システムが持つ 1 行の Canvas を全部の Canvas より上の z に置き、C の側が描く
  (全画面のアプリ・全画面エディタの上でも見える)。preedit と候補 (番号つき、ページ送り) を出す。Retro 320x240・
  Modern 426x240・全画面の 640x360 で収まる。フォントは misaki 8 か efont 12 (構成に合わせる)。
- 変換の状態はかなの指示器 (メニューバーとエディタのステータス行) と食い違わないこと。

## 確認

- `rake regress`、`rake regress:screens` (かなの入力の場面が変わらないこと。辞書が無い既定では今と同じ)、`rake regress:size`。
- sim (Retro・Modern) とネイティブ版で、辞書を設定で指した上で: エディタと Shell で「かんじ」→ 変換 → 候補 → 確定、
  最長一致 (「いった」など)、Esc・BS、数字で選ぶ、全画面エディタの上で 1 行が見える。辞書を外すと今のかな入力。
- 端末での速さ (開く時間・1 回の引き) の測定の手順を report に書く (実機は後で)。
