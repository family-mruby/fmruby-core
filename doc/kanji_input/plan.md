# 漢字変換 (辞書を SD に置く)

> 状態: 進行中 | 更新: 2026-11-11 | K0〜K5 済、残りは実機の確認とリリースへの添付 (ユーザの指示で)。 ユーザ: 指示なしで行けるところまで (未確定事項は親の仮決め、後でユーザが見直す)。 ESP32 (S3・P4) の端末で、かな入力から単語ごとに漢字へ変換する。辞書は配りやすいライセンスのデータから生成して SD に置き、flash の書き込みを増やさない。候補は端末のフォントで出せる字だけにし、フォントにある漢字はどれも変換で出せるようにする。ブラウザ版はブラウザの IME、ネイティブ版は Linux の IME (L12b)

## 目的

- 端末のかな入力 (ローマ字 → かな、doc/editor_ja) に漢字変換を足し、チャットや文書を漢字まじりで書けるようにする。
- 今は doc/editor_ja/plan.md の方針で「漢字変換は持たない」。この計画でその線引きを改める (2026-11-10 ユーザ)。

## 方針

1. **端末ごとの入り口**
   - ESP32 (S3 の Retro・P4 の Tab5・NARYAv4): この計画の自前の変換。
   - ブラウザ版: ブラウザの IME を使う (確定した文字を端末へ流し込む)。自前の変換は使わない。
   - ネイティブ版 (Linux): Linux の IME (doc/linux_native の L12b)。自前の変換は使わない。
2. **辞書は SD に置く**: flash (storage) には入れない。焼く時間を増やさないため。
   - P4 の端末は SDMMC の microSD、S3 (NARYAv3) は SPI の microSD (`/sd`)。
   - SD が無い・辞書が無いときは今のかな入力のまま動く (変換の操作は何もしない)。
3. **辞書は配りやすいデータから生成する**: 配布の条件が緩いデータ (候補: mozc の辞書の元データ。BSD 系) から、
   道具 (Ruby) で端末用の辞書ファイルを作る。GPL の辞書 (SKK) は使わない。
4. **フォントと揃える**:
   - 候補に出すのは、その端末のフォントで描ける字だけからなる語。
   - フォントにある漢字は、どれも 1 字の読みから変換で出せる (1 字の変換の表を入れる)。
   - 基準のフォントは、配る全部の構成で描ける字の集合 (misaki 8 だけの構成を含む)。K0 で確定する。
5. **単語ごとの変換**: 読み (かな) を打って変換し、候補から選ぶ (SKK や単語の変換の形)。文を文節に区切って
   変換する本格的な IME は持たない。
6. **内蔵 RAM は増やさない**: 辞書は読み込まず、SD のファイルを索引から二分探索で引く。重い仕事は優先度の
   高い帯に置かない。

## 親の仮決め (2026-11-11。表示の場所 (画面の下の 1 行) と変換キー (スペースと変換キー) はユーザが選んだ。ほかは後で見直す)

- **未確定の読み (preedit) を持つのは、辞書があって変換が有効なときだけ**。辞書が無い・変換が無効なら、今のかな入力
  (打ったかなをすぐアプリへ送る) のまま。
- **キー**: かなモードで読みを打つと preedit にたまる。スペースか変換キー (JIS の変換) で変換、もう一度で次の候補、
  Enter で確定、Esc で読み (かな) に戻る、もう一度 Esc で読みを捨てる。preedit がある間の Enter は「かなのまま確定」。
  BS は preedit の 1 字を消す。数字キーで候補を直接選ぶ。
- **表示**: preedit と候補は、システムが画面の下に出す 1 行 (デスクトップの重ね表示) に出す。どのアプリでも同じ場所。
  Retro の 320x240 でも 1 行に収める (候補はページで送る)。
- **学習はしない** (最初の版)。候補は辞書の頻度の順。
- **辞書の大きさは 1 MB 前後を目安** (生成の道具で上限を指定できる)。
- **辞書の配り方**: 生成の道具はリポジトリに置き、生成物 (辞書ファイル) はリポジトリに入れない。次のリリースで
  リリースの添付にする (リリースはユーザの指示で)。SD の置き場所は `/sd/dict/` (名前は K5 で確定)。
- **子供向けの線引き**: 辞書が SD にあれば変換は有効。設定 (system_conf) で無効にできる。


### K0 の後の親の判断 (2026-11-11)

- 候補と読みの 1 行は、デスクトップの重ね表示ではなく、**システムが持つ 1 行の Canvas を全部の Canvas より上に置き、
  C の側が描く**形にする (全画面のアプリ・全画面エディタの上でも見えるため。ユーザが選んだ「画面の下の 1 行、
  どのアプリでも同じ場所」を満たす実装の選択)。
- 今のかなの合成で打てない読みの語 (てぃ・ふぁ・ゔ など約 700 語) は、K1 では辞書から外す。小書きのかなの入力を
  合成に足すかはユーザが後で決める (残件)。語幹が っ で終わる語は、読みの先頭からの最長一致で引く (K2)。
- 辞書の置き場所は設定で変えられるようにする (Linux sim に /sd が無いため。既定は /sd/dict/)。
- (K1 の後) 候補に使ってよい字は misaki 8 と efontJA 12・12 太字・16 の共通部分 (7,065 字、漢字は 6,358 字のまま)。
  「配る全部の構成で描ける字」に合わせた。1 MB で 80,192 語。


### ユーザの見直し (2026-11-11)

- **学習はしない** (仮決めのまま確定)。
- **辞書は 1 MB** (確定)。(同日追記) **配るのは 1 MB と 4 MB の 2 つ**: 標準 (1 MB、`/home` にも置ける) と、SD 向けの大きい辞書 (4 MB、約 34 万語)。
- **辞書は CI に入れない**。手順書 (doc/release.md) と道具 (`rake kanji:dict`・`kanji:place`・`kanji:check`) で足りる。
- 確定の文字を送っている途中に前のアプリが変わったら、残りは捨ててよい。
- **カタカナの読みだけの語は辞書から外し、変換の側で読みのカタカナの形を必ず候補に足す** (どの読みでもカタカナにできる。空いた分にほかの語が入る)。
- **小書きのかなを打てるようにする**: 一般の IME と同じローマ字 (`xa`・`la` → ぁ、`xtu`・`ltu` → っ、`xya` → ゃ、`xwa` → ゎ、`thi` → てぃ、`fa` → ふぁ、`vu` → ゔ、`she` → しぇ など)。(同日追記) 今は別の意味になる組み合わせ (`thi`→ひ、`fa`→は、`xa`→xあ など) も一般の IME に合わせる。打てるようになった読みの語 (約 700) を辞書に戻す。かなの読みを打っている途中に前のアプリが変わったら、その読みは捨てる。

## 受け入れ条件

- 基準のフォントにある漢字は、すべて 1 字の読みから変換で出せる (道具が数えて 0 件の漏れを示す)。
- 候補に、端末のフォントで描けない字が出ない (道具の検査と端末の画面)。
- S3 (SPI の SD) と P4 (SDMMC) で、1 回の変換 (候補の表示まで) が体感で待たない速さ (目安は K0 の測定で決める)。
- 内蔵 RAM の増分 0 (`rake regress:size`)。焼く中身 (flash の image) が辞書の分だけ増えない。
- SD が無い・辞書が無い端末で、かな入力が今のまま動く。
- ブラウザ版でブラウザの IME の漢字まじりの文字が、エディタ・Shell・チャットなどのアプリに入る。
