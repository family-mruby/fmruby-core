# A6b 指示書: 通信の型と見本を足し、0.3.0 を通しまで確認する

> 2026-11-22 | 親セッションからサブ (Opus) への指示。A6 (report/a6.md) の続き。ユーザの決定 (2026-11-22):

1. **使ってよい API の範囲**: A6 の実装のまま (型 + 見本のアプリと端末の案内がアプリから使っているもの)。
2. **大きさの上限 (32 KB) は `flash/app/` だけに効かせる**。ライブラリ (mrblib) の本体は大きくても検索できる。
3. **通信の材料を Family mruby に足す**: `sig/` に FmrbAsterism (アプリが使う側の API) の型と、数十行の見本のアプリを
   1〜2 個 (試験のフォルダの外)。型の充実の最初の 1 つ。
4. 0.3.0 はリリースして VPS に入れる (リリースと VPS は親とユーザ。サブは手元の通しまで)。

## やること

### fmruby-core (ブランチ `ai-sources` の上)
- `sig/` に FmrbAsterism の型を足す。ほかの `sig/*.rbs` の書き方・要約の行の形・回帰の道具 (型の検査、`rake test`・
  `rake regress` に入っているもの) に合わせる。**アプリが使う側だけ** (つなぐ・オブジェクトを公開する・呼び出す・
  トピックに出す/受ける・状態・閉じる)。内側の呼び出しは書かない。各メソッドのコメントに、引数の意味・戻り値と失敗の
  しかた・使う順番・短い例を書く (束に入るのは今は要約の 1 行だけだが、検索で読まれる)。実装
  (`lib/gems/picoruby-fmrb-asterism/`) と動いているアプリ (チャット・AI ヘルパー・麻雀・試験のアプリ) を読んで、
  実際の形に合わせる。推測で書かない。
- 見本のアプリ 1〜2 個 (置き場はほかの見本に合わせる。例: `flash/app/demo/`)。数十行で、ほかの端末と文をやり取りする
  最小の形 (片方が公開して、もう片方が呼ぶ。トピックで知らせる)。アプリの書き方の規約に合わせる。Retro に入れるか
  (storage の大きさ) はほかの Asterism のアプリの扱いに合わせる。
- 確認: `rake regress`。ネイティブ版 2 つ (かネイティブ版と試験用の送り手) とローカルのルータで、見本が実際に
  やり取りできること。**ESP32 のビルドはしない** (`build/` は Tab5 用のものが残っている。触らない)。sim・ネイティブ版の
  ビルドは `build-linux/`・ネイティブ版の置き場だけ。

### asterism-tutor (ブランチ `sources` の上)
- 大きさの上限を `flash/app/` だけに。試験・README・CHANGELOG を合わせる。
- 同梱の束を、上の型と見本が入った fmruby-core から作り直す。
- 通し: 手元で作ったイメージ (deploy/vps の Dockerfile) をローカルのルータにつなぎ、**イメージの中から GitHub へ
  取りに行けること** (公開の develop。まだ新しい型は無いので、取れることと束ができることまで)、続けて
  `sources` の取りに行く先を手元の fmruby-core (file の URL。イメージに読み取り専用で mount) に向けて、
  ネイティブ版の端末の AI ヘルパーから「ほかの端末と文をやり取りするアプリを作って」を流し、返ったコードが
  新しい型と見本に沿っていて、検査を通ること。A6 の (a)(b) も 1 回ずつ流して悪くなっていないこと。
  費用は合計 1 ドルまで。鍵の扱いは A6 と同じ (表示・記録・コミットしない)。

## 受け入れ条件
1. fmruby-core: `rake regress` が通る。見本がネイティブ版でやり取りできた記録 (ログか画面の写し)。
2. asterism-tutor: `bundle exec rake test` が通る。上限が flash/app だけに効く試験。
3. 通しの (c) で、返ったコードが FmrbAsterism を型のとおりに使っている (往復の数・待ち時間・費用・検索した語と
   読んだファイルを report に)。届かなければ、何が足りないかを report に書いて止まる (型の書き方を勝手に広げない)。
4. report/a6b.md。`git status` に取りこぼしなし。起こしたものは止めてある。
