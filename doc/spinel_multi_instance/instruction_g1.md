# 作業指示書 G1: Spinel の gem を 2 つ目のアプリが使うときは遅い版に切り替える

対象: 実装担当のサブエージェント。前提: plan.md、report/i1.md (3.4、5.3、6 章)。report は `report/g1.md` へ。

## 決定 (ユーザ、2026-10-03): 案 b

Spinel の gem (raycast、FFT、spinel_hello) は、gem ごとに Spinel のインスタンスを 1 つだけ持つ (C の受け口の
`s_open` / `s_pool` / `s_est`)。Ruby 側の参照の数はアプリ (mruby の VM) ごとに別々なので、2 つ目のアプリが Spinel の版を
使うと、今のインスタンスが設定されていないタスクで計算が走り、1 つ目のアプリが閉じるとプールが消えて 2 つ目が壊れる。

**直し方 (b)**: インスタンスを作ったタスク (持ち主) を覚え、**持ち主でないタスクから Spinel の版を使おうとしたら、
その gem の遅い版 (Spinel でない版) で計算させる**。2 つ目のアプリも止まらずに動き、速さだけが落ちる。

## T1: 作る

- 3 つの gem の受け口 (lib/add/picoruby-fmrb-*/native/*.c と ports、mrblib) を読み、持ち主のタスクの記録と、持ち主
  以外からの `begin` を区別できるようにする (例: `begin` が「使用中 (別のタスク)」を返す)。
- Ruby 側 (各 gem の mrblib) で、Spinel の版を開けなかった理由が「別のタスクが使用中」なら、その gem の Spinel で
  ない版に切り替える:
  - raycast: `:ruby`。
  - FFT: Spinel でない版のうち、gem が用意している既定の代わり (C の版があればそれ。どれにするかと理由を report に)。
  - spinel_hello: Spinel でない版があればそれ。無ければ、何をするか案を返す (止まる条件)。
- **切り替えたことが分かるようにする**: アプリが「今の版」を読める口 (`backend` など) は、実際に動いている版を返す
  (Spinel と表示しながら Ruby で動く、を避ける)。ログに 1 行 (どのアプリが、どの gem の、どの版に切り替わったか)。
  アプリ側 (raycaster、fft_bench、mic_spectrum) の画面の表示がこの値を使っているかを確かめる。画面の表示を変える
  必要があれば、止まって案を返す。
- 持ち主のアプリが閉じた後、ほかのアプリが新しく開けば、そのアプリが新しい持ち主として Spinel の版を使える。
  切り替わって遅い版で動いているアプリは、そのまま遅い版で続ける (途中で Spinel の版に戻さない)。
- 強制終了された持ち主の後始末 (インスタンスとプールの解放、持ち主の記録の消去) が漏れないことを確かめる
  (今の作りでどう片付いているかを読んで、必要なら直す)。
