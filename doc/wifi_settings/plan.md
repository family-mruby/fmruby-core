# ESP32 の Wi-Fi の設定画面 (探してつなぐ、複数を覚える)

> 状態: 計画済 | 更新: 2026-11-12 | ネイティブ版 (GPD) の設定アプリの Wi-Fi のページと同じ画面を、ESP32 (P4・Tab5・S3) でもデスクトップの Network の画面から開けるようにする。近くのネットワークを探して選び、キーボードでパスワードを入れてつなぐ。覚えたネットワークを複数持ち、見えている中でいちばん強い、覚えているものに自分でつなぐ

## 目的

- ESP32 の端末で、`wifi.toml` を手で書いたり BLE の Web コンソールを使ったりせずに、画面から Wi-Fi をつなげるようにする。
- 家・会場・スマートフォンのテザリングなど、場所が変わっても、覚えたネットワークの中から自分でつなぐ。

## 決定 (2026-11-12 ユーザ)

- **入り方**: デスクトップの Network の画面からページを開く (ネイティブ版と同じ入り方)。
- **パスワード**: キーボードで入れる (画面に出すキーボードは作らない)。
- **複数のネットワークを覚える**。
- **見えている中でいちばん強い、覚えているネットワークにつなぎに行く** (起動時と、切れたとき)。

## 今の作り (2026-11-12 に確認)

- ネイティブ版: 設定アプリ (`native/apps/linux_settings.app.rb`) の Wi-Fi のページ。探す・つなぐ・切る。中は NetworkManager。
  ページが使う口は `FmrbApp.wifi_networks` ほか (OS がネットワークを選ばせてくれる環境だけ出す作り)。
- ESP32: デスクトップの Network の画面 (`system_desktop/network_dialog.rb`) は見るだけ (状態・SSID・IP・名前)。
  つなぎ先は `/home/wifi.toml` (無ければ `/etc/wifi.toml`) の `[wifi]` の `ssid`・`password` の 1 組だけ。
  `/home/wifi.toml` は遠隔 (HTTP・BLE) から読めない作り。

## 方針

1. **ページは 1 つ**: ネイティブ版の Wi-Fi のページを共通にして、ESP32 でも同じ部品を使う (デザインをそろえる)。
   開くのはデスクトップの Network の画面のボタン。Retro (320x240) にも収める。英日。
2. **口をそろえる**: `FmrbApp.wifi_networks` (探した結果: SSID・強さ・鍵の有無・覚えているか)、つなぐ・切る・忘れるの口を、
   ESP32 の側にも作る。探すのは ESP32 の Wi-Fi の探索 (P4・Tab5 は C6 を esp_hosted で通す)。
3. **覚える形**: `/home/wifi.toml` に複数のネットワークを持つ (例 `[[networks]]` の並び。今の `[wifi]` の 1 組も読む)。
   つないだら、そのネットワークを覚える。忘れる操作でその組を消す。パスワードはこのファイルにだけ置く (遠隔から読めない
   今の決まりのまま)。
4. **自分でつなぐ**: 起動時と切れたときに探し、覚えているもののうち、いちばん強いものにつなぐ。つなげなければ次に強いもの。
   画面で選んでつないだときはそれを優先する。探しすぎない (切れている間の探索の間隔を空ける。電池と BLE への影響を見る)。
5. **重い仕事は優先度の高い帯に置かない** (探索・接続は Wi-Fi のタスクか低い優先度のタスクで。入力・描画を止めない)。
   内蔵 RAM は増やさない (探した結果の並びは PSRAM)。

## 受け入れ条件

- P4・Tab5・S3 で、Network の画面からページを開き、近くのネットワークが強さつきで並び、選んでパスワードを打ってつなげる。
- 2 つ以上のネットワークを覚え、片方が見えなくなる・切れると、見えている強い方へ自分でつなぐ。
- 今の `[wifi]` の 1 組だけの wifi.toml も今どおり動く。
- 探している・つないでいる間も、入力と描画が止まらない。内蔵 RAM の増分 0。
- ネイティブ版の Wi-Fi のページの動きは変わらない。

## 決定 (2026-11-12 ユーザ、未確定事項)

- **覚える数の上限は 5**。
- **つなぐ順は強さだけ** (見えている中でいちばん強い、覚えているもの)。
- **鍵の無いネットワークも、自分でつなぐ候補に入れる** (覚えていれば)。
- **隠れた SSID は wifi.toml を直接書いて足せる**ようにする (画面に手で足す口は作らない。書き方を案内に書く)。
