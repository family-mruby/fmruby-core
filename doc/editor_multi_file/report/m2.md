# M2 報告: タブの行、File メニュー、閉じる・終了の確認

> 状態: 完了 | 更新: 2026-11-17 | 文書が 2 つ以上のときだけメニューの下にタブの行を出し、クリック・Ctrl+PageUp/Down・Alt+. / Alt+, / Alt+1〜5 で切り替える。File > Open は追加で開き (空の無題ならそこへ、同じファイルなら切り替え)、New・Close を足した。変更のある文書の Close と、終了 (Ctrl+X・Ctrl+Q・File > Exit) は終了の確認と同じ形のダイアログで聞き、終了は変更のある文書ごとに順に聞く。標準構成 (Spinel) と全部 mruby の構成の両方で、保存したファイルの中身で確認した。回帰の場面 `editor_docs` を足した。指示書は instruction_m2.md

## 1. タブの行の作り

- 置き場: `editor/tabs.rb` (module `EditorTabs`)。定数は `editor/const.rb` (`TAB_ROW_H` = `CHAR_H + 2` = 10 px、`TAB_PAD` = 3、`TAB_GAP` = 2、`TAB_NAME_MIN` = 4)。
- 高さ: chrome の文字 1 行 (8 px) と上下 1 px。下の 1 px は編集の範囲との境。メニューの行 (区切りの 1 px を含めて 9 px) のすぐ下 (`@tab_y` = 9)。
- 色: 行の地はメニューの行と同じ `MENU_BG`、名前は `MENU_TEXT`。今の文書は地と字を入れ替えた反転 (`MENU_TEXT` の地に `MENU_BG` の字)。どちらもテーマから来る既存の色で、色の鍵 (`/home/colors.toml` の [editor]) は足していない。0x01 は使っていない。ほかのタブは地を塗らず字だけ (間は 2 px と左右 3 px の余白で 8 px あく)。
- 名前: パス無しのファイル名。無題はステータス行と同じ `[New]` / `[新規]`。変更があれば後ろに `*`。ヘルプ (F1) を開いている間は、下にある文書の名前と `*` を出す (ヘルプのファイル名は出さない)。
- 詰め方: 全部が幅 (`@user_area_width - 4`) に入るまで、すべての名前を同じ字数に後ろから切る (省略の印は付けない)。4 字より短くはしない。それでも入らなければ、今のタブが入る所まで先頭を飛ばして並べ、右端に入らないタブは描かない。
- 描く時: `redraw_all` (全体の描き直し: 切り替え・開く・閉じる・名前が変わる保存) と、`redraw_dirty` で今の文書の `*` が前に描いた時と変わったときだけ (`@tab_drawn_mod` と比べる)。1 打鍵ごとには描かない。
- クリック: 描いたときに `@tab_xs`・`@tab_ws`・`@tab_ids` を残し、`mouse_up` で行の中なら `docs_switch`。保存の確認のダイアログが出ている間は切り替えない (終了の順番が崩れるため)。
- 見た目 (写し): Modern 426x240 で 2 つ・3 つ・5 つ、Modern の全画面 640x360 で 5 つと 2 つ、Retro 320x240 で長い名前 5 つ (`first_` `second` `third_` `fourth` `fifth_*` に詰まって 1 行に入った) と Retro の全画面 (`first_lon` ほか 9 字)。崩れは無かった。

### 1.1 行の数を直した所

行の数・位置を使う所はすべて `@edit_y`・`@edit_rows`・`@edit_height` を読んでいて、それを決めるのは `recompute_layout` だけだったので、直したのは 1 か所と、その呼び方の 2 か所。

| 所 | 直し |
|---|---|
| `editor.app.rb` `recompute_layout` | `@tabs_on = EditorCore.doc_count > 1`、`@tab_y = @menu_y + CHAR_H + 1`、`@edit_y = @tabs_on ? @tab_y + TAB_ROW_H : @tab_y`。1 つのときは今までと同じ値 |
| `editor/docs.rb` `docs_relayout` (新) | `recompute_layout` し、タブの行が出入りしたときは `relayout_for_font` (フォントの大きさの変更と同じ: 折り返しの区切りの見直し・`ensure_cursor_visible`・下の空きを詰める・全体の描き直し)。`docs_new` と `docs_close_now` が、新しい今の文書の状態を戻した後・`docs_enter` の前に呼ぶ |
| `editor/render.rb` `redraw_all`・`redraw_dirty` | タブの行を描く (上のとおり) |

`@edit_y` から読む所 (変えずに新しい数を見ていることを確認した): `ensure_cursor_visible`・`row_of`・`move_anchor` (スクロール)、`line_segments` (折り返しは幅だけで行の数に依らない)、`page_up`・`page_down` (`@edit_rows`)、`place_cursor_at` と編集の範囲のクリックの判定 (`@edit_y`・`@edit_rows`)、`cursor_cell_box` (カーソル・補完の候補・IME の位置)、`comp_origin` (補完の候補)、`draw_edit_area`・`draw_edit_row`・`redraw_dirty`、`fill_view_bottom`、デバッグのペイン (`@dbg_pane_y` は `@status_y` から決まり、`@edit_height` はそれと `@edit_y` の差)。検索・色・キーの一覧・保存の確認のダイアログは使える範囲の真ん中に出すので、行の数に依らない。全画面の切り替え・Window の大きさの変更・デバッグの開始と終わりも `recompute_layout` を呼ぶので、タブの行を保ったまま並べ直す。

## 2. 操作

### 2.1 キー

| キー | 動き | 所 |
|---|---|---|
| Ctrl+N | 無題を足す (File > New と同じ `docs_new`) | M1 のまま |
| Ctrl+W | 今の文書を閉じる。変更があれば確認 (`docs_close`) | M1 の「断る」をやめた |
| Alt+. / Alt+, | 次 / 前 (`docs_cycle(1)` / `docs_cycle(-1)`) | M1 のまま |
| Ctrl+PageDown / Ctrl+PageUp | 同じ (`docs_cycle(1)` / `docs_cycle(-1)`) | M1 のまま |
| Alt+1〜Alt+5 | その番目へ (`docs_switch(scancode - 0x1E)`。無ければ何もしない) | 新 |

Alt のキーは sim で送れないので、コードで確かめた: `ev_alt?` の case の `0x37`・`0x36` が Ctrl+PageDown (`0x4E`)・Ctrl+PageUp (`0x4B`) と同じ `docs_cycle(1)`・`docs_cycle(-1)` を呼び、`0x1E`〜`0x22` (HID の 1〜5) は `docs_switch` を呼ぶ。`docs_switch` は範囲の外と今の文書なら何もしない。カーネル・デスクトップの Ruby に Ctrl+PageUp/Down・Alt+数字を取るものは無かった (grep)。

### 2.2 File メニュー

`開く(O) / 新規(N) / 保存(S) / 名前を付けて保存(A) / ひな形(T) / 閉じる(C) / 終了(X)` (en: Open / New / Save / Save as / Template / Close / Exit)。Open を先頭のまま、New を 2 番目、Close を Exit の前に置いた。

- Open: 選んだファイルが開いていれば (パスが同じ。保存の窓が付ける先頭の `//` は 1 つと見なす) そこへ切り替える。今の文書が「無題・変更なし・1 行で空」ならそこへ読む。それ以外は文書を足して読む。足せない (5 つ、領域切れ) なら、ステータス行に出して何もしない。足した文書に読めなかったら、足した文書を閉じて元の文書に戻り、load_file の知らせ (「読み込めません」など) を出し直す。
- Template: ひな形を読めたら、今の文書が上と同じく空ならそこへ、そうでなければ足した文書へ入れる。足せなければ入れない。
- Exit: 終了の確認を通す (下)。

### 2.3 閉じる・終了の確認

ダイアログは終了の確認と同じもの (`quit_dialog_rect` の大きさ、`[Y]es [N]o [C]ancel/Esc`)。2 行目だけ、閉じるときは `Save before closing?` / `閉じる前に保存しますか?`、終了は今のまま `Save before exit?` / `保存しますか?`。`@dlg_kind` (`DLG_QUIT` / `DLG_CLOSE`) で分ける。

- Y: 保存して進む (閉じる、または次の変更のある文書へ)。無題なら保存の窓を出し、名前が返ってきて保存できたら進む (`@after_save`)。保存の窓を Cancel したら、その確認も取りやめる (文書はそのまま、エディタも終わらない)。保存に失敗したら同じ確認をもう一度出す。
- N: 閉じるなら変更を捨てて閉じる。終了ならその文書を「答えた」印 (`@quit_skip` のビット) を付けて次へ。
- C / Esc: 何もせず戻る。終了のときはその文書に留まる。
- 終了の順: 今の文書に変更があれば最初に、続けてタブの順。聞く前にその文書に切り替えるので、中身が見える。変更のある文書が無ければ聞かずに終わる。

## 5. 見立てと違った点・踏んだ罠

- **mruby の構成でタブの行を描くと落ちた** (`uninitialized constant EditorTabs::DOC_ST_N`)。`DOC_ST_*` は `EditorDocs` の定数で、mruby は別の module (`EditorTabs`) から裸の名前で見つけられない (Spinel は定数が平らなので通る)。文書ごとの `*` を読む口 `docs_saved_modified?` を `EditorDocs` に置いて、tabs.rb からはそれを呼ぶようにした。mruby のエディタはそれまで開いた直後に死んでいた (ビルドは通る、標準構成では起きない)。
- Spinel の生成 C: 足した ivar は `@tabs_on` が `sp_bool`、`@tab_y`・`@dlg_kind`・`@after_save`・`@quit_skip` が `sp_int`、`@tab_xs`・`@tab_ws`・`@tab_ids` が `sp_IntArray *`。`@tab_drawn_mod` だけ `sp_RbVal` (poly) になった (ヘルプの `@help_return_modified` が poly のため) が、比べ方は `sp_poly_eq(sp_box_bool(...), ...)` で正しい。タブの名前の組み立て (`tab_base_name`) は poly の文字列に `sp_poly_length_m`・`split` で、黙って 0 になる所は無かった。`mods` は 0/1 の整数の配列にした (真偽の配列を避けた)。
- sim の `/tmp` (ホストの `flash/tmp/`) は sim を上げるたびに空になる。試験のファイルは上げた後に置く。
- 開く窓が始める場所は、前に選んだフォルダのときと `/` のときがある (デスクトップの動き。エディタの変更とは関係ない)。

## 6. 確認していないこと

- 領域切れ (`EC_ERR_NOMEM`) での Open・New (起こせていない。コードの上では M1 と同じ `doc_full` を出して今の文書に戻る。Open は足す前に断られるので読まない)。
- タブが 4 字に詰めても入らず「今のタブから並べる」場合 (Retro の Window で長い名前 5 つでも 6 字で入った。日本語の長い名前なら起きうる)。
- 日本語のファイル名のタブ。
- Alt+. / Alt+, / Alt+1〜5 を実際に押すこと (sim は Alt を運べない。コードで確認、2.1)。
- 全部 mruby の構成のデバッグのペインとタブの行を同時に出すこと (デバッグのセッションは動かしていない)。並べ方は `recompute_layout` の同じ式に乗る。
- Retro の全部 mruby の構成を手で (回帰の場面だけ)。

## 7. 今のエディタの不具合 (この段では直していない)

## 8. M3 (外から開く・読む・書く) への引き継ぎ

今の `on_control(msg)` (`editor.app.rb`):

```ruby
if msg["cmd"] == "file_selected" && msg["path"]
  if msg["mode"] == "save" || @pending_file_op == :save
    save_file_as(path) ... run_after_save ... save_dialog_saved(path)
  else
    docs_open_path(path)            # opened beside the others, or switched to
  end
  @pending_file_op = nil
elsif msg["cmd"] == "file_selected"  # path nil: the file dialog was cancelled
  save_dialog_saved(nil)
elsif msg["cmd"] == "run_result"     # pid, path
  ...
end
```

- 外から開く (plan 4.4) は `elsif msg["cmd"] == "open_file"` を足し、`docs_open_path(msg["path"])` を呼べば plan 3 章の 3 の決まり (同じなら切り替え、空の無題ならそこ、5 つなら知らせる) がそのまま通る。今の起動 (`open_path`) はカーネルが `file_selected` (mode 無し) で渡すので、起動したばかりのエディタは空の無題に開く。
- 「ダイアログを出している最中」の見分け: 保存の確認は `@quit_dialog_open` (種類は `@dlg_kind`)、保存の窓の返事待ちは `@after_save != 0` (と `@pending_file_op`)。ほかのモーダルは `@active_menu`・`@search_open`・`@palette_open`・`@keys_open`・`@comp_open`・`dbg_modal?`。`docs_switch` は切り替えの前にメニュー・検索・色・キーの一覧・補完・ヘルプを閉じる (`docs_leave`) が、保存の確認は閉じない。
- 外から読む・書く (plan 4.5) の材料: 今の文書は `EditorCore.doc_index` / `doc_count`、名前は `tab_path(i, cur)` (無題は "")、変更の印は今の文書が `@modified`、ほかは `docs_saved_modified?(i)`。文書の版は無い (M3 で足す)。
