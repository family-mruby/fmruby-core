## 1. 型紙の要点 (sig/README.md)

- **「書き方の約束」の必須引数の項**: 決定 2 に合わせて書き直した。いちばん多い呼び方を必須引数の形でシグネチャに
  し、残りの呼び方は長文に書く。前の文にあった「型推論エンジンは省略可能引数もキーワード引数も持たない」は
  消した (今のエンジンには当てはまらない。5.1)。
- **素直かつまずくかの目安** (二層の項の下): シグネチャと名前から読めない振る舞いがあるか。失敗のしかた
  (nil・false・何も起きない・例外) が名前から分からない、先に呼ぶもの・呼べる場面がある、数え方や単位が見かけと
  違う (バイトか文字か、ms か µs か)、省略できる引数・キーワードがある、似た名前と振る舞いが違う。どれか 1 つで
  「つまずく」。迷ったら実装を読み、読まないと書けなかったことがあれば「つまずく」。
- **新しい節「つまずく API の型紙」**: 長文の順番を 1 何をするか → 2 引数の意味 (シグネチャで分からないものだけ)
  → 3 戻り値と失敗のしかた (例外の名前・nil・false・何も起きない。「例外は出ない」も書く) → 4 使う順番と前提 →
  5 短い例 (39 桁、`#=>`)。日本語 → `<<en>>` の行 → 英語を同じ順。`byteslice` を縮めた見本に段の番号を振って載せた。
- **新しい小節「キーワード引数・省略できる引数」**: 長文の 2 に「キーワード: `name:` (省略すると…)」の形で並べる。

## 2. String#byteslice の実装で確かめたこと

読んだ実装: mruby (`lib/upstream/patch/picoruby-mruby/lib/mruby/src/string.c` の `mrb_str_byteslice` と
`mrb_str_beg_len`。上流の string.c と同じ関数)、Spinel (`vendor/spinel/lib/sp_str.c` の `sp_str_byteslice`・
`sp_str_byteslice1`・`sp_str_byteslice_range`、呼び分けは `src/codegen_call_recv.c`)。

| 呼び方 | 振る舞い | sim の irb (mruby) で |
|---|---|---|
| `s.byteslice(start, len)` | start が負なら末尾から。len が残りより長ければ末尾まで | `"あいう".byteslice(3, 3)` → `"い"`、`(-3, 3)` → `"う"`、`(3, 99)` → `"いう"` |
| start がちょうど `bytesize` | `""` | `(9, 1)` → `""` |
| start が `bytesize` より先・len が負 | `nil` (例外なし) | `(10, 1)` → `nil`、`(0, -1)` → `nil` |
| `s.byteslice(i)` | その 1 バイト。`i >= bytesize` は `nil` | `(4)` → `"\x81"`、`(9)` → `nil` |
| `s.byteslice(range)` | 範囲の端をバイトで解く | `(3..5)` → `"い"` |
| 文字の途中で切る | 止まらず、欠けたバイトのまま返る | `(1, 3).bytesize` → `3` |
| 引数 0 個・3 個 | mruby は ArgumentError | (試していない) |

- **エンジンの違い**: 上の 6 つの形で、mruby と Spinel の振る舞いは同じ (Spinel は 2 引数・1 引数・Range を別の関数に
  分けるが、nil になる条件は mruby と同じ)。Spinel は実装を読んだだけで、Spinel の上で動かしてはいない。
- **`index` も文字の位置**: mruby (`MRB_UTF8_STRING`、`str_index_str_by_char`) も Spinel (`sp_str_index`、
  バイナリでない文字列) も、`String#index` の答えは文字の位置。`byteslice` にそのまま渡すと日本語でずれるので、
  長文の「組み合わせてはいけないもの」に入れた。
- **アプリでの使われ方**: grep で `flash/app/`・雛形・見本の 54 か所 (試験と生成の台本を含む。道具の数え方では 34 回・11 ファイル) が全部 2 引数の形。
  シグネチャは `(Integer start, Integer length) -> (String | nil)`。多くが `.to_s` を続けている (nil のときに "" に
  するため。Spinel の型を決めるためでもある) ので、長文に「続けて文字列のメソッドを呼ぶなら `.to_s`」と書いた。
