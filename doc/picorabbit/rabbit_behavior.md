# 本家 Rabbit の挙動 (移植の基準にする事実)

Family mruby の PicoRabbit は Harucom 向け PicoRabbit の形式 (YAML
frontmatter、`{::wait/}`、`{:.center}`) を読むが、**発表中の振る舞いは本家
Rabbit に合わせる**。本書は本家の公開資料とソースから確かめた事実だけを
書く。解釈や我々の決定は plan.md / instruction_*.md 側。

## うさぎと亀

| | 何を表すか | 位置の式 | 更新 |
|---|---|---|---|
| うさぎ | **発表の進み** (今のスライド) | `(index - 1) / (n - 2)`、1 で止める。index 0 はタイトル | スライド切替時 |
| 亀 | **時間** (持ち時間の消化) | `1 - 残り時間 / 持ち時間` | 5 秒ごと |

- **タイトルスライドは競走に数えない**。最初の本文スライドが出発点、最後の
  スライドがゴール。スライドに `image-slide-number-last-slide: true` を
  付けると、そのスライドがゴールになる (質疑や付録をコースから外す用)。
- スライドが 3 枚未満なら、うさぎは常にゴール。
- **亀はゴールで止まらない**。持ち時間を過ぎると式が 1 を超え、そのまま
  右へ歩き続ける。残り時間の数字表示 (timer テーマ) は負の値を赤で出す。
- 出発点とゴールに旗 (出発 赤、ゴール 青) を描くテーマがある。
- 絵の高さは画面高さの 1/12。絵の下に半透明の鏡像を描く。
- 亀が同じ位置のうさぎより先に出たら自動でページを送る設定もある
  (既定は無効)。
- 居眠り・焦り・ジャンプの表情は**本家には無い**。

## 持ち時間の指定

- `allotted_time` (タイトルスライドのメタ情報) か起動オプション。
  オプションが優先。
- 値の書式は `5m` のように単位付き (`h` / `m` / `s`)。
- `start_time` と `end_time` の両方があれば、そこから計算される。
- タイトルスライドのメタ情報: `author` `institution` `subtitle`
  `content_source` `date` `start_time` `end_time` `allotted_time` `theme`。

## キー操作

「次」と「次のスライド」は別。「次」はスライド内の段階送り (wait) を
1 つ進め、「次のスライド」は段階を飛ばして次のスライドへ行く。

| 操作 | キー |
|---|---|
| 次 (段階送り) | Space / Enter / PgDn / Tab / `n` `f` `j` `l` / `+` |
| 次のスライド | Right / Down |
| 前 (段階戻し) | PgUp / BackSpace / Delete / `p` `b` `h` `k` / `-` |
| 前のスライド | Left / Up |
| 最初 | Home / `a` / `<` |
| 最後 | End / `e` / `>` / `$` |
| 終了 | Esc / `q` |
| 全画面切替 | F5 / F10 / F11 |
| 索引モード (一覧) | `i` |
| 情報ウィンドウ | Shift+i |
| 検索 (前方 / 後方) | `/` / `?`、次の候補 `n`、中止 Esc |
| 白画面 / 黒画面 | Shift+w / Shift+b |
| 落書きモード | Shift+g (取消 Ctrl+z、消去 Ctrl+l) |
| **タイマーを元に戻す** | **Alt+t** |
| 位置調整を戻す | Alt+a |
| テーマ再読み込み | `t` / `r` |
| 画像として保存 | `s` |

## マウス

| 操作 | 動作 |
|---|---|
| 左クリック | **次のスライド** (段階送りではない) |
| 中クリック | 前のスライド |
| 右クリック | メニュー |
| 左ダブルクリック | 索引モード中のみ: そのスライドへ飛ぶ |
| Ctrl + 左クリック | メニュー |

## Markdown (本家の流儀)

- `#` が新しいページ。最初のページがタイトルページで、メタ情報は
  定義リスト (`author` の次の行に `:    名前`) で書く。
- **改行は無視されない** (通常の Markdown と違う)。
- 強調 `*x*`、画像、表、箇条書き (`*` `+` `-`)、引用 `>`。
- Harucom 版 (= 我々の入力形式) は YAML frontmatter と `{::wait/}` を
  使う点が本家と違う。
