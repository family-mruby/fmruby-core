# P3 report: 発表者支援

対象: `flash/app/tool/picorabbit.app.rb`、
`lib/add/picoruby-fmrb-picorabbit/mrblib/` の renderer / parser / slide。
指示書は `doc/picorabbit/instruction_p3.md`。

## キー割り当て

指示書の確定版どおり。**発表者支援は Shift 層**に置いた (素の t / p / b / w
は P0 で「タイマー戻し」「前」に使ってしまっている)。判定は基底の
`ev_shift?` (修飾バイト bit0/1)、scancode は P0 と同じ `FmrbConst::KEY_*`。

| 操作 | キー |
|---|---|
| 黒画面 / 白画面 | Shift+b / Shift+w |
| 残り時間の表示 | Shift+t |
| タイマー一時停止/再開 | Shift+p |
| 索引 | `i` (Esc / `i` で戻る) |

## T1: タップの左右分割

`mouse_up` の左ボタンは **x が画面の右半分なら次のスライド、左半分なら前**。
中/右ボタンは前。本家のクリックは段階送りでないので、**タップも wait を
飛ばす**。

## T2: 黒画面 / 白画面

画面全体を 0x00 / 0xFF で塗り、スプライトは park と同じ `sprites_visible`
で隠す。**どのキーでもタップでも元に戻るだけ**で、そのキーの動作はしない。
黒白中も時間は進み、`on_update` は何も描かない。park (Ctrl+Tab) から
戻ったときに黒白中なら黒白のまま復帰する。

## T3: 残り時間と一時停止

- 残り時間はフッタの**ページ番号の左**、size 1、`MM:SS`。超過は `-MM:SS` を
  赤 (0xE0)。箱の位置はページ番号が最大幅になったときを基準に決めてあるので、
  ページが進んでも動かない。
- 更新は `on_update` の 1 秒周期に相乗りし、**文字が変わったときだけ**
  その箱を塗って描く。放置中の present は 1/s のまま。
- Shift+p は「停止した時刻」を覚え、再開時に `@start_ms` へ停止していた
  長さを足す。停止中は表示を強制 ON にし、`||` を前置する。
- `t` (タイマー戻し) は停止も解除する。

## T4: 索引

`i` で全スライドの見出しを 1 行ずつ (size 1、`N. 見出し`、`truncate_to_width`
で 1 行に)。20 枚を超えたら 2 列。**選択行は青バー + 黄文字、今いる
スライドは行頭に `>`**。Up/Down/PgUp/PgDn/Home/End で選択、
Enter / Space / Right で飛ぶ、**行のタップで即座に飛ぶ** (本家はダブル
クリックだが、タッチで打ちにくいのでシングル)。`i` / Esc で何もせず戻る。

**ヘッダの右端に「残り時間 現在/枚数」を出す** (ユーザ提案)。索引は
「残り時間に対してどこへ飛ぶか」を決める場面で開くので、そこに残り時間が
あると判断が一画面で済む。描画は T3 と同じ経路 (size 1、超過は赤) で、
索引を開いたときと選択が動いたときだけなので present は増えない。

索引中はスプライトを隠し、タイマーは進め続ける。`on_update` は何も描かない
(= 索引を開いている間ヘッダの時刻は止まって見えるが、開き直せば最新になる)。

## T5: ゴールを手前に置く

スライドの中に `{::goal/}` の行があれば、そのスライドがうさぎのゴール。
`{::wait/}` と同じ場所で parser が拾い、`Slide#goal` に持つ (複数あれば
最初のもの)。`rabbit_progress` は分母にゴールのインデックスを使い、
ゴール以降のスライドではうさぎは 1.0 で止まる。

## T6: 時間切れの合図

frontmatter `chime: true` のときだけ、亀が 1.0 に達して banzai に変わる
**その 1 回**、`note_on` を 1 回。切るのは次の周期 (跳躍中と同じく戻り値を
200 にして 200ms で戻る)。定常経路に `sleep` は入れていない。
`t` で戻して再び時間切れになれば、また 1 回鳴る。

## 検収 (Linux sim, headless, 426x240)

| 項目 | 結果 |
|---|---|
| タップ左右 | 右半分 3/6 -> 4/6、左半分 4/6 -> 3/6 -> 2/6 -> 1/6 |
| タップが wait を飛ばす | wait のある「Slide Two」で「after the wait」を出さずに次へ |
| 黒画面 | 全画素 0x00 (スプライトの帯も)。`n` で復帰し、本文は blank 前と **0 differing pixels** = ページは飛ばない |
| 白画面 | 全画素 0xFF、タップで復帰、同じく 0 差分 |
| 残り時間 | `00:59` -> 10 秒後 `00:49`。超過は `-00:19` が **#ff0000**、ページ番号は従来色 |
| 一時停止 | `\|\|00:42` で 20 秒、**画面全体で 0 differing pixels**。再開 9 秒後に `00:34` = 止めた分だけ戻して継続 |
| 索引 | ヘッダに `00:51 1/6`。Down 2 回で選択が 3 行目へ (`>` は 1 行目のまま)、Enter で「Slide Two」へ。行のタップで「Slide Four」へ。`i` -> `i` で本文が **0 差分** |
| ゴール | `{::goal/}` の「Slide Four」でうさぎ x=406、その次の「Questions」でも同じ位置 |
| chime | `chime: true` で `sounding_windows=5` (peak 3072)、`chime` 無しでは **0 / peak 0** |
| 回帰 | demo.md 全 11 枚・demo_ja.md 全 6 枚とも P2 と **0 differing pixels** |
| ログ | E / Exception **0**、放置中 1.0 presents/s |

## 途中で見つけて直した 2 件

1. **一時停止中に亀の歩きコマだけ動いていた**。`turtle_frame` が壁時計
   (`board_millis`) で足を数えていたため。亀が持っている時計 (`elapsed_ms`)
   で数えるように直し、停止中は脚も止まるようにした。
2. **一時停止の瞬間にスプライトが 5px だけ後から追いついていた**。
   `toggle_pause` は時計しか描き直しておらず、走者は次の 1 秒周期で
   「止まった時刻の位置」へ動いていたため。時計を触るキー
   (Shift+p / Shift+t / `t`) は `refresh_race` で走者と時計をまとめて
   合わせるようにした。これで停止中の画面全体の差分が 0 になった。

## 実機 (Tab5) 確認

`FMRB_HW_TARGET=TAB5 rake build:esp32` -> `rake flash` (USB-Serial-JTAG、
ボタン操作なし)。ブートログは `Guru|abort` が **0**、
`Remote desktop ready: http://192.168.10.21/` まで到達。以降は WiFi 経由
(`fmrb_rd_launch` / `fmrb_rd_input` / `fmrb_rd_snap`) で操作した。
デッキは実機に入っている `demo.md` (`allotted_time: 5`)。

| 項目 | 実機での結果 |
|---|---|
| タップ左右 | 右半分 1/11 -> 2/11、左半分 2/11 -> 1/11 |
| Shift+t | `04:16` -> 10 秒後 `04:05` |
| Shift+b | 画面全体が黒。`n` で 5/11 のまま復帰 (ページは飛ばない) |
| Shift+w | 画面全体が白。タップで 9/11 のまま復帰 |
| Shift+p | `\|\|02:44` で 15 秒不変、再開 6 秒後に `02:37` = 止めた分を戻して継続 |
| 索引 | ヘッダに `03:46 3/11`。Down 2 回で選択が「5. Features」へ (`>` は 3 行目のまま)、Enter で 5/11 へ |
| 索引のタップ | 9 行目のタップで 9/11「Goals」へ |
| 生存 | 一連の操作のあとも `/app/list` で PicoRabbit が RUNNING |

**Shift 層が実機でも通る**ことが確認できた点が大きい (sim の注入と実機の
USB HID は別経路)。

実機で確認**できていない**もの:

- `{::goal/}` と chime。実機に入っているデッキがどちらも使っていないため
  (sim では確認済み)。試すなら該当のデッキを `flash/home/slides/` に置いて
  storage を焼き直す必要がある。**chime の音色そのものはユーザ確認**。
- 操作中のランタイムログ。シリアルを開くとボードがリセットされるので、
  セッションの最初に開いたまま保持していないと後から読めない
  (今回は flash 直後のブートログだけ取得した)。
