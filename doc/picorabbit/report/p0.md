# P0 report: 土台直し

対象: `flash/app/tool/picorabbit.app.rb` と
`lib/add/picoruby-fmrb-picorabbit/mrblib/picorabbit_renderer.rb`。
指示書は `doc/picorabbit/instruction_p0_p1.md`。

## 1. うさぎ = 発表の進み、亀 = 時間

`render_timer` の配線を入れ替えた。位置の計算は本家の式に合わせて 2 つの
私有メソッドに分けてある。

- `rabbit_progress(slide_idx, total_slides)` = `(slide_idx - 1) / (total_slides - 2)`
  を 0..1 に丸める。タイトルスライドは競走に数えないので、最初の本文
  スライド (index 1) が出発点、最後 (index n-1) がゴール。スライドが
  3 枚未満なら常に 1.0。
- `turtle_progress` = `elapsed / allotted_ms`、1.0 で止める。本家はゴールを
  過ぎても歩き続けるが、P1 で万歳させるためここで止める (指示書の決定)。
- ジャンプ物理 `@usagi_jump_y` はうさぎの描画に付け替えた。元は緑の `*`
  = 亀側に付いていた。
- 色はうさぎ `timer_rabbit`、亀 `timer_turtle`。絵は P1 で置き換わるので、
  ここでは `*` (うさぎ) と 4x4 の矩形 (亀) のまま向きだけ直した。

### allotted_time の読み方

`parse_allotted_ms` を renderer に足した (旧 `to_i` の場所)。

| 値 | 解釈 |
|---|---|
| `5` | 5 分 (Harucom 形式。demo.md がこれ) |
| `90s` | 90 秒 |
| `5m` | 5 分 |
| `1h30m` | 90 分 |
| `abc` / `0` / `1h30` (単位なしの端数) / 無し | タイマー無し |

ホストの ruby で表の全件を確認済み。

## 2. ev[:scancode] に揃えた

`ev[:keycode]` と `ev[:character]` の比較を全部消して `ev[:scancode]` に
した。定数は既存アプリ (shooter, robo_explorer, file_manager) と同じ
`FmrbConst::KEY_*` — これはもともと USB HID Usage ID の値なので、
アプリ内に新しい定数は置いていない。

本家に合わせて「次 (段階送り)」と「次のスライド (段階を飛ばす)」を分けた。
`next_slide` / `prev_slide` を app 側に足してある。

| 操作 | キー |
|---|---|
| 次 (wait を 1 つ進める) | Space / Enter / PgDn / Tab / n f j l |
| 次のスライド (wait を飛ばす) | Right / Down |
| 前 (wait を 1 つ戻す) | PgUp / BackSpace / p b h k |
| 前のスライド | Left / Up |
| 最初 / 最後 | Home, a / End, e |
| 終了 | Esc / q |
| うさぎジャンプ | u |
| タイマーを元に戻す | t (`FmrbRenderer#reset_timer`) |

## 3. draw_text_mixed と画素幅の折り返し

- 見出し (タイトルスライド・タイトルバー)、本文、箇条書き、番号付き、
  引用、フッタのスライド名を `draw_text_mixed` にした。コードブロックと
  inline code は ASCII 前提なので `draw_text` のまま。
- 幅は全部 `@gfx.text_width(str, :default)` の画素幅。`text_width` は
  現在の text_size を掛けて返すので、見出しは `set_text_size(2)` の後に
  測っている。
- `draw_rich_text` を折り返し付きに書き直し、`draw_rich_text_at` は
  役目が同じなので消して 1 本にまとめた (色と最大幅を引数に取る)。
  箇条書き・番号付き・引用もこれを通るので折り返す。戻り値は次の行の y。
- 折り方: ASCII は語単位、和文は空白が無いので文字単位。行末の空白は
  行を閉じるときに落とす (中央寄せ・右寄せの幅がずれるため)。
  1 行に収まらない長い語 (URL や識別子) は画面幅で強制的に割る。
  禁則処理はしない (plan の P2)。

## 4. on_update の帯塗り

指示どおり P0 では触っていない (200ms 周期のまま)。P1 で消える。

## 5. テーマ既定

`Theme.default` の `bg` を `FmrbConst::THEME_WINDOW_BG`、`text` を
`FmrbConst::THEME_TEXT` にした。

実際の値は `window_bg = 0xFF` (白) / `text = 0x00` (黒) なので、既定
テーマの地色は黒から白に変わる。最初は bg と text だけを直したが、
そうすると `quote_text` (0xDB、明るい灰) と `footer_bg` (0x00、黒帯) が
白地から浮いた。**この 2 つは演出色ではなく「地に対して決まる色」**なので、
地と一緒に動かすことにした (ユーザ判断)。

| 色 | 変更後 | 役 |
|---|---|---|
| `bg` | `THEME_WINDOW_BG` | 地 |
| `text` | `THEME_TEXT` | 本文 |
| `footer_bg` | `THEME_WINDOW_BG` | 地と同じ (黒帯を消す) |
| `footer_text` | `THEME_BORDER` | 基底が「罫線・枠・控えめな文字」に当てている色 |
| `quote_text` | `THEME_BORDER` | 同上 |
| `quote_bar` / `title` / `title_bg` / `bullet` / `code_*` / `inline_code_*` / `timer_*` | 据え置き | 演出色 |

**旧来の黒いパレットは `theme: dark` として残した** (`Theme.default` の
元の中身をそのまま `Theme.dark` に改名し、`for_name` に追加)。frontmatter
1 行で黒地に戻せる。`light` は変えていない。`for_name` の既定 (未知の名前)
は従来どおり `default`。

## 検収 (Linux sim, headless, 426x240)

ビルドは `rake clean_all` -> `rake build:linux`。
`file build/fmruby-core.elf` が x86-64 であることを確認してから起動した。

キャラクタの位置は `tools/fmrb_pngscan.rb <png> row 237` で読んだ。
トラックは `track_left = 12`、`track_w = 402` (画面幅 426)。
うさぎは `*` の描画で `x-2` から 5px、亀は `fill_rect` で `x-2` から 4px。

### キー (demo.md, 11 枚)

| 確認 | 結果 |
|---|---|
| Space で wait が 1 つ進む | 3/11 のまま `{::wait/}` 後の一行が出る |
| Right で wait を飛ばして次のスライド | 3/11 (step 0) -> 4/11 |
| l / e / a / Left / Home / End | 5/11 / 11/11 / 1/11 / 1 枚戻る / 先頭 / 末尾 |
| 順送りキー一式 (Down Enter Tab PgDn n f j) | 1/7 -> 7/7、末尾で止まる |
| 逆送りキー一式 (PgUp BackSpace p b h k Up) | 7/7 -> 1/7、先頭で止まる |

| u | うさぎの `*` が row 234-239 -> 225-231 に上がり、着地して戻る |
| t | 亀が x=414 (ゴール) -> x=12 (出発点)、うさぎは動かない |
| Ctrl+Tab | park でデスクトップ、復帰で 11/11 のまま戻る |

Space と Right の 2 枚: `10_wait_step0.png` (3/11、wait 前) と
`11_wait_step1.png` (3/11、wait 後) / `12_right_skips.png` (4/11)。

### タイマーの向き (allotted_time: 1 の一時 .md、本文 6 枚 + タイトル)

| 時刻 | ページ | うさぎ x | 期待 | 亀 x | 期待 |
|---|---|---|---|---|---|
| 起動直後 | 1/7 | 12 (0%) | 0% | 12 (0%) | 0% |
| +38s | 1/7 (送っていない) | 12 (0%) | 0% | 266 (63.2%) | 38/60 = 63.3% |
| +56s、3 回送った直後 | 4/7 | 172 (39.8%) | (3-1)/(7-2) = 40% | 386 (93.0%) | 56/60 = 93.3% |
| +90s | 4/7 | 172 (39.8%) | 40% | 414 (100%) | 1.0 で停止 |

**ページを送ったときだけ動くのがうさぎ、時間だけで動くのが亀**であることが
数字で出ている。1 分を過ぎても亀はゴールから先に行かない。

demo.md (11 枚) 側でも `(slide_idx - 1) / (total_slides - 2)` の一致を確認:
3/11 (index 2) で 10.9% (期待 11.1%)、4/11 (index 3) で 22.1% (期待 22.2%)、
11/11 (index 10) で 100%。タイトル (index 0) は 0% に丸められる。

### allotted_time の書式

| 値 | sim での結果 |
|---|---|
| `5` (demo.md) | 5 分ぶんの速さで亀が進む (48 秒で 16.2%) |
| `90s` | 90 秒ぶんの速さ (22 秒で 23.9%)、90 秒でゴールに止まる |
| `1` | 上の表のとおり |
| `later` (数えられない値) | トラックもキャラクタも出ない。エラーも出ない |

### 地に相対する色と `{:.center}` の付け先 (2 巡目)

`51_center_last.png` (demo.md 11/11 「Thank you!」):
**3 か所とも中央に来る**。フッタは黒帯ではなく地と同じ白になり、

  ここでは指示どおり `THEME_BORDER` を使っている。

`53_dark.png` (一時 .md、`theme: dark`、`allotted_time: 5m`):
黒地・白文字・灰フッタの旧パレットがそのまま出る。frontmatter 1 行で

## 6. `{:.center}` の付け先 (追加で直した)

パーサは配置指示を**直前の要素**に付けていたが、demo.md は

```
Family mruby OS
<空行>
{:.center}
```

と書いてあるので、指示が空行の要素 (`:blank`) に付いて消えていた。
P0 の変更前からの挙動。**最後の非空行要素まで遡って付ける**ように直した
(前に何も無ければ捨てる)。demo.md 末尾の 3 か所が意図どおり中央に来る。

## 直さなかった気づき

- **`update_rabbit` が 1 周期に 2 回進む**。`on_update` が呼んだ後、
  `redraw_timer_area` -> `render_timer` の中でもう一度呼ばれる。ジャンプが
  本来の倍の速さで終わる (実測 2 枚のキャプチャで往復)。これも P0 前からの
  配線で、**P1 で `on_update` を書き直すときに自然に片付く**ので触らない
  (ユーザ判断)。
