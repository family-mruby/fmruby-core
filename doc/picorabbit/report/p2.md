# P2 report: 日本語の発表で使える本文にする

対象: `lib/add/picoruby-fmrb-picorabbit/mrblib/picorabbit_renderer.rb` と
`flash/home/slides/demo_ja.md` (新規)。指示書は
`doc/picorabbit/instruction_p2.md`。

parser は触っていない (ルビは inline なので `parse_inline` の担当、
配置指示との衝突は `{:` を除くだけで済んだ)。app 側も触っていない。

## T1: 本文の文字サイズ

`text_size: 1 | 2` を frontmatter で受ける (既定 1、それ以外の値も 1)。
`@ts` に持ち、**見出しは本文より 1 段大きく上限 3** (`@hs`)。

size 1 前提だった定数は初期化時に 1 度だけ倍にして、instance 変数として
持ち回る。定数のままにしたのは「size 1 のセルの寸法」の定義だけ。

| 変数 | 中身 | 本文 1 | 本文 2 |
|---|---|---|---|
| `@char_w` / `@char_h` | 本文 1 文字 | 6 / 8 | 12 / 16 |
| `@line_h` | 行送り | 10 | 20 |
| `@head_h` | 見出し 1 文字の高さ | 16 (size 2) | 24 (size 3) |
| `@title_bar_h` | タイトルバー | 20 | 28 |

追従させたもの: 行送り、文字高、箇条書きのインデントと marker 幅、
番号付きのインデント、引用バーの高さ、コードブロックの行高・内側余白・
桁数、段落間の `@line_h / 2`、`max_y` の打ち切り判定。
**変えないもの**: 左右の余白 (`MARGIN_X`)、フッタ (ページ番号とスライド名は
size 1 のまま)、スプライトとトラック。

### 測るときのサイズ

`text_width` は**現在の text_size を掛けて返す**。一方 1 行の中には
本文サイズの base と size 1 のルビが同居する。そこで

- `w1(str)` = キャンバスを size 1 に固定して測る -> 呼び出し側が掛ける
- `set_ts(size)` = 現在のサイズを覚えていて、変わるときだけコマンドを出す

に統一した。折り返し・中央寄せ・切り詰めは全部 `w1` 基準。
`truncate_to_width(str, w, size)` は測る対象のサイズを引数で受ける。

### fmrb ブロック

**ブロックの実行前にキャンバスを size 1 に固定する**。ブロックは
`6px * 桁数` で文字を置くように書かれている (demo.md のものがそう) ので、
本文 size 2 のときに 2 倍のままだと枠から出る。実行後は
`@cur_ts = nil` にしてキャッシュを捨てる (ブロックが自分でサイズを
変えているかもしれないため)。

## T2: ルビ `{漢字|かんじ}`

3 段すべてに 1 種類ずつ足した。

- `parse_inline`: `{` の次が `:` **でない**ときだけ候補として読み、`|` と
  `}` が揃えば `[:ruby, base, ruby]`。揃わなければ普通の文字。
  `{::wait/}` / `{:.center}` は行頭で先に処理されるが、`{:` を除いて
  二重に守ってある。
- `layout_rich_text`: ルビ区間は**分割しない 1 語**。幅は base (本文
  サイズ) と ruby (常に size 1) の**広い方**。1 行に入らなければ次の行へ。
  piece は `[:ruby, base, 幅, ruby, base幅, ruby幅]` の 6 要素。
- `draw_rich_line`: **2 周**する。1 周目が本文サイズで base を、2 周目が
  size 1 でルビを描く。piece ごとにサイズを往復させないため。
  狭い方が広い方の中央に来るように置く。
- 行の高さ: ルビを含む行だけ `RUBY_H = 8` を上に足す (行頭 y にルビ、
  その 8px 下に base)。含まない行は従来どおり。`push_line` が行ごとに
  `has_ruby` を返し、`draw_rich_text` の戻り値にも足す。
- 本文 size 1 のときルビも 8px で同じ大きさになるが、指示どおりそのまま
  描く (「ルビは常に size 1」で一貫させる)。

## T3: 日本語のサンプル

`flash/home/slides/demo_ja.md` (6 枚)。frontmatter は `title` (`<br>` 入り) /
`subtitle` / `author` / `allotted_time: 5m` / `text_size: 2`。和文の段落
(折り返す長さ)、箇条書き 2 段、番号付き、引用、inline code、太字、
ルビ 2 か所 (文頭の `{基板|きばん}` と文中の `{侮|あなど}`)、
`{::wait/}` 1 か所、`{:.center}` 1 か所、`fmrb` ブロック 1 つ。
demo.md (英語) はそのまま。

**書きながら 1 つ踏んだ**: 最初 `` `{漢字|かんじ}` `` と書いてルビの書式を
inline code で見せようとしたが、**inline code は Font0 で描くので和文が
出ない** (P0 でそう決めた)。サンプルの側を ASCII (`{kanji|kana}`) に直した。
ホストのテストに「inline code に多バイトが入っていないか」の検査を足して
ある。

### demo_ja.md (text_size: 2)

| 見たもの | 結果 |
|---|---|
| 表題 | 見出しサイズ 3、副題と著者は本文サイズ 2、どちらも中央 |
| 本文の折り返し | 画面幅で折れる (3 行に流れる)。**右余白 (x=423-425, y=0-213) は全 6 枚とも地の色だけ** (カーソルを置いた行を除く) |
| ルビ | `きばん` の字画が row 43-48、base `基板` は row 50 から。**ルビの升目は base の 8px 上** |
| 見出しの切り詰め | 長い見出しの最後の字が x=408 で止まり、409-425 はタイトルバーの地色。size 3 の 1 字 (24px) が入らないところで切れている |
| コードブロック | 本文サイズ 2 で描かれ、枠の中に収まる。構文色つき |
| inline code / 太字 | 本文サイズ 2。太字は和文でも mixed で出る |
| `{::wait/}` | Space で段階が進み、`**下から上まで...**` が出る (4/6 のまま) |
| `{:.center}` | size 2 でも中央にそろう |
| `fmrb` ブロック | size 1 で描かれ、和文ラベルが枠に収まる (本文サイズに引きずられない) |
