対象: 実装担当セッション。作業リポジトリ: fmruby-core。
先に読むもの: plan.md の P3、rabbit_behavior.md (キーとマウスの表)、

## キー割り当て (P0 との衝突を解いた確定版)

plan.md の P3 は `T` / `P` / `B` と書いているが、P0 で `t` = タイマーを
元に戻す、`p` = 前 (本家) を使ったので、**発表者支援は本家と同じく
Shift 層に置く**。本家が Shift 層で使っているのは w / b / e / n / g / i、
空いている文字を使う。

| 操作 | キー | 本家 |
|---|---|---|
| 黒画面 | Shift+b | 同じ |
| 白画面 | Shift+w | 同じ |
| 残り時間の数字を出す/消す | **Shift+t** | 本家は timer テーマで常時表示 |
| タイマー一時停止/再開 | **Shift+p** | 本家に無い |
| 索引モード | `i` (Shift なし) | 同じ |
| 索引モードから戻る | `i` / Esc | 同じ |

Shift の判定は基底の `ev_shift?(ev)` (修飾バイトの bit0/1)。scancode は
P0 と同じ `FmrbConst::KEY_*`。sim の注入は `fmrb_input.rb key shift+b`。
**Shift なしの b / w / t / p は P0 の割り当てのまま** (前 / 前 / タイマー
戻し / 前)。

## T1: タップとマウスボタン (座標に依存させない)

**当初の「画面の左右半分で分ける」案は実機で不成立だった** (2026-08-23、
Tab5 で確認)。Tab5 のタッチはトラックパッド式の相対移動で、タップは
**指の位置ではなくカーソルがいる位置**でのクリックになる
(main/drivers/touch/touch_task.c 冒頭の設計)。左半分を叩いても直前の
カーソル位置でクリックされるので、x で分ける判定は意味を持たない。
注入イベント (座標つき) では通ってしまうため、sim と rd_input では
見つからない。

確定版 (座標を見ない):

| 入力 | 動作 |
|---|---|
| button 1 (1 本指タップ / 左クリック) | **次のスライド** (本家のクリックと同じ。段階送りでない) |
| button 2 / 3 (Tab5 の 2 本指タップ / マウスの中・右) | **前のスライド** (本家の中クリック相当) |

- `ev[:x]` は判定に使わない。今の「どこを押しても `advance` (段階送り)」も
  捨てる。
- 索引モードの行タップはそのまま (カーソルを行に乗せてタップ、という
  デスクトップ全体と同じ作法で動く)。黒白画面中の扱いは各項に書く。
- 検収は rd_input の `click` / `rclick` で通るが、**実タッチでの確認は
  ユーザに依頼する** (注入では相対移動の経路を通らない)。

## T2: 黒画面 / 白画面

- Shift+b で画面全体を黒 (0x00)、Shift+w で白 (0xFF) に塗って present。
  スプライトは `sprites_visible = false` で隠す (park と同じ経路)。
- **どのキーでもタップでも元に戻る** (戻るだけで、そのキーの動作はしない。
  発表者が「戻したつもりでページが飛ぶ」事故を避ける)。戻るときは
  `render_slide` で描き直し、スプライトを戻す。
- 黒白中も時間は進む (タイマーは止めない)。`on_update` は黒白中は
  スプライトを動かさない (隠れているので present 不要)。

## T3: 残り時間の数字と一時停止

- Shift+t で表示/非表示。表示位置は**フッタの右端** (ページ番号の左)、
  size 1、`MM:SS`。`allotted_time` が無ければ何も出さない。
- 残りが負になったら `-MM:SS` を **赤** (`timer_rabbit` でなく専用に
  `FmrbGfx::RED` 相当の 0xE0) で。本家 timer テーマの「超過は赤」。
- 更新は `on_update` の 1 秒周期に相乗り: 表示中は**亀と同じ present に
  載せる** (present を増やさない。表示 ON でも放置中 1/s のまま)。
  フッタのその部分だけ地色で塗ってから数字を描く (帯全体は塗らない)。
- Shift+p で一時停止/再開。停止中は `turtle_progress` が止まり、残り時間も
  止まる。実装は「停止開始時刻」を持ち、再開時に `@start_ms` へ停止していた
  長さを足す。停止中は数字表示を**強制 ON** にし、数字の前に `||` を付けて
  停止中と分かるようにする (再開で元の表示状態に戻す)。
- `t` (タイマー戻し) は停止中でも効く (戻した上で停止は解除)。

## T4: 索引モード

- `i` で開く。**スライド番号と見出しの一覧**を画面いっぱいに描く
  (size 1、1 行 1 枚、`N. 見出し`。見出しは `truncate_to_width` で
  1 行に切る。20 枚を超えたら 2 列)。現在のスライドを反転表示。
- Up/Down (と PgUp/PgDn) で選択を動かす、Enter / Space / Right で
  そのスライドへ飛ぶ (wait は 0 から)、`i` / Esc で何もせず戻る。
  **行のタップ/クリックで飛ぶ** (本家はダブルクリックだが、タッチで
  ダブルは打ちにくいのでシングルにする)。
- 索引中はスプライトを隠し、タイマーは進め続ける (黒白と同じ)。
- 描画は開いたときと選択が動いたときだけ (毎フレーム描かない)。

## T5: ゴールを手前に置く指定

- スライドの中に **`{::goal/}`** の行があれば、そのスライドがうさぎの
  ゴール (本家の `image-slide-number-last-slide`)。`{::wait/}` と同じ
  場所で parser が拾い、`Slide` に `goal` 真偽値 (`attr_accessor`) を持つ。
  複数あれば最初のもの。
- `rabbit_progress` の分母・到達判定で `total_slides - 1` の代わりに
  ゴールのインデックスを使う。ゴール以降のスライドではうさぎは 1.0 で
  止まる (居眠り判定もそのまま)。
- demo_ja.md の最後に「質疑」スライドを足し、その 1 つ前に `{::goal/}`
  を置く (サンプルで仕様を見せる)。

## T6: 時間切れの合図 (chime)

- frontmatter `chime: true` のときだけ。亀が 1.0 に達して banzai に
  切り替わる**その 1 回**で、`FmrbAudio#note_on(ch, freq, vol)` を
  1 回 + 短い `note_off` (200ms 程度。`on_update` の次の周期で切る形で
  よい。定常経路に `sleep` を入れない)。
- `FmrbAudio.new(self)` は `on_create` で 1 回。音の確認は headless でも
  `tools/fmrb_audio_probe.rb` で「鳴った窓が 1 つある」ことを数字で取る
  (ルートの CLAUDE.md「音の確認」)。音色の善し悪しはユーザ確認。
- `t` で戻したあと再び時間切れになれば、また 1 回鳴る。

## 検収 (sim, 426x240)

`allotted_time: 1` + `chime: true` + `{::goal/}` 入りの一時 .md で:

| 項目 | 見るもの |
|---|---|
| タップ左右 | `click 400 120` で次のスライド、`click 20 120` で前 (wait のあるスライドで**段階を飛ばす**ことも 1 枚) |
| 黒/白画面 | Shift+b の直後のスクリーンショットが全画素 0x00 (pngscan の row 数本で)、任意キーで元の絵に戻り (P2 の同スライドと pngdiff 0)、その間スプライトが無い |
| 残り時間 | Shift+t で `MM:SS` が出て 1 秒ごとに減る (10 秒おきに 2 枚)、超過で `-MM:SS` が赤、放置中の presents/s が 1.0 のまま |
| 一時停止 | Shift+p 後 20 秒で亀の x と数字が**不変** (pngdiff 0)、再開後に止めていた分だけ遅れて進む |
| 索引 | `i` の画面 1 枚、Down 2 回 + Enter で 3 枚目に飛ぶ、クリックで飛ぶ、`i` で何もせず戻る |
| ゴール | `{::goal/}` のスライドでうさぎが x=ゴール、その次 (質疑) でも動かない (pngscan) |
| chime | 亀が banzai に切り替わる前後で `fmrb_audio_probe.rb` に音のあった窓が 1 つ。`chime` 無しの .md では 0 |
| 回帰 | demo.md / demo_ja.md の全スライドが P2 のスクリーンショットと pngdiff 0 (フッタ帯は除く矩形)、E/Exception 0 |

索引モードの見た目は趣味の範囲なので、**一覧の絵が描けた時点で 1 枚見せて
OK をもらってから**キー操作を作り込む (小さい関門)。
