## T1: 本文の文字サイズ (`text_size`)

- frontmatter `text_size: 1 | 2` (既定 1)。`FmrbRenderer` が `@ts` に持つ。
  値が 1 でも 2 でもなければ 1。
- **size 1 固定の定数を全部 `@ts` 倍にする**: 行高 (`LINE_H`)、文字高
  (`CHAR_H`)、箇条書きのインデント幅、引用バーの高さ、コードブロックの
  行高と内側余白、段落間の `LINE_H / 2`。左右の余白 (`MARGIN_X`) は
  そのままでよい。
- **見出しは本文より 1 段大きく、上限 3** (本文 1 → 見出し 2 [今のまま]、
  本文 2 → 見出し 3)。タイトルバーの高さ (`TITLE_BAR_H`) も見出しの
  サイズに追従させる。見出しの切り詰め (`truncate_to_width`) は測る前に
  サイズを合わせること (`text_width` は現在のサイズを掛けて返す。P0 と
  同じ注意)。
- タイトルスライドも同じ規則 (表題は見出しサイズ、副題は本文サイズ)。
- **コードブロックと inline code も本文サイズに追従**させる (発表では
  コードも読ませるものなので)。`fmrb` ブロックの描画領域の計算は
  `$fmrb_w` 等をそのまま渡しているなら変更不要。
- フッタ (ページ番号) とスプライトは**変えない** (size 1 のまま)。
- 1 画面に入らない本文は今と同じく `max_y` で打ち切る (スクロールや
  自動分割はしない)。

## T2: ルビ `{漢字|かんじ}`

- `parse_inline` に 1 種追加: `{` のあとに `:` が**続かない**ときだけルビ
  候補として読み、`|` と `}` が見つかれば `[:ruby, base, ruby]` 区間に
  する。`|` か `}` が無ければ普通の文字として扱う。`{::wait/}` /
  `{:.center}` は行頭で先に処理されているので衝突しないが、念のため
  `{:` は除外する。
- `layout_rich_text`: ルビ区間の幅は **base と ruby の広い方**。ルビは
  **常に size 1** で測る (本文が size 2 でも)。base は本文サイズ。
- 行高: ルビを含む行だけ `RUBY_H = 8` を**上に**足す (行の先頭 y を
  8 下げて base を描き、ルビはその 8px 上に size 1 で描く)。含まない行は
  今までどおり。`draw_rich_text` の戻り値 (次の y) にもこの分を入れる。
- ルビの x は base の中央に合わせる。base より ruby が広いときは base を
  ルビの中央に置く。
- 本文 size 1 のときはルビ 8px が本文 8px と同じ大きさになるが、
  **それでも描く** (仕様として「ルビは常に size 1」で一貫させる。
  プロジェクタ想定の size 2 で本来の見た目になる)。
- 折り返し: ルビ区間は分割しない (1 語扱い)。1 行に入らないルビ区間は
  次の行へ送る。
