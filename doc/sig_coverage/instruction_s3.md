# S3 指示書: 例の無いメソッドに例を足し、行をまたぐ強調を直す

> 2026-11-25 | 親セッションからサブ (Sonnet) への指示。計画は plan.md (5 章の S3、7 章の決定 23)。書き方の正は
> `sig/README.md`。数え方は `rake sig:coverage` の「3. doc gaps」と、明細 `tmp/sig_coverage/report.md` の 3 章。

## 目的

Family mruby の sig (上流由来の 15 ファイル以外。23 ファイル・780 メソッド) の書き方の欠けを 0 にする。今の数:

| 欠け | 数 | 明細の節 |
|---|---|---|
| 例 (` ```ruby `) が無い | 104 | No ```ruby example |
| 長文が無い | 3 | No long form |
| 強調 `**` が行の中で閉じていない | 122 行 (61 か所ほど) | A ** that is not closed on its line |
| 長文に散文があるのに英語側 (`<<en>>` の行) が無い | 16 | Long form with prose but no <<en>> line |

## やること (fmruby-core、ブランチ `sig-s3`)

### 1. 例を足す (104 件) と、長文を足す (3 件)
- `tmp/sig_coverage/report.md` の一覧のメソッドを 1 つずつ。**実装と、同梱のアプリでの使われ方を読んでから書く**
  (`flash/app/`・`flash/lib/templates/`・`flash/usr/share/samples/`。使われていなければ実装の引数と戻り値から)。
  推測で書かない。例に戻り値 (`#=> ...`) を書くなら、実装から確かに言える値だけにする。
- 素直なメソッドは「例だけ」(散文を足さない)。例は 39 桁以内、1〜4 行。日本語側と `<<en>>` の後の英語側の両方に
  同じ例を置く (既にある書き方に合わせる。例だけのメソッドで英語側を分けていないファイルは、その形に合わせる)。
- 読んでいて、そのメソッドが「つまずく」側 (README の目安) だと分かったら、型紙の順で短い長文を足してよい。
  ただし**シグネチャと要約は変えない**。シグネチャが実装と食い違っていると分かったら、直さずに報告に並べる
  (親が sim で確かめてから直す)。
- 例を書けないもの (呼ぶ場面がアプリに無く、実装からも安全な呼び方が言えないもの) は、無理に書かずに報告に並べる。

### 2. 行をまたぐ強調を直す (122 行)
- 明細の `file:line` を上から。`**` を開いた行の中で閉じる。**文の意味と語は変えない**: 強調の範囲を 1 行に収まる
  語句に縮めるか、行の折り返しを変えて 1 行に入れる。日本語側と英語側の両方にある。
- コードの例 (` ``` ` の中) は触らない。

### 3. 英語側の無い長文に英語を足す (16 件)
- 日本語の散文を、同じ中身の英語にして `<<en>>` の行の後に置く (例も英語側に写す)。

### 4. 確かめる
- `rake sig:coverage` で、上の 4 つが 0 になる (書けなかった理由のあるものを除く。残ったものは報告に)。
  `rake sig:coverage:update` で基準を更新し、別コミットにする。
- `rake ti:test`、`rake regress` (境界の検査 `boundary:check` が落ちたら `ruby tools/boundary/gen.rb` で作り直して
  一緒にコミット。長文は境界の SDK に入らないはずだが、落ちたら何が変わったかを報告に書く)。
- 要約 (1 行目) は変えないので、型データベースの大きさは変わらないはず。変わったら報告に書く。
- **ビルドと sim の確認はしない** (親が検収で行う)。

## 報告に必ず書くこと (doc/sig_coverage/report/s3.md)

1. 足した例の数 (ファイルごと)、長文を足した数、直した強調の数、英語を足した数。
2. **根拠**: 例を書いたメソッドのうち、アプリの使い方を写したものはそのファイル、実装から書いたものは読んだ
   `パス:行` を、ファイルごとの表で (104 行の表でよい)。
3. **シグネチャ・要約が実装と食い違っていると分かったもの** (直していない。親が確かめる)。
4. 例を書けなかったもの・残った欠けと理由。
5. **親が sim で確かめるとよい例 10 個ほど** (戻り値を書いた例のうち、自信の低いものから。打つ式 → 書いた結果。
   1 行 60 文字以内)。
6. 確かめていないこと。迷った所。
