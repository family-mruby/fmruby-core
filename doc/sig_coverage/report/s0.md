## 1. 数え方

### 1.1 アプリが使っているのに sig に無いもの (数え方 1)

対象: `flash/app/` (`flash/app/test/` を除く)・`flash/lib/templates/`・`flash/usr/share/samples/` の `.rb`。
80 ファイルのうち、ignore.yml の 7 ファイル (後述) を除いた 73 ファイル。

各ファイルを Prism で読み、呼び出しを 5 つに分ける。

| 種類 | 例 | 欠けとするもの |
|---|---|---|
| 受け手が定数 | `Machine.board_millis` | sig にクラスが無い (アプリ自身のクラスでもない) → クラスとメソッドの両方を欠けに。sig にクラスがあるのにクラスメソッドが無い → メソッドを欠けに |
| 受け手が sig で型の付いたインスタンス変数 | `@gfx.draw_text_mixed` | そのクラス (`FmrbGfx`) とその祖先に無い。sig で型が付いているのは今 `@gfx` だけ |
| 受け手の型が決まらない | `s.byteslice(0, 3)` | **どのクラスの sig にもその名前が無い**ものだけ |
| 受け手なし (self を含む) | `rand(6)`・`self.idle_gc = 1` | 同上 |
| 定数の読み出し | `FmrbConst::KEY_UP` | 値の定数 (大文字と `_`、または大文字だけで親の定数の下) は、親が sig にあれば定数の欠け、親も無ければ親をクラスの欠けに |

- sig の引き方は tidbgen (database_builder.rb) に合わせた: インスタンスメソッドは自分・親・include、クラスメソッドは
  自分・親・extend、どちらも最後に Object。`initialize` は `new`。private は数えない。
- アプリ自身の定義は欠けにしない: クラス・モジュール・定数 (`TUNES`)・`def`・`attr_*`・`alias`・`define_method`・
  `Struct.new` の項目。定義は**アプリの全ファイルと、アプリが読むライブラリ (`flash/lib/*.rb`・
  `flash/usr/share/**/*.rb`) を合わせて**集める。あるアプリが定義した名前は別のアプリでも欠けにならない
  (数え漏れの側に倒れる)。ライブラリのクラスは名前の全体でだけ当てる (ROS のメッセージ型 `...::Time` が
  `::Time` を隠さないように)。
- 宣言のための呼び出し (`require`・`attr_reader`・`private`・`include` など) は数えない。
- 定数を受け手にした呼び出しのうち、`Math::PI / 2`・`FmrbConst::PLATFORM == "esp32"` のように値の定数に
  演算子・`to_s` などを呼ぶものは、定数の欠けと「型の決まらない呼び出し」として数える (`Net::HTTP.get_response` は
  クラス)。
- 欠けは名前ごとに回数と使っているファイル (多い順に 3 つ) を明細に出す。

### 1.2 実装にあって sig に無いもの (数え方 2)

- (a) Ruby: `lib/gems/picoruby-fmrb-*/mrblib/**` と `vendor/asterism/mrblib/**`、それに上流の gem のうち指示の
  11 クラス (`Machine`・`Math`・`GC`・`Dir`・`File`・`IO`・`Time`・`JSON`・`MessagePack`・`I2C`・`GPIO`) の mrblib
  (picoruby-machine・picoruby-json・picoruby-gpio・picoruby-i2c・mruby-time・mruby-math・mruby-dir)。
  JSON は C ではなく mrblib の Ruby なので、上流の mrblib も (a) に入れた。
  - 公開メソッドだけ: 裸の `private`/`protected` の後、`private def`、`private :name`、`module_function` の
    インスタンス側、`class << self` の中の `private` の後を除く (`def self.x` は `private` の後でも公開)。
  - `_` で始まるもの、`method_missing` などフックを除く。`attr_*` と `alias` は数える。`initialize` は `.new`。
  - メソッドの直前のコメントに `@api private` があれば印を付ける (Asterism の gem が内部用にこう書いている)。
    **数からは除いていない** (2.2・3 章)。
- (b) C: `lib/gems/*/ports/**/*.c`・`lib/gems/*/src/**/*.c` と、上流の 11 クラスに当たる C (picoruby-machine・
  picoruby-gpio・picoruby-i2c の src、mruby-math・mruby-time・mruby-dir の src、mruby の `src/gc.c`)。上流の C は
  11 クラス (とその下) の分だけを残す。
  - `mrb_define_method`・`_class_method`・`_module_function`・`_singleton_method` と各 `_id` 形。名前は
    `"x"`・`MRB_SYM(x)`・`MRB_SYM_Q/B/E`・`MRB_OPSYM`。module function はクラスメソッドとして数える。
  - 対象のクラスは、そのファイルが `mrb_define_class`・`mrb_define_module`・`mrb_class_get` ほか (`_under`・`_id`
    形も) で代入した変数と、`mrb->kernel_module` などを追う。追えないものは推測せず「追えなかった」として出す
    (今は 0)。コメントの中は数えない。
  - 境界の生成物 (`fmrb_boundary_mrb.inc`) は sig から作るので数えない。
- 実装のクラスが sig では別の名前空間に書いてある場合 (一方が他方の後ろに一致) は、それで照合し、明細に出す (今は無い)。
- 実装と sig で種類 (クラスメソッドかインスタンスメソッドか) が違うものは欠けでなく「種類違い」として別に出す
  (今は `Asterism::Proxy#methods` の 1 件、6 章)。

### 1.3 書き方の欠け (数え方 3)

対象は `fmrb_*.rbs`・`enumerable.rbs`・`gpio.rbs` の公開メソッド (別名を除く)。コメントは tidbgen の
`build_visible_comment` と同じく、HTML コメントの行を落として strip したもの。

- 要約 = 1 行目。無い・112 バイトを超える・`<<en>>` が無い、を数える。
- 長文 = 2 行目以降。無い・` ```ruby ` が無い、を数える。
- 参考に「散文があるのに `<<en>>` の行が無い長文」も明細に出す (5 つの数には入れない。今 1 件:
  `FmrbApp.path_read_only?`)。

## 5. 数え切れなかったもの

- **動的な呼び出し**: アプリ (除いた後の 73 ファイル) では `respond_to?` 1 回 (midi_bench) だけ。`send`・
  `method_missing`・`instance_eval`・`const_get` は無い (生成の台本の `send` 2 回は除いた)。影響は無視できる。
  明細の「Dynamic calls」に出る。
- **型の決まらない呼び出し** (340 回): どのクラスにも無い名前だけを数えるので、**sig のどこかに同じ名前があれば、
  受け手のクラスに無くても欠けにならない**。例: `@tc.close` は `close` がどこかにあるので数えない。この取りこぼしの
  大きさは道具では測れない。型が付いている `@gfx` (FmrbGfx) の呼び出しだけはクラスで照合している。sig に
  インスタンス変数の型を足すほど (`@ui: FmrbUI` など) 正確になる。
- **定義の寄せ集め**: アプリとライブラリの定義を全部合わせて見るので、あるアプリが `def round` を書けば全アプリで
  `round` が欠けでなくなる。ROS のメッセージ型 (`flash/usr/share/asterism/msgs`) の多くの名前もここに入る。
- **定数の名前の解決**: 裸の定数 (`TRANSPARENT_COLOR`) は、どこかのクラスの sig に同じ名前の定数があれば有りとする
  (アプリのクラスの親を追わない)。
- **Prism が読めなかったファイル**: `flash/usr/share/samples/ruby/ja_sample.rb` (日本語のクラス名 `class ニホンゴApp`
  を Prism は定数と認めない)。読めた所まで数え、`ニホンゴApp` が受け手なしの欠け 2 回に出ている。
- **C**: 関数の引数で渡されたクラスへの定義は「追えなかった」として出す作り (今は 0)。`#if` の分かれは両方数える。
- **Ruby の実装**: `define_method` での定義と、トップレベルの `def` (今は無い) は数えない。

## 6. 見立てと違った点・残件

- **英語の無い要約 25 件は無かった** (2.1)。決定 6 と S3 の「英語の無い 25 件に英語を足す」は、要約については
  やることが無い。長文で散文に `<<en>>` が無いのは 1 件 (`FmrbApp.path_read_only?`)。plan.md への反映は親。
- **FmrbConst が最大の欠け** (2.1・3 章)。plan のどの段にも無い。
- **要約の上限は実際は 111 バイト**: `editor_ti_bridge.c` の `et_copy_field` は `cap - 1` バイトまで写して NUL を
  置くので、`ET_DOC_MAX` 112 の箱に入る要約は 111 バイトまで。sig/README.md と CLAUDE.md の「112 バイトまで」とは
  1 バイト違う。112 バイトちょうどの要約が 1 件ある (`Array#collect!`、上流由来の array.rbs なので数え方 3 の
  対象外)。道具は指示どおり 112 を超えるものを数えている。基準を 111 にするか、文書を直すかは親とユーザ。
- **`gpio.rbs` は sig/ に無い**: sig/README.md は `enumerable.rbs` と `gpio.rbs` をうちのものと書くが、`gpio.rbs` は
  型エンジンの試験用の `tools/ti/test_sig/` にだけあり、ファームの db には入っていない。道具は sig/ にあれば数える。
  `GPIO` は今アプリが使う定数としても欠けている (数え方 1 は `I2C` のみ 3 回、`GPIO` はアプリでは 0。実装は C 13・
  Ruby 7)。
- `Asterism::Proxy#methods` は実装ではインスタンスメソッドで、sig には object.rbs の `Object.methods` (クラスメソッド) だけがあるので、種類違いとして出る。
- 残件: 4.2 の判断が済んだら ignore.yml に足して `rake sig:coverage:update`。増えたら落ちる検査への切り替え
  (決定 3) は、範囲ごとに 0 になってから。
