# 全画面の高解像度モード (使い方と仕組み)

> 状態: 完了 | 更新: 2026-09-28 | P4 系 (Tab5 / NARYAv4) とブラウザ版で、属性を持つアプリの全画面だけ 640x360 になる。アプリの書き方、エディタのフォント、遠隔の道具での見え方

企画の経緯は `doc/fullscreen_hires/` (plan.md と report/)。

## 何が起きるか

- 通常の画面は 426x240 で、Tab5 と NARYAv4 はそれを 3 倍して 1280x720 に出す。
- `fullscreen_hires` を持つアプリが**全画面の一番上**にいる間だけ、画面は
  640x360 になり、2 倍して出る。物理の大きさは同じで、細かさだけが上がる。
- 窓に戻る (F11)、別の全画面アプリが上に来る、park される (Ctrl+Tab)、
  終わる、のどれでも 426x240 に戻る。決めるのはカーネルで、アプリは
  「高解像度にしてよい」と宣言するだけ。アプリが実行中に切り替える口は無い。
- 対象は P4 系とブラウザ版 (基本の大きさが 426x240 のページ) だけ。
  Retro (S3) と Linux の sim では属性は無視され、従来の全画面になる。
  ブラウザ版で 640x360 や 852x480 のページを選んでいるときも無視される。

## アプリの書き方

`.app.toml` に 1 行足す。

```toml
default_window_mode = "fullscreen"   # 起動時から全画面にするなら
fullscreen_hires = true              # 全画面のとき 640x360 にしてよい (整数 1 も可)
```

- 全画面で起動するアプリは、最初から 640x360 の canvas で作られる
  (`@window_width` / `@window_height` が 640 / 360)。
- 窓と全画面を行き来するアプリ (F11 で `toggle_fullscreen` を呼ぶもの) は、
  大きさが `on_resize(w, h)` で届く。**大きさを定数で持たず、届いた値で
  配置を組み直す**。640x360 と窓の大きさの両方で描けること。
- 描画の座標は常に canvas の画素。640x360 のときは 1 画素が物理の 2x2、
  426x240 のときは 3x3 になる。フォントの見た目の大きさも 2/3 になる。
- マウスとタッチの座標は、そのときの画面の大きさで届く。画面上の速さは
  どちらの大きさでも同じになるよう補正してある。
- 組み込みでは `default/editor` と `default/editor_fs` (エディタ) が持っている。
- 試験用アプリ `flash/app/test/hires_test.app.rb` が最小の例 (起動時から
  640x360、F11 で窓と往復、試験用の図柄を描く)。

## エディタのフォント

- View > Font (日本語は「文字の大きさ」) で、本文のフォントを 3 つから選ぶ。
  小 (8、美咲) / 標準 (12、既定) / 大 (16)。窓と全画面で共通。
- 選んだ値は `/home/editor.toml` の `[editor]` の `font = 8|12|16` に残り、
  次の起動でも効く。ほかの行はそのまま残る。読めない値は 12 になる。
- 640x360 の全画面では、12 で 106 桁 x 28 行、8 で 159 桁 x 42 行、
  16 で 79 桁 x 21 行 入る。

## 表示側の守り

表示タスク (display_p4) は、高解像度の持ち主の canvas がおかしな状態でも
画面を止めない。

- 持ち主の canvas は、与えられた位置にかかわらず (0, 0) に写す。
- 持ち主が消えた・隠れたら、すぐ 426x240 に戻る。
- 持ち主が 640x360 の絵を出せない状態 (別の大きさにされた、絵が無い) が
  500ms 続いたら、自分で 426x240 に戻る。ログは
  `screen mode: owner N has shown no 640x360 frame ...`。
- 自分で戻したときは、入力側 (タッチ・マウス・遠隔入力) の画面の大きさも
  合わせて戻す。

## 遠隔の道具での見え方

- 遠隔デスクトップのページ (端末の `http://<IP>/`): 画面の大きさに追従する。
  ページ上の見た目の大きさは変わらず、クリックは画面全体に届く。
  H.264 も 640x360 を流す (符号化は 640x368、下の 8 行はページが隠す)。
- `tab5_screenshot`: `frame_size` が 640x360 になる。
- `tab5_input` / `web_input`: 座標はそのときの画面の大きさ。640x360 の
  ときに 426x240 のつもりの座標を送ると左上に寄る (板は拡大しない)。
  先に画面を取って大きさを見る。
- ブラウザ版のページ: 見た目の大きさは選んだ解像度とズームで決まり、
  640x360 に切り替わっても変わらない。
