# VOICEVOX の声を使うときの決まり (調べた記録)

> 状態: 調査済 | 更新: 2026-10-20 | 無料の日本語の音声合成 VOICEVOX の声を、Family mruby や asterism-games で使うときの決まりと、配り方の考え方。麻雀の実況 (doc/commentary/) のために調べたが、ほかの読み上げにも使える。規約は変わりうるので、使う前にそのキャラクターの最新の規約を確認する

## 1. VOICEVOX の全体の決まり

- ソフトと生成した音声は、**商用・非商用ともに無料**で使える。
- 使うときは、VOICEVOX を使ったことが分かる**クレジット**が要る。書き方の例は「VOICEVOX:ずんだもん」(キャラクターの名前を付ける)。
- 生成した音声を使うときは、**そのキャラクター (音声ライブラリ) の規約にも従う**。全体の決まりの上に、キャラクターごとの決まりが乗る。
- **生成した音声をほかの人に使わせるとき**は、その人にも同じ条件 (キャラクターの規約に従うこと、全体の決まりの該当項) を守らせる必要がある。
  - よって、生成した音声を **MIT などの自由なライセンスの中に混ぜて配ることはできない**。配るなら、声の部分だけを別にして、キャラクターの規約とクレジットを付ける。
- 禁止事項にある「再配布」は、ソフト本体 (VOICEVOX) を勝手に配ることを指す。生成した音声のことではない。
- アプリ・ゲーム・OSS に組み込むことについての、個別の記載は無い。利用者の間では、生成した音声を配ることを灰色と見る意見もある (公式の回答ではない)。

## 2. キャラクターごとの決まり (調べた範囲)

キャラクターは 40 人以上いる (声の無い「Nemo」もある)。規約の書き手はキャラクターごとに違う。

### ずんだもん (と東北ずん子・東北きりたん・東北イタコ)

- 商用・非商用ともに使える。共通の規約に従う。
- **クレジットが要る** (例「VOICEVOX:ずんだもん」)。
  - 動画: 説明欄か画面の中の、探せば見つかる場所。
  - アプリ: 紹介の画面など、少し探せば見つかる場所。
- クレジット無しで商用に使うには、キャラクターごとに有料の契約が要る (40 万円 + 税)。
- 禁止: 公序良俗に反する使い方、政治・宗教の活動 (人や団体を攻撃・宣伝するものを含む)、情報商材やその宣伝、わざと嘘や誤解を招く内容を作って広めること、成人向けの風俗業、反社会的勢力。当てはまると許可を取り消されうる。
- 無料で使える範囲についての個別の質問には答えない、とされている。迷う使い方は書き手に問い合わせる。

### 青山龍星

- 他のキャラクターと同じく、クレジットを書けば商用・非商用で使える、と紹介されている。
- **企業が関わる形で使う場合は、事前の確認が要る**、という 2022 年時点の記事がある。今も同じかは、使う前に規約を確認する。

### そのほか

- No.7、玄野武宏、雀松朱司、白上虎太郎、四国めたん、春日部つむぎなどは、それぞれに規約がある。この記録の時点では本文を確認していない。使う前に読む。

## 3. 配り方の考え方 (2026-10-20 の整理)

| 形 | 中身 | 規約の重さ |
|---|---|---|
| **配らない (各自の PC で作る)** | アプリには言葉の一覧と作る道具だけを入れ、WAV は各自の PC の VOICEVOX でその場で作る | 軽い。声の再配布が起きない。キャラクターも各自が選べる |
| **声の束を別にして配る** | 声だけを別の gem や束にして、キャラクターの規約とクレジットを付けて配る | 重い。受け取る人にも規約を守らせる形にする |
| **端末に入れて配る** | 端末 (flash/) に WAV を入れる。flash/ は「git に入っているもの = 配ってよいもの」 | 重い。上と同じく規約とクレジットを付け、再配布してよいキャラクターを選ぶ |

- クレジットは、使った画面 (実況のページ、アプリの紹介) と、配るものの中の CREDITS に書く。
- 配信 (動画・生放送) で流すときは、配信の説明欄にもクレジットを書く。

## 4. 手元で動かす形

- VOICEVOX は Windows・macOS・Linux 向けのアプリと、エンジンだけの docker のイメージがある。エンジンは手元の HTTP (既定 `127.0.0.1:50021`) で、文から「読み方の問い合わせ」を作り、それを合成して WAV を返す。
- WSL から Windows 側のアプリのエンジンを呼ぶには、WSL の網の設定 (Windows と localhost を共有する設定) か、Windows 側の住所を使う。WSL の中で docker のエンジンを動かしてもよい (CPU 版)。
- エンジンはメモリを多く使う (目安で 1〜2GB、実測はしていない)。小さな VPS には置きにくい。
