# ミュート (音を出さない設定)

> 状態: 進行中 | 更新: 2026-10-01 | 本体の音を一括で消す設定。再起動しても残り (起動音も鳴らない)、デスクトップのメニューバーと遠隔 (devctl / MCP) から切り替えられる。M1 で作る

## 目的

通話中など音を出したくないときに、アプリの起動・ゲーム・起動音を含めて、本体の音を一括で止められるようにする。
開発の検証 (サブエージェントが実機でアプリを起動する) の前に、遠隔から止めておけるようにする。

## 分かっていること

- 音の出口: P4 (Tab5 / NARYAv4) は core の audio_p4 (APU のエミュレーションから I2S)。コーデックに音量と
  ミュートの口がある (`audio_p4_hw_set_volume`、0 でミュート)。Retro (S3) は WROVER の graphics-audio が鳴らし、
  core から音の命令を送る。WROVER 側の音量の命令は今は何もしない (スタブ)。sim は graphics-audio の SDL、
  ブラウザ版は audio_p4 から AudioWorklet。
- 起動音 (ジングル) はデスクトップが鳴らす。`boot_splash = false` でロゴごと消せるが、ミュートとは別の設定。
- 外部 MIDI 出力 (シリアル) は本体の音ではない。

## 方針

- **core 側の 1 か所で止める**: 音の命令が出ていく所 (host_task から音の出口へ) で、ミュート中は鳴らす命令を
  送らない (止める命令は通す)。ミュートにした瞬間に、鳴っている音も止める。これで P4・Retro・sim・ブラウザ版の
  どれにも同じに効き、graphics-audio は変えずに済む。P4 は加えてコーデックのミュートも使ってよい
  (確実に無音にするため)。
- **設定として残す**: system_conf に `audio_mute` (既定 false) を足し、起動時に読む (起動音より前に効く)。
  切り替えたら保存する。
- **切り替えの口**: (1) デスクトップのメニューバーの指示器 (かなの指示器と同じくクリックで切り替え) と
  メニューの項目、(2) 遠隔: devctl に `POST /audio/mute?on=0|1` と `GET /audio/mute`、(3) MCP の fmrb サーバに
  ミュートを切り替える手段 (Tab5 / NARYAv4 の devctl 経由。sim はできる範囲で)。
- アプリ側の API の変更はしない (アプリはミュートを知らずに動く)。外部 MIDI 出力は止めない。
- 内蔵 RAM を増やさない。

## 受け入れ条件

- ミュート中は、起動音・アプリの音 (MML、ゲーム、BASIC の PLAY など) が鳴らない。外す と鳴る。
- 再起動してもミュートが残る (起動音も鳴らない)。
- メニューバーと遠隔の両方から切り替えられ、状態が一致する。
- P4 (P4-Nano)・sim・ブラウザ版で確認。Retro はビルドと sim、実機はつないだときに。
