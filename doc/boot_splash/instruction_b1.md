# B1 指示書: 起動の演出の試作 (と、差し込みの直し 2 つ)

> 親: plan.md (方針と受け入れ条件)。時間の目安は doc/regression/usage.md 0 章。

## やること (この順で)

### 1. 起動の演出の試作

`main/ruby/kernel/system_desktop.app.rb` の起動の演出を plan.md の方針の形に置き換える。

- 見た目 (ブラウン管の電源 ON):
  1. 黒の画面の中央に、細い横の白い線 (高さ 1〜2 px) が短く出る。
  2. 線が左右に伸び、画面の幅いっぱいになる。
  3. 上下に開いて、ロゴの画面 (今の白背景とロゴの層) が見える。
  4. 開ききった直後に一瞬だけ明るい山を作り、すぐ落ち着く。
- 今の作り (下の層にロゴ、上の層をカラーキー 0x01 で透かしていく) を流用してよい。描く量は画面に出る量に
  比例させる (毎フレーム全画面を塗り直さない)。整数の計算だけ (Float を使わない)。
- 音 (`BOOT_EVENTS` を置き換え): G3 → D4 と完全 5 度で上がり、G4・A4・D5 の和音で伸ばす。三角波で G2 の
  低音、ノイズで軽いきらめき。全体で約 1.2 秒、最後は消えるように止める (ぶつ切りにしない。音量を段階で
  下げてよい)。見た目と音の段の合わせ目を揃える (線が出る・開ききる、で音が変わる)。
- `BOOT_HOLD_MS` などの待ちも見直し、起動からデスクトップが使えるまでを今より短くする。
- `boot_splash = false` の飛ばし方、`finish_boot_animation` の後始末 (音を止める・画像を消す) は今のまま
  動くこと。

### 2. 差し込みの直し (ユーザから、試作の後に)

- **エディタ: 改行を何行か入れた後に BS で消していくと、カーソルの反転が残る**。再現して原因を見つけ、
  根本で直す (反転を消す・描き直す範囲の計算の誤りなど。画面全体を毎回描き直す直し方はしない)。
  標準のエディタ (Spinel) で直し、mruby のエディタにも同じ誤りがあれば直す。
- **Cyberpunk 風のテーマ: パスを入力する白い欄の文字が黄緑で読みにくい**。どの画面のどの欄かを見つけ、
  白い欄の上で読める色にする。テーマの色の定義の決め方 (doc/app_theme/plan.md) に沿い、ほかのテーマの
  同じ欄の色の付け方と揃える。ほかの白い欄にも同じことが起きていれば一覧にして直す。

## 確かめること (これだけ)

- 段ごと: `rake regress` (35 秒)、`rake regress:spinel` (20 秒)。
- 演出: sim (Retro と Modern) で起動の連続した画面を撮り (各段が分かる 6〜8 枚)、
  `ruby tools/fmrb_audio_probe.rb --dump` で音を WAV に落とし、各音の周波数を解析して音高を表にする。
  起動からデスクトップが使えるまでの時間を、変更前と後で測る。
- 直し: エディタは sim で「改行を数行 → BS で戻る」の前後の画面、Cyberpunk のテーマはその欄の画面。
- 最後に 1 回: `rake regress:screens` と `rake regress:run` (VM プールが変更前と揺れの幅の中。KB 単位で
  増えたら理由を書く)。起動の演出は画面の場面の前に終わるはずなので、screens の基準が変わったら理由を書く。
- 直しのやり直しでは、変えた所が影響する道具だけを流し直す。

## 触ってよい範囲

- fmruby-core (develop)。作業ツリーの既存の未コミット (components/ のサブモジュール 2 つ、wasm/vendor/) には
  触らない。ロゴの画像は変えない。
- コミットは件名 `<種類>(<場所>): <要約>`、英語、Co-Authored-By、pathspec を明示。演出と直し 2 つは別の
  コミット。push しない。基準の更新はしない。
- 終わったら Linux のビルド (x86-64)、sim を片付け、裏の処理を残さない。

## 止まる条件
