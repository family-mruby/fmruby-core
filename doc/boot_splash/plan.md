# 起動の演出 (ロゴと音)

> 状態: 進行中 | 更新: 2026-11-15 | 起動のロゴの出し方と音を、ブラウン管の電源 ON の見せ方と、完全 5 度で上がって響く和音に変える。今の菱形のアイリスとハ長調の進行 (約 2.7 秒) を、短くて締まった演出 (約 1.2 秒) に置き換える

## 目的

起動のロゴの演出と BGM を「スマートでカッコいい」ものにする (2026-11-15 ユーザ)。起動の速さは譲らない
(黒い画面で待たせない。今より長くしない)。

## 方針 (2026-11-15 ユーザが選んだ形)

- **見た目: ブラウン管の電源 ON**。黒の中央に細い横の光の線が出て、横に伸び、上下に開いてロゴの画面になる。
  開ききったところで一瞬だけ明るく、すぐ落ち着く。
- **音: 完全 5 度で上がって響く和音**。G3 → D4 と 5 度で上がり、G4・A4・D5 の和音 (sus2/add9 の響き) で
  伸ばす。三角波の低音 G2、ノイズで軽いきらめき。今の APU (`FmrbAudio`) で鳴らす。
- 全体で約 1.2 秒 (今のアイリス 1.7 秒 + 待ち 1 秒より短く)。
- `boot_splash = false` で演出を飛ばす決まりは残す。

## スコープ

- `main/ruby/kernel/system_desktop.app.rb` の起動の演出 (`BOOT_EVENTS`・`start_boot_animation`・
  `tick_boot_animation`) だけ。ロゴの画像 (`/boot/boot.png`) は変えない。
- Retro (320x240) と Modern (426x240) の両方。Spinel のカーネル (標準) と mruby の両方で動く。

## 受け入れ条件

- 演出の各段の画面 (sim の連続した撮影) と、音の WAV (`tools/fmrb_audio_probe.rb --dump`) で、上の形になって
  いることが分かる。音高は WAV の周波数解析で G3・D4・G4・A4・D5・G2 に当たる。
- 起動からデスクトップが使えるまでの時間が今より短い。
- `rake regress`・`rake regress:spinel` が通り、`regress:screens`・`regress:run` が変更前と揺れの幅の中。
- 見た目と音の良し悪しはユーザが目と耳で決める。
