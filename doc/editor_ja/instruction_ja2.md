## T1 (本丸): 行の折り返し

### editor-core 側

- `ec_wrap_segments(y, view_cells)` を追加: 行 y をセル幅 view_cells で
  折り返したときの**区分境界 (文字インデックス列)** を返す
  (ec_render_hl / ec_render_width と同じ 1 区分 = 固定長レコードの平坦
  形式で良い)。計算はセル幅マップの接頭和。**2 セル文字を区分境界で
  割らない** (入らない全角は次区分へ)。
- **行単位キャッシュ**: 区分結果 (または区分数) を行ごとにキャッシュし、
  その行の編集で無効化。view_cells が変わったら (リサイズ・全画面切替)
  全無効化。キャッシュの持ち方は実装に任せるが、**全行の一括再計算を
  平時に走らせない**こと。
- mruby / Spinel 両バインディング (FFI 宣言は専用ファイル、P5 の規則)。

### エディタ側: アンカー基準スクロール

plan.md 3.2 の設計どおり:

- 画面先頭を **@anchor = (論理行, 区分番号)** で持つ。描画はアンカーから
  画面行数ぶん区分を順に消費するだけ。**文書全体の画面行数の合計は
  どこにも計算しない** (スクロール比率が要る表示は論理行ベースの近似)。
- カーソル上下は「現在の (行, 区分) の前後の区分」へ、桁は**セル位置を
  なるべく維持** (通常のエディタの上下移動の感覚)。PageUp/Down は
  画面行数ぶんの区分移動。ensure_cursor_visible もアンカー相対で閉じる。
- 行番号ガターは**先頭区分にのみ論理行番号**、継続区分は空白 (または
  折返し記号。どちらにしたか report に)。
- dirty 意味論: 1 行編集で**区分数が不変**ならその行の区分だけ再描画、
  **区分数が変わったらその行以下を再描画** (既存 mark_dirty_from と同型)。
- 行描画は JA1 の draw_row_text をそのまま区分スライス (col0/nchars を
  区分ごとに変える) で呼ぶ (report/ja1.md の引継ぎどおり)。
  DRAW_TEXT_MAX_BYTES 分割はそのまま有効。
- **折り返し ON/OFF はメニューのトグル** (既定 ON)。OFF = 従来の
  横スクロール (JA1 の挙動そのまま。右端の半端セル仕様も維持)。
  設定の永続化はしない (バッファ単位でよい。HL トグルと同じ扱い)。
- 選択・検索ジャンプ・デバッガの停止行表示 (行番号ベース) が折り返しと
  共存すること。禁則処理・単語境界は範囲外 (v1 は文字単位)。

### 受け入れ条件

- 全角/半角混在の長い行 (200 セル級) が折り返されて全文見える。編集
  (行中央への挿入・削除で区分数が増減するケース含む) が正しく追随する。
- 上下移動・PageUp/Down・行頭行末・ensure_cursor_visible が区分単位で
  自然に動く。選択が折り返し行間をまたいで正しく描かれる。
- トグル OFF で JA1 の横スクロール挙動に完全に戻る。
- 53KB / 200KB ファイル (P4 の受け入れ資産) を折り返し ON で開いて
  スクロールが重くならない (edit_lat: 前後比較。全行再計算をしていない
  ことの傍証になる)。
- en/ja 両方、両エンジン、Linux/S3/P4 ビルド通過。スクリーンショット。

## T2: クリック / タッチでカーソル移動

JA1 で「編集領域のクリックでカーソルが動かない (元から未実装)」と
判明した。子供向けの操作性の要なので、折り返しと同時に入れる
(座標→位置変換が折り返しの区分計算とほぼ同じため)。

- 編集領域の mouse_down (タッチはマウスに合流済み) で:
  画面行 → (論理行, 区分) はアンカーからの相対、区分内のセル位置 →
  文字インデックスはセル幅マップの走査 (JA1 の cell_offset の逆)。
  全角文字の左半分/右半分どちらを突いてもその文字の位置になること。
- カーソル移動のみ (選択のドラッグ開始は範囲外。将来やる場合は
  mouse_move の頻度と再描画の関係に注意 — 必要なら「キュー処理後に
  1 回だけ描画」の合流を検討、という設計メモを report に残す)。
- 折り返し OFF (横スクロール) でも動くこと。
- ガター/メニューバー/ステータス行のクリックが従来どおりであること
  (編集領域の判定に食われない)。
