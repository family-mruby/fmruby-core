# Demo MIDI files

The MIDI APU demo plays `song.mid` if it is present, and falls back to
`scale.mid`. Drop any Standard MIDI File in as `song.mid` to hear it.

| File | Origin | Licence |
|---|---|---|
| `scale.mid` | generated by `tool/midi/test/make_test_midi.rb` | ours |
| `tempo_change.mid` | generated by the same script | ours |
| `song.mid` | "The Entertainer" (Scott Joplin), from the Mutopia Project | Public Domain |

A public domain composition does not by itself make a particular MIDI file
free: whoever sequenced it may hold rights over that rendering. Mutopia
states a licence per file, and only files marked Public Domain are used here,
checked in the file's own metadata rather than assumed from the site.
Anything added later should be checked the same way.
