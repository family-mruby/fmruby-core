# Ruby profile probes: one language or core-library feature each.
#
# A probe starts at a "## id:" line. Its header lines ("## key: value") are
#   id      unique name (also the row name in the table)
#   area    syntax, pattern, const, object, meta, proc, exception, string,
#           numeric, collection, core, runtime
#   title   what it checks, in a few words
#   expect  a Ruby expression for the answer CRuby 3.4 gives (evaluated on
#           the implementation under test too, so keep it a plain literal)
#   mrblib  optional: how the shared layer (mrblib/) relates to the feature
#           (uses / avoids / guards), for the table's last column
#   kind    optional: "measure" -- the probe returns a number (microseconds)
#           and is reported, not judged
# Everything up to the next "## id:" is the probe's code, run with eval in a
# method of the runner; its last value is the answer. Lines starting with
# "#" before the first probe are comments. Each probe is compiled on its own,
# so a probe the compiler rejects only fails itself.
#
# Results: ok (the answer equals expect), differs (another answer), ng (an
# exception: the feature is missing or the code did not compile).
