# IMU configuration data

`bmi270_config.bin` is the 8192-byte configuration image the BMI270 needs
before it produces any measurement. `BMI270#init` streams it into the sensor
over I2C; without it the part answers on the bus but never leaves its
uninitialised state.

The image is generated by `tool/gen_bmi270_config.rb` from the array shipped
with the M5Unified component (MIT), which in turn carries the configuration
published by Bosch Sensortec as part of the BMI270 sensor API (BSD-3-Clause).
It is data for the sensor, not code that runs on this machine.
