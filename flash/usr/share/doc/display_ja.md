# 画面の解像度

Modern の端末 (P4-Nano・Tab5) の画面は、2 つの解像度から選べます。

- 標準 (426x240): 字と的が大きく、Tab5 の画面に向きます。Tab5 は最初は
  こちらです。
- 高精細 (640x360): 1 画面に入る量が 2.25 倍になります。HDMI のモニタで
  エディタと Window を並べるときに向きます。字は 2/3 の大きさに見えます。
  P4-Nano は最初はこちらです。

選んだ解像度は端末の /etc/system_conf.toml にあり、ファームウェアを
更新してもこのファイルはそのまま残ります。前から標準で使っていた P4-Nano は、
Config で高精細を選ぶまで標準のままです。

## 切り替え方

メニューの Config を開き、「表示」の「画面の解像度」を < > で選んで
「保存して再起動」を押します。再起動すると新しい解像度で上がります。

- 高精細のとき、全画面のエディタは切り替えなしでそのまま 640x360 で出ます。
- 426x240 に合わせて作ったゲームなどの全画面のアプリは、そのアプリが
  前にいる間だけ画面が 426x240 に切り替わり、標準のときと同じ大きさで
  出ます。閉じる・Window に戻すと 640x360 に戻ります。切り替えの瞬間に
  画面が一瞬乱れることがあります。
- どの大きさでも描けるアプリ (シューター・PicoRabbit など) は、切り替えずに
  640x360 の全画面で出ます。自分のアプリでそうするには、.app.toml に
  `fullscreen_any_size = true` と書きます。
- マウスの速さは、どちらの解像度でもモニタの上で同じになるように
  合わせてあります (Config の「入力」のマウスの倍率はそのまま使えます)。

## 映らなくなったとき (戻し方)

- **電源を入れたら (リセットしたら)、起動中に Shift を連打する** と、設定を
  見ずに、その回だけ標準 (426x240) で上がります。押しっぱなしでは効かない
  ことがあるので、連打してください。設定は書き換わらないので、Config で
  選び直してください。
  キーボードは端末に直接つないでおきます。
- PC から戻すとき: WiFi の遠隔操作で /etc/system_conf.toml の
  display_width = 426、display_height = 240 に書き戻して再起動します
  (開発の道具 tools/fmrb_rd_fs.rb の get・put・reboot)。
