# Wi-Fi の設定

ESP32 の端末 (Tab5・NARYA など) は、覚えたネットワークのうち、近くに
見えている中でいちばん強いものに自分でつなぎます。起動したときと、
つながりが切れたときに探します。

## 1. 画面からつなぐ

デスクトップのメニューの Network を開き、「Wi-Fi の設定...」を押すと
Wi-Fi の画面が開きます。

- 近くのネットワークが強い順に並びます (使っているものがいちばん上で、
  名前の前に `>` が付きます)。棒の数が電波の強さ、右の錠が鍵のある
  ネットワーク、「保存」が覚えているネットワークです。
- 選んで「つなぐ」。鍵があって覚えていないネットワークでは、
  パスワードの欄が出ます。キーボードで打ってから「つなぐ」(Enter でも)。
  打った文字は * で表示されます。
- つながると、そのネットワークを覚えます (/home/wifi.toml に書きます)。
  つながらなかったときは覚えず、覚えているネットワークへ戻ります。
- 「切る」で切ります。次にネットワークを選ぶか、端末を起動し直すまで、
  自分ではつなぎに行きません。
- 「忘れる」で、選んだ覚えているネットワークを消します。近くに無い
  覚えているネットワークは、一覧の下に薄い名前で並びます。
- 「探す」で、もう一度探します。画面を開いたときにも 1 回探します。

覚えるのは 5 つまでです。6 つ目を覚えると、いちばん古く覚えたものが
消えます。

## 2. 自分でつなぐ順

1. 近くに見えている、覚えているネットワークを、強い順に試します。
2. 次に、隠れた (名前を出さない) ネットワークを、名前で試します。
3. どれにもつながらないときは、少し待ってからもう一度探します。
   待つ時間は 5 秒から始まり、つながらないたびに倍になって、2 分で
   止まります。つながると 5 秒に戻ります。

鍵の無いネットワークも、覚えていれば候補に入ります。

## 3. wifi.toml を直接書く

設定は /home/wifi.toml にあります (無ければ、開発用のビルドが入れた
/etc/wifi.toml を読みます。/home/wifi.toml があるときは、それだけを
読みます)。パスワードが入っているので、このファイルは遠隔 (HTTP・BLE)
からは読めません。書き換えるのは端末の上 (エディタやシェル) か、
BLE の Web コンソールの Settings (受け付ける時間を開いたとき) です。
Web コンソールで書いたネットワークは、画面でつないだときと同じく、
覚えているものに足されます (先頭に入り、同じ名前があればそれを書き換え
ます。ほかのものは残り、5 つを超えると一番古いものが消えます)。

```toml
[wifi]
enable = true
# hostname = "fmruby"        # 省くと fmruby-XXXXXX (MAC の末尾)

[[networks]]                 # 新しいものが先、5 つまで
ssid = "home"
password = "パスワード"

[[networks]]
ssid = "cafe"
password = ""                # 鍵の無いネットワーク

[[networks]]
ssid = "hidden-net"          # 隠れた SSID は、ここに手で書いて足す
password = "パスワード"
hidden = true                # 名前で試す (探しても見えないため)
```

- 隠れた SSID は、画面からは足せません。上のように `hidden = true` を
  付けて、このファイルに書いてください。
- 前の形 (`[wifi]` の中に `ssid` と `password` が 1 組) も、今までどおり
  読めます。それが 1 つ目のネットワークになります。画面でネットワークを
  覚えたり忘れたりすると、上の新しい形で書き直します (そのとき、
  ファイルの中のコメントは残りません)。
- `[wifi]` があるときは `enable = true` が要ります (今までと同じ)。
- Wi-Fi そのものを使うかどうかは /etc/system_conf.toml の
  `wifi_auto_start` で決まります。NARYA (S3) は Bluetooth と Wi-Fi を
  同時には使えないので、Wi-Fi を使うときは `ble_auto_start = false` に
  してください。
