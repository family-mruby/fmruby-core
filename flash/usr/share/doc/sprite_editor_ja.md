# スプライトエディタ: 小さな絵とタイルを描く

スプライトエディタ (/app/tool/sprite_editor.app.rb) は、ゲームのキャラクターやチャットのスタンプに
使う小さな絵を、1 点ずつ拡大して描くアプリ。ランチャーから開く。

画面

- 上にメニュー (ファイル・編集)、左に道具、まん中に拡大した絵、右に色、下に状態の行。
- 状態の行には、ファイルの名前 (変更があると *)、絵の大きさ、指している点の位置、今の色が出る。

道具 (左の列)

- ペン: 押したまま動かすと、なぞったところを今の色で塗る。キーは P。
- 消す: なぞったところを透明にする。キーは E。
- 塗る: 押した点とつながった同じ色のところを、まとめて今の色にする。キーは F。
- 拾う: 押した点の色を今の色にする (拾ったらペンに戻る)。キーは I。
- 戻す: 直前の操作を取り消す。10 回まで戻れる。Ctrl+Z でも同じ。

色 (右)

- 256 色 (端末が出せる色の全部) が 16 x 16 の升目に並ぶ。押すとその色になる。
- 左上から 2 つ目の市松模様の升目が透明 (色の番号 01)。絵の上でも透明は市松模様で出る。
  スプライトやスタンプとして出すと、透明のところは後ろが見える。
- 升目の下の列は最近使った色。その下に今の色とその番号 (16 進) が出る。

ファイル (メニューのファイル)

- 新規 (Ctrl+N): 大きさを 16x16・24x24・32x32・48x48 から選ぶ。全部透明の絵から始まる。
- 開く (Ctrl+O): PNG か BMP を選ぶ。開く・保存・名前を付けて保存のファイルの画面は
  /home/stamps/ から始まる (無ければ作る)。
- ファイルマネージャーで絵をダブルクリックすると画像ビューワーが開く。その「スプライトエディタで開く」で
  このアプリに移る。ファイルマネージャーで絵を右クリック (か S) しても「スプライトエディタで開く」がある。
  ダブルクリックでこのアプリを開くようにするには、/home/associations.toml に
  `png = "/app/tool/sprite_editor.app.rb"` (BMP なら bmp = ...) を書く。
- 保存 (Ctrl+S): 開いたファイルに、開いた形式 (PNG か BMP) のまま書く。まだファイルの無い
  新しい絵では、名前を付けて保存と同じになる。
- 名前を付けて保存: 置き場と名前を選んで保存する。.png も .bmp も付けないと .png になる。
- 保存していない変更があるまま、新規・開く・閉じる (右上の丸・Ctrl+Q) をすると、保存するか聞かれる。
  「キャンセル」で元の画面に戻る。

タイルのシート

- 48 x 48 より大きな絵は、16 x 16 のタイルが並んだシートとして開く。右下にタイルの一覧が出て、
  押したタイルがまん中で拡大される。保存すると、直したタイルのほかはそのまま書き戻る。
- タイルが多いときは、一覧の右の矢印かホイールで送る。

Window の大きさ

- 右下の角をつかむと大きさを変えられる。広げると、絵の拡大と色の升目が大きくなる。
