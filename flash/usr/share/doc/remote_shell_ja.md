# リモートシェル

リモートシェルを有効にすると、あなたが許した人が、Asterism の console
(ブラウザの Terminal) から、遠くにいながらこの端末に入れます。同じ家の
ネットワークにいなくても届きます。困ったときに、この端末のファイルや
アプリを見て直してもらうための仕組みです。

既定は無効です。有効にしない限り、だれも入れません。

## 1. 有効にする

受け取りのアプリ (Receiving) を開き、「リモートシェル: 無効」を押すと
「リモートシェル: 有効」に変わります。もう一度押すと無効に戻ります。
選んだ状態は /home/asterism/receive.toml に書かれ、端末を起動し直しても
残ります。

入れるのは、次の両方がそろった人だけです。

- 「シェル」のタブの一覧にある相手。ふつうは「console から」の 1 つで、
  console の管理者がこの端末に印を付けると、console から届きます。
- その console で、管理者がその人にリモートシェルを許していること
  (見るだけ、または変えるまで)。

また、確かめられた接続 (証明書のある tls/ のルータ、または console から
開いたブラウザ版) でなければ入れません。

## 2. 入られている間の印

だれかが入っている間は、画面の上のメニューバーに「RS」が出ます
(かなのモードの表示の左)。相手が出る (`exit`) か、5 分のあいだ何も
しなければ消えます。

## 3. 見られること・変えられること

- 見る: フォルダの一覧、ファイルの中身、空き容量、メモリ、動いている
  アプリの一覧、端末の版。
- 変える (許された人だけ): ファイルの写し・名前の変更・削除、フォルダを
  作る、ファイルを console へ取り出す・console から置く、アプリを起動する・
  止める。
- できないこと: 自分の Ruby のプログラムを動かすこと、エディタのような
  画面を使うこと、この端末の画面やキーボードを操作すること。

/home の外 (/usr・/etc など本体の領域) も読み書きできます。本体のファイルを
消すと起動しなくなることがあるので、そこを変える前には console が相手に
一度確かめます。

## 4. 鍵の場所は対象外

次の場所は、リモートシェルからは読めず、書けず、消せません。中身の一覧も
出ません。

- /home/asterism (Asterism の鍵と証明書、受け取りの設定)
- /home/wifi.toml・/etc/wifi.toml (Wi-Fi のパスワード)
- /home/secrets.toml・/etc/secrets.toml (API のキー)

これらを含むフォルダ (/・/home・/etc・/home/asterism) も、まとめて消したり
動かしたりできません。受け取りの設定も鍵の場所にあるので、リモートシェルを
有効にするかどうかは、この端末の上でしか変えられません。

## 5. 切るには

受け取りのアプリで「リモートシェル: 有効」を押して無効にします。入って
いる人は、次の行から断られ、「RS」の印も消えます。ネットワークを切っても
入れなくなります。

ブラウザ版では、ページを閉じると入れなくなります。ブラウザ版のファイルは
そのブラウザの中にあり、ページを読み込み直しても残りますが、読み込み
直したページは console からもう一度開くまで入れません。
