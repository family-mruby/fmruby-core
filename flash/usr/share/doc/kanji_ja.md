# 漢字変換

かな入力 (Ctrl+Space、JIS キーボードなら半角/全角) で打った読みを、
単語ごとに漢字へ変換できます。辞書のファイルを SD カードに置くと使える
ようになります。辞書が無いときは、今までどおりかなだけを打てます。

ブラウザ版とネイティブ版 (Linux) は、この辞書を使いません。下の
「ブラウザ版とネイティブ版」を見てください。

## 1. 辞書を手に入れる

- Family mruby のリリース (GitHub のリリースのページ) に添付してある
  2 つのファイル:
  - fmrb_kanji.dic            辞書 (約 1 MB)
  - fmrb_kanji_LICENSE.txt    辞書の元データの使用条件
- 開発する人は、ソースから作れます。fmruby-core で
  `rake kanji:dict` を実行すると (元データを取ってきて作ります)、
  tools/kanji/work/out/ に辞書と LICENSE ができます。同じ版のソースから
  作れば、リリースの添付と同じファイルになります。

## 2. SD カードに置く

置き場所は /sd/dict/fmrb_kanji.dic です (SD カードの一番上の dict
フォルダ)。LICENSE も同じフォルダに置いてください。

### PC で写す

1. SD カードを PC に差し、一番上に dict フォルダを作る。
2. fmrb_kanji.dic と fmrb_kanji_LICENSE.txt をそこへ写す。
3. カードを端末に戻し、端末を再起動する。

開発する人は `rake kanji:place DEST=<カードの一番上>` で、辞書が壊れて
いないかを確かめながら写せます (dict フォルダも作ります)。

### ネットワークで送る (Asterism)

別の Family mruby の端末の Shell から (端末のノード ID は `anodes` で
分かります):

    asend <ノード> fmrb_kanji.dic --sd

PC からは `ruby tools/fmrb_send.rb <ノード> fmrb_kanji.dic --sd`
(fmruby-core で)、console のページからも SD を選んで送れます。
受け取る端末では、先に受け取りを有効にしておきます (Shell の
`areceive` か、アプリ「受け取り」)。

**--sd で送ったファイルは /sd/inbox/ に届きます**。受け取った端末の
Shell で dict へ移してください:

    mkdir /sd/dict
    mv /sd/inbox/fmrb_kanji.dic /sd/dict/

/sd/dict/ がもうあれば mkdir は要りません。同じ名前のファイルが
inbox にあると、届いた方は fmrb_kanji(1).dic のような名前になります
(送るときに -o を付けると上書きします)。移したら端末を再起動します。

辞書は**起動のときに探します**。置いた後・入れ替えた後は再起動が要ります。
SD が無い・辞書が無い・壊れているときは、変換なしのかな入力のまま動きます。

## 3. 使い方

かなモードで読みを打つと、画面の下に 1 行が出て、読みがたまります
(まだアプリには入りません)。

| キー | 読みを打っているとき | 候補を出しているとき |
|---|---|---|
| スペース・変換 | 変換して候補を出す | 次の候補 |
| Enter | かなのまま確定 | 選んでいる候補で確定 |
| 1〜9 | 読みをかなで確定し、数字を打つ | その番号の候補で確定 |
| Esc | 読みを捨てる | 読みに戻る |
| BS | 読みの 1 字を消す | 読みに戻って 1 字消す |
| かなを打つ | 読みに足す | 今の候補で確定し、続けて次の読み |

- 矢印・Tab・記号・Ctrl+S などを押すと、見えているとおりに確定してから、
  そのキーがアプリに届きます。かなモードを切ったときや、別のアプリへ
  移ったときも、見えているとおりに確定します。
- 確定の Enter は改行になりません。
- 読みの全部が辞書に無いときは、先頭から一番長く一致したところを
  変換します。残りは次の読みになります (いった → 行っ、残り た)。
- 漢字 1 字の読みからも変換できます。端末のフォントにある漢字は、
  どれも出せます。

### 画面の下の 1 行

左に読み、その右に番号つきの候補、右端に「今の番号/候補の数」が出ます。
選んでいる候補は色が反転します。候補が多いときは、スペースで次の
ページへ進みます (最後の次は最初に戻ります)。候補が無いときは
「(候補なし)」と出ます。この 1 行はどのアプリの上でも同じ場所
(全画面のアプリの上でも) に出ます。

## 4. 変換を止める・置き場所を変える

/etc/system_conf.toml に次の行を書いて再起動します。

    kanji_convert = false                    # 辞書があっても変換しない
    kanji_dict = "/sd/dict/fmrb_kanji.dic"   # 辞書の場所 (書かなければこれ)

辞書を SD から外しても、変換は止まります。

## 5. ブラウザ版とネイティブ版

- ブラウザ版: PC のブラウザの日本語入力 (IME) を使います。エディタ・
  Shell など文字のカーソルがあるアプリで IME を日本語にして打つと、
  確定した文字がアプリに入ります。ゲームなどカーソルの無いアプリでは
  IME は効きません。
- ネイティブ版 (Linux): Linux の日本語入力 (IME) を使います。

どちらも、この辞書は要りません。

## 6. 辞書について

- mozc の辞書の元データ (IPAdic ほか) と、Unicode の Unihan の読みから
  作っています。使用条件は fmrb_kanji_LICENSE.txt にあります。
- 候補は端末のフォントで描ける字だけからなる語です。よく使う語から
  1 MB に入るだけ (約 8 万語) を入れています。
- 選んだ候補を覚えることはしません (候補の順はいつも同じ)。
- かな入力で打てない読み (てぃ・ふぁ・ゔ など) の語は入っていません。
