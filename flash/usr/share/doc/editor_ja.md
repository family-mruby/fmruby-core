# エディタ: 複数のファイルを開く

エディタは 5 つまでのファイルを同時に開けます。2 つ以上開いているときは、
メニューの下にタブの行が出て、開いているファイルの名前が並びます。タブの行は
メニューの行とも編集する所とも違う色の帯です。編集中のファイルは反転して表示
され、名前の後ろの「*」は保存していない変更があることを表します。ファイルが 1 つのときはタブの行は出ません。

開く・閉じる

- ファイル > 開く は、今開いているファイルはそのままに、追加で開きます。
  もう開いているファイルを選ぶと、そのファイルに切り替わります。編集中の
  ファイルが新規で空のときは、そこに開きます。
- ファイル > 新規 (Ctrl+N) は、空のファイルを足します。
- ファイル > ひな形 は、新しいファイルにひな形を入れます。編集中のファイルが
  新規で空のときは、そこに入れます。
- ファイル > 閉じる (Ctrl+W) は、編集中のファイルを閉じます。保存していない
  変更があれば先に聞きます: Y で保存して閉じる、N で変更を捨てて閉じる、
  C か Esc で閉じずに戻ります。最後の 1 つを閉じると空のファイルになります。
- 5 つ開いているときは、それ以上は開けません。どれかを閉じてください。

ほかの所から開く

エディタが動いているときに、ファイルマネージャやシェルの edit でファイルを
開くと、2 つ目のエディタは起動せず、動いているエディタにタブが足されます
(ファイル > 開く と同じ決まりです)。保存の確認やメニューを出している最中なら、
それを閉じた後に開きます。デスクトップのエディタのアイコンやメニューは、
動いているエディタを前に出します。

ファイルを切り替える

- タブをクリックします。
- Alt+. で次、Alt+, で前のファイルへ。
- Alt+1 〜 Alt+5 で、その番目のファイルへ。
- Ctrl+PageDown と Ctrl+PageUp は Alt+. と Alt+, と同じです (Alt の無い
  キーボード向け)。

エディタを終える

Ctrl+X、Ctrl+Q、ファイル > 終了 は、保存していない変更のあるファイルを 1 つずつ、
そのファイルを見せてから聞きます。C か Esc を押すとそこで止まり、エディタは
終わりません。

実行 (F5)、検索、型の手助け (F1・Ctrl+T・Ctrl+E)、コピー・貼り付けは、編集中の
ファイルに対して働きます。あるファイルでコピーして別のファイルに貼り付ければ、
ファイルの間で文字を写せます。キーの一覧 (メニューの「キー」か Alt+K) にも
載っています。

F5 で実行したアプリの名前はファイルごとに覚えていて、AI ヘルパー (Modern) の
「直して」はそのアプリのエラーだけを使います。
