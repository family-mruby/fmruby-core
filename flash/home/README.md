# About /home

This is where your working data lives.
It ships with:

- services.toml       your service list (the file explains itself)
- services/           your service sources (three examples included)

Samples live in the system area:

- /usr/share/samples/ruby/     small Ruby program samples
- /usr/share/samples/slides/   PicoRabbit slide decks
- /app/                        the installed apps (tests under /app/test)

To play with a sample, copy it here first and edit your copy.
