# /home について

ユーザの作業データの置き場所です。
以下が格納されてます:

- services.toml       あなたのサービス一覧 (ファイル自身に説明があります)
- services/           あなたのサービス本体 (例を 3 つ同梱)

サンプルは次のシステム領域にあります:

- /usr/share/samples/ruby/     小さな Ruby プログラムサンプル
- /usr/share/samples/slides/   PicoRabbit のスライド見本
- /app/                        インストール済みアプリ (試験用は /app/test)

サンプルで遊ぶときは、ここへコピーしてから自分の写しを編集してください。
