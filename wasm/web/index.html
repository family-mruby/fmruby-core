How to use it

  • Click the screen to switch the machine on. The mouse and the keyboard work while the screen has focus; the top-left menu opens the launcher, the editor and the rest of the desktop.
  • Japanese kana input toggles with Ctrl+Space, or by clicking the [A] indicator in the menu bar (A → kana → katakana). Romaji is typed as usual: kya gives the kana for "kya".
  • Sound only starts after that first click -- browsers do not let a page make noise before one.
  • Theme and resolution are stored in this browser and applied at boot, so changing them reloads the page.
  • What you write is kept. Everything under /home -- the programs you save, your service list -- and anything in /app/usr, which is where an app has to sit for the launcher to list it. Your settings are kept as well. All of it stays in this browser between visits. Nowhere else: it never leaves the machine you are reading this on. A private window keeps nothing, and a browser may reclaim the space after a long absence, so download your files if they matter to you; that one file puts your work, and your settings, back here or in another browser. Open the page twice and only the first tab saves.
  • Full screen puts the machine on the whole display. Where the browser allows it the machine keeps Esc for itself; where it does not, Esc leaves full screen instead of reaching the app.

What it is not

  • Everything runs in the page. What you save under /home is kept, but the rest of the machine is built fresh every time: files written anywhere else, and /tmp above all, are gone on the next reload.
  • Desktop Chrome and Firefox are what this targets. Safari is untested, and phones and tablets are not a target -- there is no on-screen keyboard.
